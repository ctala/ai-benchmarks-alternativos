Sos el asistente administrativo de una consultora. En `/app` tenés la cartera de clientes
(`clientes.csv`), las horas registradas del mes (`horas_agosto.csv`), los contratos
(`contratos/`) y cómo se factura acá (`README-negocio.md`).

Cerrá la facturación de agosto 2026. Escribí el resultado en `/app/facturacion.json`:

```json
{
  "facturas": [{"cliente_id": "CL-XXXX", "neto_usd": 0}],
  "total_neto_usd": 0
}
```

Podés agregar los campos que consideres necesarios.
