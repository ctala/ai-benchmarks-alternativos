# Análisis de bugs

## Bug 1: División por cero
```python
average = total / len(processed)
```
Si `orders` está vacía o ninguna orden tiene estado `'pending'`, `processed` queda vacía y se lanza `ZeroDivisionError`.

**Solución:** comprobar si hay órdenes procesadas antes de dividir. Devuelvo `0`, aunque `None` también es válido si quieres distinguir "sin datos" de "promedio cero".

## Bug 2: Mutación del diccionario original
```python
order['final_price'] = final_price
order['status'] = 'processed'
```
Esto modifica los diccionarios de la lista que recibe la función. Es un efecto secundario inesperado: si llamas a la función dos veces con la misma lista, la segunda vez no encuentra órdenes `pending`, y el código que llamó a la función ve sus datos alterados.

**Solución:** crear una copia de cada orden y modificar la copia. Con `{**order, ...}` basta una copia superficial si los valores son simples. Si las órdenes tienen estructuras anidadas (listas, otros dicts), usa `copy.deepcopy(order)`.

## Bug 3: `count` incorrecto
```python
'count': len(orders)
```
Cuenta todas las órdenes recibidas, incluidas las que no se procesaron. Debería reflejar las procesadas, que además es el divisor del promedio, así que los datos del resultado serían inconsistentes.

## Problemas adicionales

4. **`KeyError` si faltan claves.** `order['status']` falla si la orden no tiene esa clave. Con `.get('status')` se evita para el estado. Para `'total'` conviene que el error sea explícito, porque una orden pendiente sin total es un dato corrupto.
5. **Precisión de punto flotante.** Con dinero, `0.1 * 150.30` puede dar resultados como `135.27000000000001`. Redondeo a 2 decimales; en producción lo ideal es usar `Decimal`.
6. **Números mágicos.** `100` y `0.1` están incrustados en el código. Mejor como constantes con nombre.

## Versión corregida

```python
DISCOUNT_THRESHOLD = 100
DISCOUNT_RATE = 0.10


def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order.get('status') != 'pending':
            continue

        order_total = order['total']
        discount = order_total * DISCOUNT_RATE if order_total > DISCOUNT_THRESHOLD else 0
        final_price = round(order_total - discount, 2)

        # Copia: no se modifica el diccionario original
        processed_order = {
            **order,
            'final_price': final_price,
            'status': 'processed',
        }

        processed.append(processed_order)
        total += final_price

    count = len(processed)
    average = round(total / count, 2) if count > 0 else 0

    return {
        'processed': processed,
        'total': round(total, 2),
        'average': average,
        'count': count,
    }
```
