# Análisis de bugs

## Bug 1: División por cero

```python
average = total / len(processed)
```

Si ninguna orden tiene `status == 'pending'` (o si `orders` está vacía), `processed` queda vacía y se lanza `ZeroDivisionError`. Es un caso normal: por ejemplo, cuando todas las órdenes ya fueron procesadas en una ejecución anterior.

**Solución:** verificar que haya elementos antes de dividir.

```python
average = total / len(processed) if processed else 0
```

## Bug 2: Mutación del diccionario original

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

Los diccionarios en Python se pasan por referencia, así que la función modifica las órdenes del llamador. Esto provoca:

- **Efectos secundarios inesperados:** quien llama a la función ve sus datos alterados sin haberlo pedido.
- **Comportamiento no idempotente:** si se llama dos veces con la misma lista, la segunda vez no procesa nada porque todas las órdenes ya tienen `status = 'processed'`. Esto además dispara el Bug 1.
- **Aliasing:** `processed` contiene los mismos objetos que `orders`, así que modificar uno afecta al otro.

**Solución:** crear una copia antes de modificar.

```python
processed_order = {**order, 'final_price': final_price, 'status': 'processed'}
```

> Nota: `{**order}` hace una copia superficial. Si las órdenes contienen estructuras anidadas que se van a modificar (por ejemplo, una lista de items), habría que usar `copy.deepcopy(order)`.

## Bug 3: `count` incorrecto

```python
'count': len(orders)
```

Cuenta **todas** las órdenes recibidas, no las procesadas. Esto es inconsistente con `total` y `average`, que solo consideran las pendientes. Con 10 órdenes de las cuales solo 3 estaban pendientes, el resultado diría `count: 10`, lo cual es engañoso.

**Solución:**

```python
'count': len(processed)
```

## Versión corregida

```python
def process_orders(orders):
    """
    Procesa las órdenes pendientes aplicando un 10% de descuento
    a las que superan 100. No modifica la lista ni los diccionarios originales.
    """
    total = 0
    processed = []

    for order in orders:
        if order.get('status') != 'pending':
            continue

        order_total = order['total']
        discount = order_total * 0.1 if order_total > 100 else 0
        final_price = order_total - discount

        # Copia en lugar de mutar el original
        processed_order = {
            **order,
            'final_price': final_price,
            'status': 'processed',
        }

        total += final_price
        processed.append(processed_order)

    count = len(processed)
    average = total / count if count else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count,
    }
```
