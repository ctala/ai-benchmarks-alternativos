```python
def process_orders(orders):
    """
    Procesa las órdenes cuyo estado es 'pending':
    - Aplica un 10 % de descuento si el total > 100.
    - Calcula el precio final.
    - Devuelve un nuevo diccionario con las órdenes procesadas,
      el total acumulado, el promedio y la cantidad de órdenes procesadas.

    No muta el diccionario de entrada y evita división por cero.
    """
    total = 0
    processed = []                     #lista de órdenes ya procesadas (copias)

    for order in orders:
        # Solo nos interesan las órdenes pendientes
        if order.get('status') == 'pending':
            # Evitamos mutar el diccionario original: trabajamos sobre una copia
            new_order = order.copy()

            # Cálculo del descuento y precio final
            discount = new_order['total'] * 0.1 if new_order['total'] > 100 else 0
            final_price = new_order['total'] - discount

            # Actualizamos la copia
            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            # Acumulamos resultados
            total += final_price
            processed.append(new_order)

    # Evitamos división por cero: si no hay órdenes procesadas, el promedio es 0
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,   #lista de órdenes procesadas (copias)
        'total': total,
        'average': average,
        'count': len(processed)   #número real de órdenes procesadas
    }
```

### Qué cambió y por qué

1. **Evitar la división por cero**  
   ```python
   average = total / len(processed) if processed else 0
   ```
   Si `processed` está vacío, se asigna `0` (o bien podría ser `None` según la política del proyecto).

2. **No mutar el diccionario original**  
   Se crea una copia superficial con `new_order = order.copy()` y se modifican únicamente esa copia. El diccionario que llegó en `orders` queda intacto.

3. **`count` refleja las órdenes procesadas**  
   Se devuelve `'count': len(processed)`, que coincide con la cantidad de elementos realmente añadidos a la lista `processed`.
