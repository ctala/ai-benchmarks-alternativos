## Bugs encontrados

### 1. División por cero
Si ninguna orden tiene `status == 'pending'`, `processed` queda vacía y `total / len(processed)` lanza `ZeroDivisionError`.

**Corrección:** calcular el promedio solo si hay órdenes procesadas. Si prefieres, puedes devolver `None` en lugar de `0`, lo que distingue "sin datos" de "promedio cero".

### 2. Muta los diccionarios originales
`order['final_price'] = ...` y `order['status'] = 'processed'` modifican las órdenes que recibió la función. Quien llama puede tener efectos secundarios inesperados, y si reutiliza la lista original verá estados distintos a los que tenía antes.

**Corrección:** crear una copia nueva de cada orden con los campos actualizados, usando `{**order, ...}`.

### 3. `count` (aclaración)
Dices que `count` debería ser `len(processed)`, pero el código actual con `len(orders)` puede ser intencional: indica cuántas órdenes se recibieron en total. Depende de lo que quieras reportar, así que en la versión corregida dejo ambos valores con nombres explícitos para que no haya ambigüedad:

- `count`: número de órdenes procesadas (`len(processed)`), como pediste.
- `total_orders`: número de órdenes recibidas (`len(orders)`).

## Versión corregida

```python
def process_orders(orders):
    total = 0.0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Copia en lugar de modificar la orden original
            processed_order = {
                **order,
                'final_price': final_price,
                'status': 'processed',
            }
            processed.append(processed_order)
            total += final_price

    # Evita división por cero
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed),
        'total_orders': len(orders),
    }
```
