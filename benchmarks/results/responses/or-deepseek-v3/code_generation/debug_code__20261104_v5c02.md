## Bugs identificados y correcciones:

### 1. **División por cero**
**Problema**: `average = total / len(processed)` causará `ZeroDivisionError` si no hay órdenes con estado 'pending' (cuando `len(processed) == 0`).

**Solución**: Verificar si `processed` tiene elementos antes de calcular el promedio.

### 2. **Mutación del diccionario original**
**Problema**: Se modifican los diccionarios originales en `orders` al asignar `order['final_price']` y `order['status'] = 'processed'`. Esto afecta los datos originales fuera de la función.

**Solución**: Crear una copia del diccionario antes de modificarlo.

### 3. **'count' incorrecto**
**Problema**: `'count': len(orders)` devuelve el total de órdenes en lugar del número de órdenes procesadas.

**Solución**: Cambiar a `len(processed)` para que refleje solo las órdenes procesadas.
