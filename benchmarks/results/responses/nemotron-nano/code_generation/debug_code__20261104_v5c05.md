```python
from copy import deepcopy
from typing import List, Dict, Any


def process_orders(orders: List[Dict[str, Any]]) -> Dict[str, Any]:
    """
    Procesa una lista de órdenes cuyo 'status' es 'pending'.

    - Calcula el descuento (10% si total > 100) y el precio final.
    - Cambia el estado a 'processed' **solo en la copia**.
    - Devuelve estadísticas sin mutar los diccionarios originales.
    """
    total_processed = 0.0          # suma de precios finales de las órdenes procesadas
    processed: List[Dict[str, Any]] = []   # lista de copias modificadas

    for order in orders:
        # Sólo nos interesan las órdenes pendientes
        if order.get('status') != 'pending':
            continue

        # Validaciones básicas
        if 'total' not in order or not isinstance(order['total'], (int, float)):
            raise ValueError(f"La orden {order} no tiene un campo 'total' válido.")
        if 'total' < 0:
            raise ValueError(f"El total de la orden {order} no puede ser negativo.")

        # Hacemos una copia profunda para no mutar el original
        order_copy = deepcopy(order)

        # Cálculo del descuento y precio final
        discount = order_copy['total'] * 0.1 if order_copy['total'] > 100 else 0
        final_price = order_copy['total'] - discount

        # Actualizamos la copia
        order_copy['final_price'] = round(final_price, 2)   # opcional: redondear a 2 decimales
        order_copy['status'] = 'processed'

        processed.append(order_copy)
        total_processed += final_price

    # ---------- Estadísticas ----------
    count = len(processed)

    # Evitamos división por cero
    average = total_processed / count if count else 0.0

    # ---------- Resultado ----------
    return {
        "processed": processed,          # lista de copias con los nuevos campos
        "total": round(total_processed, 2),
        "average": round(average, 2),
        "count": count                    # número de órdenes realmente procesadas
    }
```

### 🔎  Qué cambió y por qué  

| Cambio | Razón |
|--------|-------|
| `order.get('status') != 'pending'` + `continue` | Ignoramos órdenes que no están en estado *pending* sin lanzar excepción. |
| `deepcopy(order)` | Creamos una copia independiente; las modificaciones no afectan al diccionario original. |
| `order_copy['final_price'] = round(final_price, 2)` | Redondeamos para evitar números con muchos decimales innecesarios (no es obligatorio, pero suele ser útil). |
| `total_processed` (nombre más descriptivo) | Claridad en la variable que acumula el total. |
| `average = total_processed / count if count else 0.0` | Evita `ZeroDivisionError` cuando no hay órdenes pendientes. |
| `count = len(processed)` | Refleja cuántas órdenes fueron realmente procesadas. |
| `raise ValueError(...)` | Detectamos datos incoherentes antes de que el algoritmo produzca resultados erróneos. |
| `round(..., 2)` en los valores retornados | Mantiene la salida consistente y “limpia”. |
| Comentarios y docstring | Mejoran la legibilidad y facilitan el mantenimiento. |
