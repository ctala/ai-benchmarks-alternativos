# 13. Posibles problemas y ajustes

## Problema 1: Muchas visitas, pocas ventas de Aurora

**Causas posibles:**

- El precio se percibe alto sin suficiente valor.
- Falta prueba social.
- La landing de Aurora no es clara.
- No hay asesoría suficiente.

**Ajuste:**

- Reforzar testimonios.
- Enviar más tráfico a WhatsApp.
- Mostrar rutina paso a paso.
- Explicar ingredientes y resultados.

---

## Problema 2: CAC alto

**Causas posibles:**

- Segmentación muy amplia.
- Anuncios no enfocados en Bogotá.
- Creativos genéricos.
- Falta de retargeting.

**Ajuste:**

- Segmentar más fino.
- Priorizar retargeting.
- Usar audiencias de clientas Luna/Sol.
- Reforzar anuncios con Aurora.

---

## Problema 3: WhatsApp responde pero no cierra

**Causas posibles:**

- Respuestas lentas.
- No se resuelve objeción de precio.
- No se recomienda rutina.
- Falta seguimiento.

**Ajuste:**

- Crear guion de cierre para Aurora.
- Enviar testimonios.
- Preguntar tipo de piel.
- Ofrecer asesoría breve.
- Hacer seguimiento suave a 24-48 horas.

---

## Problema 4: TikTok da vistas pero no vende

**Causas posibles:**

- Contenido muy entretenido pero sin intención.
- No se muestra compra.
- No se lleva a web o WhatsApp.
- Falta prueba social.

**Ajuste:**

- Incluir CTA claro.
- Mostrar resultados.
- Enlazar a Aurora.
- Usar código o enlace directo.
- Hacer videos tipo reseña y rutina.
