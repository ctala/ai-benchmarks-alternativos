## Bug 1: División por cero si no hay órdenes `pending`

### Problema

Esta línea falla si `processed` está vacío:

```python
average = total / len(processed)
```

Si ninguna orden tiene estado `'pending'`, entonces `processed` queda como lista vacía:

```python
len(processed) == 0
```

Eso provoca:

```python
ZeroDivisionError: division by zero
```

### Solución

Hay que calcular el promedio solo si existe al menos una orden procesada:

```python
average = total / len(processed) if processed else 0
```

O de forma equivalente:

```python
count = len(processed)
average = total / count if count else 0
```

---

## Bug 2: El código muta el diccionario original

### Problema

Aquí:

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

se está modificando directamente el diccionario que viene en la lista `orders`.

Eso significa que la función tiene efectos secundarios no deseados. Por ejemplo:

```python
orders = [
    {'status': 'pending', 'total': 150}
]

result = process_orders(orders)

print(orders[0])
```

Con tu versión original, el objeto de entrada cambia a:

```python
{'status': 'processed', 'total': 150, 'final_price': 135.0}
```

Cuando probablemente deberías obtener una lista procesada nueva, sin alterar el input original.

### Solución

Crear una copia del orden antes de modificarlo:

```python
new_order = dict(order)
```

Luego modificar `new_order`, no `order`.

Si los diccionarios tuvieran estructuras anidadas, podrías usar `copy.deepcopy(order)`, pero para este caso `dict(order)` es suficiente.

## Bug 3: `'count'` debería ser `len(processed)`, no `len(orders)`

### Problema

Eso cuenta todas las órdenes recibidas, incluyendo las que no están en estado `'pending'`.

Pero si `'count'` representa cuántas órdenes fueron procesadas, debería ser:

```python
'count': len(processed)
```

# Versión corregida

```python
def process_orders(orders):
    total = 0.0
    processed = []

    for order in orders:
        if order.get('status') == 'pending':
            # Copia para no modificar el diccionario original
            new_order = dict(order)

            amount = new_order.get('total', 0)

            discount = amount * 0.1 if amount > 100 else 0
            final_price = amount - discount

            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            total += final_price
            processed.append(new_order)

    count = len(processed)

    # Evita división por cero si no hay órdenes procesadas
    average = total / count if count else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count
    }
```

# Versión aún más robusta

Si quieres manejar también el caso en que `orders` sea `None`, puedes hacer:

```python
def process_orders(orders):
    if orders is None:
        orders = []

    total = 0.0
    processed = []

    for order in orders:
        if order.get('status') == 'pending':
            new_order = dict(order)

            amount = new_order.get('total', 0)

            if amount > 100:
                discount = amount * 0.1
            else:
                discount = 0

            final_price = amount - discount

            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            total += final_price
            processed.append(new_order)

    count = len(processed)
    average = total / count if count else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count
    }
```
