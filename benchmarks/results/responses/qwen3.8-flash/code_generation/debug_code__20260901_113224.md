## Bugs identificados

### 1. División por cero si no hay órdenes `pending`

Este bloque:

```python
average = total / len(processed)
```

falla si `processed` está vacío, porque `len(processed)` sería `0`.

Ejemplo que rompe el código:

```python
orders = [
    {"status": "cancelled", "total": 50}
]
```

No hay ninguna orden pendiente, así que `processed = []` y se ejecuta:

```python
average = 0 / 0
```

Eso lanza:

```python
ZeroDivisionError
```

La corrección es calcular el promedio solo si hay órdenes procesadas.

### 2. Muta el diccionario original

En este código:

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

estás modificando directamente los diccionarios que vienen en `orders`.

Eso significa que después de llamar a la función, el input original cambia.

Si la función debe procesar órdenes sin alterar el input original, debes trabajar sobre una copia.

## Versión corregida

```python
def process_orders(orders):
    total = 0.0
    processed = []

    for order in orders:
        if order.get("status") == "pending":
            order_copy = dict(order)

            subtotal = order_copy.get("total", 0)
            discount = subtotal * 0.1 if subtotal > 100 else 0
            final_price = subtotal - discount

            order_copy["final_price"] = final_price
            order_copy["status"] = "processed"

            total += final_price
            processed.append(order_copy)

    count = len(processed)
    average = total / count if count > 0 else 0.0

    return {
        "processed": processed,
        "total": total,
        "average": average,
        "count": count,
    }
```

---

## Explicación de la corrección

### Evitar mutación

Se crea una copia de cada orden:

```python
order_copy = dict(order)
```

Luego se modifican solo los campos en la copia:

```python
order_copy["final_price"] = final_price
order_copy["status"] = "processed"
```

Así el diccionario original dentro de `orders` no cambia.

---

### Evitar división por cero

Se calcula el promedio de forma segura:

```python
count = len(processed)
average = total / count if count > 0 else 0.0
```

Si no hay órdenes procesadas, `average` será `0.0`.

---

### `count` correcto

Se devuelve:

```python
"count": count
```

donde:

```python
count = len(processed)
```

Es decir, la cantidad de órdenes realmente procesadas.
