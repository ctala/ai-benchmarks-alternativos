## 2. Muta el diccionario original

### Código problemático

```python

order['status'] = 'processed'
```

### Problema

`order` es una referencia al diccionario original dentro de `orders`. Al modificarlo, estás cambiando la lista de entrada.

### Ejemplo


Antes de ejecutar `process_orders`, la orden era:

Después, se convierte en:


Esto suele ser un efecto secundario no deseado.

# Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Copiamos el diccionario para no mutar el original
            processed_order = order.copy()

            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'

            total += final_price
            processed.append(processed_order)

    # Evitamos división por cero si no hay órdenes procesadas
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```

# Versión un poco más robusta

Si quieres evitar errores por claves faltantes, puedes usar `.get()`:

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order.get('status') == 'pending':
            order_total = order.get('total', 0)

            discount = order_total * 0.1 if order_total > 100 else 0
            final_price = order_total - discount

            processed_order = order.copy()

            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'

            total += final_price
            processed.append(processed_order)

    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```

Esta versión evita `KeyError` si alguna orden no tiene `status` o `total`.
