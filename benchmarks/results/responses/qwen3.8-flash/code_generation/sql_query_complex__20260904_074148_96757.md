- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada

## Respuesta completa

Te dejo una query SQL usando CTEs y funciones de ventana. Asume que:

- `status = 'completed'`
- El revenue se toma de `orders.total`
- La categoría más comprada se calcula por cantidad total de productos (`SUM(order_items.quantity)`)
- Los últimos 6 meses son desde `NOW()`
- En caso de empate en categoría, se elige la primera por nombre

```sql
WITH completed_orders AS (
    SELECT
        o.id,
        o.customer_id,
        o.total
    FROM orders o
    WHERE o.status = 'completed'
      AND o.created_at >= NOW() - INTERVAL '6 months'
),

customer_totals AS (
    SELECT
        c.id AS customer_id,
        c.name AS nombre,
        c.email,
        c.country AS pais,
        COUNT(DISTINCT co.id) AS total_orders,
        COALESCE(SUM(co.total), 0) AS total_revenue,
        CAST(
            COALESCE(SUM(co.total), 0) AS DECIMAL(18, 2)
        ) / NULLIF(COUNT(DISTINCT co.id), 0) AS avg_order_value
    FROM customers c
    INNER JOIN completed_orders co
        ON co.customer_id = c.id
    GROUP BY
        c.id,
        c.name,
        c.email,
        c.country
    HAVING COUNT(DISTINCT co.id) >= 3
),

category_totals AS (
    SELECT
        co.customer_id,
        COALESCE(p.category, 'Sin categoría') AS categoria,
        SUM(oi.quantity) AS total_quantity
    FROM completed_orders co
    INNER JOIN order_items oi
        ON oi.order_id = co.id
    INNER JOIN products p
        ON p.id = oi.product_id
    GROUP BY
        co.customer_id,
        COALESCE(p.category, 'Sin categoría')
),

ranked_categories AS (
    SELECT
        customer_id,
        categoria,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY total_quantity DESC, categoria ASC
        ) AS rn
    FROM category_totals
)

SELECT
    ct.nombre,
    ct.email,
    ct.pais,
    ct.total_orders,
    ct.total_revenue,
    ct.avg_order_value,
    rc.categoria AS categoria_mas_comprada
FROM customer_totals ct
LEFT JOIN ranked_categories rc
    ON rc.customer_id = ct.customer_id
   AND rc.rn = 1
ORDER BY ct.total_revenue DESC
LIMIT 10;
```

Notas por motor de base de datos:

- Para **MySQL**, cambia el filtro de fecha por:

```sql
AND o.created_at >= NOW() - INTERVAL 6 MONTH
```

- Para **SQL Server**, cambia:

```sql
AND o.created_at >= DATEADD(MONTH, -6, GETDATE())
```

- Para **SQL Server**, también cambia `LIMIT 10` por:

