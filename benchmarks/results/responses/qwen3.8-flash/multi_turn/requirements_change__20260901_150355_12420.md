## Flujo actualizado

1. **Gmail Trigger** → recibe emails nuevos
2. **IF** → filtra emails con "propuesta" o "cotizacion" en el asunto
3. **Function** → extrae y normaliza datos del remitente
4. **Notion** → crea una página en una base de datos
5. **Slack** → envía notificación

## Configuración clave

### 1. Gmail Trigger
- **Resource**: Message
- **Operation**: Trigger
- **Query**:
```
subject:propuesta OR subject:cotizacion
```

Con esto Gmail ya filtra desde el origen y reduces nodos innecesarios.

### 2. Function node (extracción de datos)

Usa esto para normalizar los campos:

```javascript
const email = $input.first().json;

const sender = email.headers?.from || email.from || '';
const [senderName, senderEmail] = sender.split('<');

return [{
  json: {
    remitente: senderName ? senderName.replace(/"/g, '').trim() : 'Sin nombre',
    email: senderEmail ? senderEmail.replace('>', '').trim() : sender.trim(),
    asunto: email.subject || '',
    fecha: email.date || new Date().toISOString(),
    messageId: email.id || '',
    snippet: email.snippet || ''
  }
}];
```

### 3. Notion
- **Resource**: Database
- **Operation**: Create Database Item
- **Database ID**: el ID de tu base de datos en Notion

Mapea las propiedades así:

| Propiedad Notion | Valor desde n8n |
|------------------|-----------------|
| Remitente | `{{ $json.remitente }}` |
| Email | `{{ $json.email }}` |
| Asunto | `{{ $json.asunto }}` |
| Fecha | `{{ $json.fecha }}` |

### 4. Slack
- **Resource**: Channel
- **Operation**: Send Message
- **Message**:
```
📩 *Nueva propuesta/cotización recibida*

*Remitente:* {{ $json.remitente }}
*Email:* {{ $json.email }}
*Asunto:* {{ $json.asunto }}
*Fecha:* {{ $json.fecha }}
```

## Cosas a tener en cuenta

- Reemplaza `TU_DATABASE_ID` y `#tu-canal` con tus valores reales.
- Las credenciales de Gmail, Notion y Slack deben estar conectadas en n8n.
- En Notion, la base de datos debe tener las propiedades con exactamente esos nombres (`Remitente`, `Email`, `Asunto`, `Fecha`) o ajusta el mapeo.
- Si quieres filtrar también por cuerpo del email, cambia la query de Gmail por una más amplia y añade un nodo IF después.
