2. **API:** Una API es el ventanero de un mercado que solo acepta pedidos en un formato exacto: si le dices “un pollo, dos kg, a domicilio”, te responde; si le dices “uno” sin medida, no sabe qué hacer. Te da el servicio sin que tengas que entrar a la cocina ni aprender a cocinar.

4. **Rate limit:** El rate limit es el portero de un club que deja entrar 100 personas por hora aunque haya 10.000 con entrada. No es un rechazo: es un ritmo para que la puerta no se rompa y el local no se vuelva una trampa.

5. **Prompt engineering:** El prompt engineering es el director de escena: no actúa, pero decide qué diálogos, tono y restricciones se usan para que el personaje diga lo que necesitas.
