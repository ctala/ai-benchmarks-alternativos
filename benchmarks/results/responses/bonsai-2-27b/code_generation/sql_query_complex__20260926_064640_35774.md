## Respuesta completa



Asumo que:

- “Últimos 6 meses” se filtra con `orders.created_at`.
- El revenue se toma de `orders.total`.
- `categoria_mas_comprada` es la categoría con mayor cantidad total de unidades compradas en esos pedidos completados.
- En caso de empate en categoría, se toma la primera alfabéticamente.
- `total_orders`, `total_revenue` y `avg_order_value` corresponden a los últimos 6 meses y solo pedidos `completed`.

```sql
WITH completed_orders_6m AS (
    SELECT
        o.customer_id,
        o.id AS order_id,
        o.total
    FROM orders o
    WHERE o.status = 'completed'
      AND o.created_at >= CURRENT_DATE - INTERVAL '6 months'
),

customer_totals AS (
    SELECT
        customer_id,
        COUNT(*) AS total_orders,
        SUM(COALESCE(total, 0)) AS total_revenue
    FROM completed_orders_6m
    GROUP BY customer_id
    HAVING COUNT(*) >= 3
),

category_rank AS (
    SELECT
        o.customer_id,
        p.category,
        ROW_NUMBER() OVER (
            PARTITION BY o.customer_id
            ORDER BY SUM(i.quantity) DESC, p.category ASC
        ) AS rn
    FROM completed_orders_6m o
    JOIN order_items i
        ON i.order_id = o.order_id
    JOIN products p
        ON p.id = i.product_id
    GROUP BY o.customer_id, p.category
)

SELECT
    c.name,
    c.email,
    c.country,
    ct.total_orders,
    ct.total_revenue,
    ROUND(
        CAST(ct.total_revenue AS DECIMAL(18,2)) / NULLIF(ct.total_orders, 0),
        2
    ) AS avg_order_value,
    cr.category AS categoria_mas_comprada
FROM customer_totals ct
JOIN customers c
    ON c.id = ct.customer_id
LEFT JOIN category_rank cr
    ON cr.customer_id = ct.customer_id
   AND cr.rn = 1
ORDER BY ct.total_revenue DESC
LIMIT 10;
```
