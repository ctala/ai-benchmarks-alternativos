## Nodo 2 (recomendado): Function – Extraer y Filtrar

**Tipo:** `Code`

```javascript
function extractAndFilter(item) {
  const subject = (item.json.subject || '').toLowerCase();
  const senderName = item.json.sender || '';
  const senderEmail = item.json.from || '';
  const date = item.json.date || '';

  // Filtro: "propuesta" o "cotización" (con y sin tilde)
  const hasProposal = subject.includes('propuesta');
  const hasQuote = subject.includes('cotización') || subject.includes('cotizacion');

  if (!hasProposal && !hasQuote) {
    return []; // Se descarta el email
  }

  return [{
    json: {
      nombreRemitente: senderName,
      emailRemitente: senderEmail,
      asunto: item.json.subject,
      fecha: new Date(date).toISOString(),
      tipo: hasProposal ? 'propuesta' : 'cotizacion',
      cuerpo: item.json.text || item.json.html || ''
    }
  }];
}
```

> Si `sender` no existe, N8N devuelve un objeto vacío. Asegúrate de que el Gmail Trigger esté configurado para incluir `sender` en los campos extraídos.

> 2. Obtén el **Database ID** (lo ves en la URL: `notion.so/abcd1234...`).

### Si no quieres mapear manualmente, usa un sub-nodo `Code` antes de Notion:

```javascript
function mapForNotion(item) {
  const { nombreRemitente, emailRemitente, asunto, fecha, tipo, cuerpo } = item.json;

  return [{
    json: {
      Remitente: { title: nombreRemitente },
      Email: { title: emailRemitente },
      Asunto: { title: asunto },
      Fecha: { date: fecha },
      Tipo: { select: { name: tipo } },
      Estado: { select: { name: 'nuevo' } },
      Cuerpo: { rich_text: [{ text: cuerpo.substring(0, 500) }] }
    }
  }];
}
```

> ⚠️ El formato exacto de las propiedades depende de la **versión del nodo Notion** que tengas instalada. Si el nodo es de la **v2 (Notion API)**, el mapeo es diferente. Asegúrate de usar el nodo correcto.

## Posibles problemas

| Problema | Solución |
|---|---|
| No llega nada a Notion | Revisa el **Database ID** y que el OAuth tenga permisos `pages:write` |
| Slack no envía nada | Verifica que el bot esté agregado al canal y tenga permiso `chat:write` |
| El filtro no captura "cotización" | Asegúrate de incluir la versión sin tilde (`cotizacion`) en el código |
| Los emails llegan duplicados | Aumenta el **polling interval** y usa `Max. Emails: 1` |
