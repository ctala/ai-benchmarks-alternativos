```python
from copy import deepcopy
from typing import List, Dict, Any


def process_orders(orders: List[Dict[str, Any]]) -> Dict[str, Any]:
    """
    Procesa las órdenes pendientes aplicando un descuento del 10% cuando el total supera 100.
    No muta los diccionarios originales y gestiona el caso de que no haya órdenes pendientes.

    Parámetros
    ----------
    orders: lista de diccionarios con al menos las claves 'status' y 'total'.

    Retorna
    -------
    dict con:
        - processed: lista de copias de las órdenes procesadas (con 'final_price' y 'status' actualizado)
        - total: suma de los precios finales de todas las órdenes procesadas
        - average: precio medio (0 si no se procesó ninguna orden)
        - count: número de órdenes procesadas
    """
    total = 0.0
    processed: List[Dict[str, Any]] = []

    for order in orders:
        # Seguridad: si alguna orden no tiene las claves esperadas la ignoramos.
        if order.get('status') != 'pending' or 'total' not in order:
            continue

        # Copiamos el diccionario para no mutar el original.
        order_copy = deepcopy(order)

        # Cálculo del descuento.
        discount = order_copy['total'] * 0.1 if order_copy['total'] > 100 else 0.0
        final_price = order_copy['total'] - discount

        # Actualizamos la copia.
        order_copy['final_price'] = final_price
        order_copy['status'] = 'processed'

        # Acumulamos resultados.
        total += final_price
        processed.append(order_copy)

    # Evitamos división por cero.
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)          # ahora refleja cuántas órdenes fueron procesadas
    }
```

### Qué se ha cambiado y por qué

1. **Prevención de división por cero**  
   ```python
   average = total / len(processed) if processed else 0.0
   ```
   Si `processed` está vacío, el promedio se define como `0.0` y no se lanza excepción.

2. **No mutar los objetos de entrada**  
   - Se usa `deepcopy(order)` para crear una copia independiente antes de modificarla.  
   - La lista `processed` contiene esas copias, por lo que la lista y los diccionarios originales que recibió la función permanecen intactos.

3. **`count` correcto**  
   ```python
   'count': len(processed)
   ```
   Ahora indica cuántas órdenes fueron realmente procesadas.

4. **Validación mínima de datos**  
   - `order.get('status') != 'pending'` y `if 'total' not in order` evitan `KeyError`.  
   - Si una orden es inválida simplemente se ignora, lo que hace a la función más tolerante.

5. **Tipado y documentación**  
   - Se añaden anotaciones de tipos (`List[Dict[str, Any]]`) y una docstring explicativa, lo que facilita el mantenimiento y la autogeneración de documentación.

6. **Uso de valores flotantes**  
   - `total`, `discount` y `final_price` se inicializan como `float` para evitar mezclas inesperadas de `int`/`float` en cálculos posteriores.

Con estos ajustes la función es **segura**, **predecible** y **no tiene efectos colaterales** sobre los datos que recibe. Además, el resultado ahora refleja fielmente la información que el cliente de la función espera.
