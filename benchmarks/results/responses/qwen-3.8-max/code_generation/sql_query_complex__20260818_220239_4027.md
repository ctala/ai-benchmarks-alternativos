- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada

## Respuesta completa

Aquí tienes una query que cumple lo que pides. Estoy asumiendo que:

- El revenue se calcula con `orders.total`.
- Solo se consideran órdenes `status = 'completed'` de los últimos 6 meses.
- `total_orders` cuenta las órdenes completadas en ese periodo.
- `categoria_mas_comprada` se define como la categoría con más unidades compradas (`SUM(order_items.quantity)`).

```sql
WITH completed_orders_last_6m AS (
    SELECT
        id,
        customer_id,
        total
    FROM orders
    WHERE status = 'completed'
      AND created_at >= CURRENT_DATE - INTERVAL '6' MONTH
      -- En MySQL puedes usar: DATE_SUB(CURDATE(), INTERVAL 6 MONTH)
      -- En SQL Server: DATEADD(MONTH, -6, GETDATE())
),

customer_metrics AS (
    SELECT
        customer_id,
        COUNT(*) AS total_orders,
        SUM(total) AS total_revenue,
        CAST(SUM(total) AS DECIMAL(18, 2)) / NULLIF(COUNT(*), 0) AS avg_order_value
    FROM completed_orders_last_6m
    GROUP BY customer_id
    HAVING COUNT(*) >= 3
),

category_totals AS (
    SELECT
        o.customer_id,
        p.category,
        SUM(oi.quantity) AS units_bought,
        SUM(oi.quantity * oi.unit_price) AS category_revenue
    FROM completed_orders_last_6m o
    JOIN order_items oi
      ON oi.order_id = o.id
    JOIN products p
      ON p.id = oi.product_id
    GROUP BY
        o.customer_id,
        p.category
),

ranked_categories AS (
    SELECT
        customer_id,
        category AS categoria_mas_comprada,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY units_bought DESC, category_revenue DESC, category
        ) AS rn
    FROM category_totals
)

SELECT
    c.name AS nombre,
    c.email,
    c.country AS pais,
    cm.total_orders,
    cm.total_revenue,
    cm.avg_order_value,
    tc.categoria_mas_comprada
FROM customer_metrics cm
JOIN customers c
  ON c.id = cm.customer_id
LEFT JOIN ranked_categories tc
  ON tc.customer_id = cm.customer_id
 AND tc.rn = 1
ORDER BY cm.total_revenue DESC
LIMIT 10;
```

Notas importantes:

- Si quieres que `categoria_mas_comprada` se calcule por revenue en vez de por unidades, cambia en `ranked_categories`:

```sql
ORDER BY category_revenue DESC, units_bought DESC, category
```

- Si las “al menos 3 órdenes completadas” deben ser históricas y no necesariamente dentro de los últimos 6 meses, entonces el filtro `HAVING COUNT(*) >= 3` debería aplicarse sobre todas las órdenes completadas del cliente, no solo sobre `completed_orders_last_6m`.
