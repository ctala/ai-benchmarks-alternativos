**system:**

Eres un asistente tecnico para emprendedores que trabajan con N8N.

Necesito un workflow en N8N que lea emails de Gmail, extraiga los datos del remitente, y los guarde en un Google Sheet.

1. **Trigger**: Gmail Trigger (se activa con cada email nuevo)
2. **Extraer datos**: Function node para parsear remitente, asunto, fecha

En realidad, cambio de idea. No quiero Google Sheets, quiero que los datos vayan a Notion. Ademas, quiero que el workflow filtre solo los emails que tengan la palabra 'propuesta' o 'cotizacion' en el asunto. Y que me mande una notificacion a Slack cuando llegue uno.


## Respuesta completa

Perfecto. Te dejo un workflow en N8N con esta lógica:

```text
Gmail Trigger
   ↓
Code: extraer y normalizar datos del email
   ↓
Filter / IF: solo si el asunto contiene “propuesta” o “cotización”
   ↓
Notion: crear página con los datos
   ↓
Slack: enviar notificación
```

La idea es que cuando llegue un email a Gmail cuyo asunto tenga `propuesta` o `cotizacion`, N8N guarde los datos en Notion y luego te avise por Slack.

## 3. Workflow en N8N

### Nodo 1: Gmail Trigger

Agrega el nodo:

```text
Gmail Trigger
```

Configuración recomendada:

- Credential: tu credencial de Google OAuth2.
- Trigger / Event: `New Email`, `Message Received` o similar, según tu versión de N8N.
- Opcional: filtrar solo emails de la carpeta `INBOX`.

Este nodo se ejecutará cuando llegue un nuevo correo.

---

### Nodo 2: Code

Agrega un nodo:

```text
Code
```

Modo:

```text
Run Once for All Items
```

Pega este código:

```javascript
const items = $input.all();

const normalize = (text = '') =>
  text
    .toString()
    .toLowerCase()
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '');

return items.map(item => {
  const headers = item.json?.payload?.headers || [];

  const getHeader = name => {
    const header = headers.find(
      h => (h.name || '').toLowerCase() === name.toLowerCase()
    );
    return header?.value || '';
  };

  const from = getHeader('From');
  const subjectRaw = getHeader('Subject');
  const dateHeader = getHeader('Date');

  const nameMatch = from.match(/^\s*"?([^"<]*?)"?\s*<([^>]+)>/);

  const senderEmail = (nameMatch?.[2] || from || '').trim();

  const senderName =
    (nameMatch?.[1] || '')
      .trim()
      .replace(/^"+|"+$/g, '') ||
    senderEmail ||
    'Desconocido';

  const subject = subjectRaw || '(sin asunto)';

  let receivedAt = new Date().toISOString();

  if (dateHeader) {
    const parsedDate = new Date(dateHeader);
    if (!Number.isNaN(parsedDate.getTime())) {
      receivedAt = parsedDate.toISOString();
    }
  }

  const normalizedSubject = normalize(subject);

  const isRelevant =
    normalizedSubject.includes('propuesta') ||
    normalizedSubject.includes('cotizacion');

  return {
    json: {
      senderName,
      senderEmail,
      subject,
      receivedAt,
      isRelevant,
      snippet: item.json?.snippet || '',
      gmailId: item.json?.id || '',
    },
  };
});
```

Este nodo hace varias cosas:

- Extrae el nombre del remitente.
- Extrae el email del remitente.
- Extrae el asunto.
- Extrae la fecha.
- Normaliza el asunto para que detecte:
  - `propuesta`
  - `Propuesta`
  - `PROPUESTA`
  - `cotización`
  - `Cotización`
  - `cotizacion`
  - `COTIZACION`
- Genera un campo booleano llamado `isRelevant`.

### Nodo 3: Filter o IF

Agrega un nodo:

```text
Filter
```

o también puedes usar:

```text
IF
```

La condición debe ser:

```text
isRelevant equals true
```

Si usas el nodo **Filter**, puedes poner una condición tipo Boolean:

```text
Value: {{ $json.isRelevant }}
Equals: true
```

Si usas el nodo **IF**, puedes configurarlo así:

```text
Value 1: {{ $json.isRelevant }}
Operation: Equal
Value 2: true
```

La salida `true` continúa hacia Notion.

La salida `false` puede quedar vacía o conectarse a un nodo de finalización.

## 4. Conexión final de nodos

El workflow debe quedar así:

```text
Gmail Trigger
   ↓
Code
   ↓
Filter / IF
   ↓ true
Notion
   ↓
Slack
```

Si usas nodo `IF`:

```text
Gmail Trigger
   ↓
Code
   ↓
IF
   ├─ true → Notion → Slack
   └─ false → sin salida
```

## 6. Detalle importante con Gmail

Algunos triggers de Gmail devuelven solo información básica del mensaje. Si al probar ves que el nodo `Code` no encuentra `payload.headers`, entonces agrega después del `Gmail Trigger` un nodo:

```text
Gmail
```

Con operación:

```text
Get
```

Y usa el ID del mensaje para obtener el email completo.

La estructura sería:

```text
Gmail Trigger
   ↓
Gmail: Get Message
   ↓
Code
   ↓
Filter
   ↓
Notion
   ↓
Slack
```

En ese caso, en el nodo `Gmail` usarías algo como:

```text
Message ID: {{ $json.id }}
```

Y luego el nodo `Code` trabajaría con la respuesta completa del correo.

## 8. Opcional: notificar aunque falle Notion

Si quieres que Slack avise aunque Notion falle, puedes hacerlo de dos formas:

### Opción A

Conectar el filtro directamente a Slack y también a Notion:

```text
Filter
   ├─ Slack
   └─ Notion
```

### Opción B

Dejar:

```text
Filter → Notion → Slack
```

Pero activar en el nodo de Notion la opción:

```text
Continue On Fail
```

Así el workflow sigue aunque Notion dé error.
