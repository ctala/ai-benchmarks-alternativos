## Respuesta completa

1. **Cómo funciona un modelo de lenguaje (LLM)**  
Un LLM aprende patrones del lenguaje a partir de enormes cantidades de texto y genera respuestas prediciendo qué palabras encajan mejor. Es como un catador ciego que probó millones de recetas: con solo oler el principio de tu plato, intuye qué ingrediente debería venir y te sirve una versión plausible. Cocina rápido, pero no siempre sabe si la receta es verdadera.

2. **Qué es una API**  
Una API es un punto de acceso con reglas claras que permite que tu producto use capacidades de otro sistema sin tocar su interior. Es como el conserje de un hotel con llaves maestras: tú no entras a la cocina ni a la caldera; le pides un servicio por la ventanilla y él te lo trae. Si el conserje cambia de uniforme, tu forma de pedir puede seguir siendo la misma.

3. **Qué es el fine-tuning de un modelo**  
El fine-tuning toma un modelo ya entrenado y lo ajusta con ejemplos específicos para que se comporte mejor en tu caso de uso. Es como un perro rastreador que ya sabe buscar, pero lo entrenan para encontrar trufas en tu finca y responder a tus señales. No le enseñas a olfatear desde cero; le enseñas tu negocio.

4. **Qué es un rate limit**  
Un rate limit es un tope de solicitudes permitidas en un periodo de tiempo para proteger la estabilidad del servicio. Es como la freidora de un restaurante: aunque haya cien pedidos, solo puede sacar diez porciones por minuto sin quemar el aceite ni arruinar la calidad. Si llegan más, toca esperar o rechazar pedidos.

5. **Qué es el prompt engineering**  
El prompt engineering es el arte de escribir instrucciones y contexto para que el modelo entregue exactamente lo que necesitas. Es como darle un molde a un pastelero con masa infinita: la masa puede ser la misma, pero la forma, el tamaño y las indicaciones deciden si sale un oso, una estrella o un desastre. Cuanto mejor sea el molde, más útil será el resultado.
