## Respuesta completa

El bug sutil está en el caso en que **`mad` vale `0`**.

En concreto, el código no maneja el caso:

```python
threshold = 3 * mad
```

si `mad == 0`, entonces:

```python
threshold == 0
```

y el filtro:

```python
filtered = [x for x in data if abs(x - median) <= threshold]
```

se convierte en:

```python
abs(x - median) <= 0
```

que solo se cumple cuando `x` es exactamente igual a la mediana.

---

## Cuándo falla exactamente

Falla cuando **más de la mitad de los valores son iguales a la mediana** y hay al menos algún valor distinto.

Ejemplo:

```python
data = [1, 1, 1, 2]
```

Paso a paso:

```python
median = find_median([1, 1, 1, 2])
```

La lista ordenada es:

```python
[1, 1, 1, 2]
```

Como `n = 4`, la mediana es:

```python
(1 + 1) / 2 = 1.0
```

Luego calcula las desviaciones absolutas:

```python
[abs(1 - 1.0), abs(1 - 1.0), abs(1 - 1.0), abs(2 - 1.0)]
```

o sea:

```python
[0.0, 0.0, 0.0, 1.0]
```

La mediana de esas desviaciones es:

```python
mad = 0.0
```

Entonces:

```python
threshold = 3 * 0.0 = 0.0
```

Y el filtro solo conserva los valores cuya distancia a la mediana sea `0`:

```python
filtered = [1, 1, 1]
```

El `2` se elimina, aunque no sea necesariamente un outlier extremo.

El resultado final es:

```python
sum([1, 1, 1]) / len([1, 1, 1]) = 1.0
```

cuando quizás debería haber considerado el `2`.

---

## Por qué es un bug

La MAD —median absolute deviation— mide la dispersión de los datos respecto a la mediana. Si la mayoría de los datos son idénticos, la MAD puede ser `0`.

Cuando eso pasa, el umbral:

```python
threshold = 3 * mad
```

también es `0`, y el filtro se degenera: cualquier valor que no sea exactamente igual a la mediana se trata como outlier, aunque esté muy cerca.

Es decir, el código no distingue entre:

```python
[1, 1, 1, 2]
```

y

```python
[1, 1, 1, 1000000]
```

En ambos casos, si `mad == 0`, elimina todos los valores distintos de la mediana.

---

## Condición exacta

Para datos numéricos normales, `mad == 0` ocurre cuando hay una **mayoría estricta** de valores iguales a la mediana.

Por ejemplo:

```python
[5, 5, 5, 6]
[1, 1, 1, 1, 2]
[7, 7, 7, 7, 7, 8]
```

Si todos los valores son iguales, el problema no se nota:

```python
[5, 5, 5]
```

devuelve `5.0`, que es correcto.

El bug se manifiesta cuando hay mayoría de valores iguales **y además algún valor diferente**.

## Nota adicional

Hay otro caso límite más obvio: si `data` está vacía,

```python
len(data) < 3
```

entra en:

```python
return sum(data) / len(data)
```

y hace:

```python
sum([]) / len([])
```

o sea:

```python
0 / 0
```

lo que lanza `ZeroDivisionError`.

Pero el bug sutil de la lógica de eliminación de outliers es el caso `mad == 0`.
