# El bug: la MAD puede valer 0

El problema aparece cuando **más de la mitad de los valores son idénticos**. En ese caso la mediana de las desviaciones (MAD) es `0`, el umbral es `0`, y el filtro elimina **todo valor que no sea exactamente igual a la mediana**, aunque sea perfectamente normal.

## Ejemplo concreto

```python
remove_outliers_and_average([10, 10, 10, 10.1, 9.9])
```

Paso a paso:

1. `median = 10`
2. Desviaciones: `[0, 0, 0, 0.1, 0.1]`, ordenadas `[0, 0, 0, 0.1, 0.1]`
3. `mad = 0` (el elemento central es 0)
4. `threshold = 3 * 0 = 0`
5. `filtered = [10, 10, 10]`, porque 10.1 y 9.9 tienen desviación 0.1, que es mayor que 0
6. Resultado: `10.0`

9.9 y 10.1 no son outliers, pero se descartan. El código no lanza ningún error y devuelve un número creíble, así que el fallo pasa desapercibido.

Otros ejemplos:
- `[1, 2, 2, 2, 3]` devuelve `2.0`. Se tiran el 1 y el 3.
- `[0, 0, 0, 0, 1, 2, 3]` devuelve `0.0`, cuando la media real es aproximadamente 0.86 y no hay outliers.

## Cuándo ocurre exactamente

`mad == 0` sucede cuando al menos la mitad de las desviaciones son 0, es decir, cuando la mitad o más de los datos coincide exactamente con la mediana:
- **n impar**: al menos `n//2 + 1` valores iguales.
- **n par**: los dos centrales de las desviaciones ordenadas deben ser 0, lo que requiere al menos `n//2 + 1` valores iguales a la mediana.

Es típico en datos reales discretizados o redondeados: lecturas de sensores, puntuaciones enteras, precios repetidos, o muchos ceros.

Curiosamente, `filtered` **nunca queda vacío**. Siempre quedan al menos los valores iguales a la mediana, y con `mad > 0` al menos la mitad cumple `desviación ≤ mad ≤ 3·mad`. Por eso no hay `ZeroDivisionError` en esa línea, y el bug es silencioso.

## Bug secundario: lista vacía

## Corrección posible

```python
def remove_outliers_and_average(data):
    if not data:
        raise ValueError("data no puede estar vacío")
    if len(data) < 3:
        return sum(data) / len(data)

    median = find_median(data)
    mad = find_median([abs(x - median) for x in data])

    if mad == 0:
        # La MAD no sirve como medida de dispersión aquí.
        # Opción: usar la desviación absoluta media como respaldo.
        mean_ad = sum(abs(x - median) for x in data) / len(data)
        if mean_ad == 0:
            return median  # todos los valores son iguales
        threshold = 3 * mean_ad
    else:
        threshold = 3 * 1.4826 * mad  # MAD escalada (equivale a ~σ en datos normales)

    filtered = [x for x in data if abs(x - median) <= threshold]
    return sum(filtered) / len(filtered)
```

El factor `1.4826` no corrige el bug, pero es la forma estándar de que `3·MAD` equivalga aproximadamente a "3 desviaciones típicas". Sin él, el criterio original es más agresivo de lo que parece.
