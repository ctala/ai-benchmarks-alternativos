## Respuesta completa

Así queda el workflow actualizado:

```
Gmail Trigger → Filter (asunto) → Edit Fields (extraer datos) → Notion (crear página) → Slack (notificar)
```

## 1. Gmail Trigger

- **Poll Times**: cada minuto (o el intervalo que prefieras)
- **Event**: Message Received
- **Simplify**: **desactivado**, para tener el nombre y el email del remitente por separado
- **Credenciales**: Gmail OAuth2

## 2. Filter: solo "propuesta" o "cotización"

Usa un nodo **Filter** con esta condición:

- **Value 1** (expresión):
  ```
  {{ /propuesta|cotizaci[oó]n/i.test($json.subject ?? '') }}
  ```
- **Operación**: Boolean → `is true`

Esta expresión:
- No distingue mayúsculas de minúsculas ("PROPUESTA", "Propuesta")
- Acepta "cotizacion" con y sin tilde
- Detecta también plurales ("propuestas", "cotizaciones")

## 3. Edit Fields: extraer datos

Nodo **Edit Fields (Set)** con estos campos:

| Campo | Valor (expresión) |
|---|---|
| `nombre` | `{{ $json.from.value[0].name \|\| $json.from.value[0].address }}` |
| `email` | `{{ $json.from.value[0].address }}` |
| `asunto` | `{{ $json.subject }}` |
| `fecha` | `{{ $json.date }}` |
| `extracto` | `{{ ($json.text ?? '').substring(0, 500) }}` |

Si el remitente no tiene nombre, se usa su email.

## 4. Notion: crear página en una base de datos

**Antes de configurar el nodo:**
1. Crea una base de datos en Notion con estas propiedades:
   - **Nombre** → Title
   - **Email** → Email
   - **Asunto** → Text
   - **Fecha** → Date
   - **Estado** → Select (opcional, por ejemplo "Nuevo", "Respondido")
2. Crea una integración en [notion.so/my-integrations](https://www.notion.so/my-integrations) y copia el token.
3. En la base de datos, ve a **"..." → Connections** y agrega tu integración. Si omites este paso, n8n no encontrará la base de datos (es el error más común).

**Configuración del nodo:**
- **Resource**: Database Page
- **Operation**: Create
- **Database**: selecciona tu base de datos
- **Properties**: mapea cada propiedad con `{{ $json.nombre }}`, `{{ $json.email }}`, etc.
- Si quieres guardar el extracto del email, agrégalo en **Blocks** como párrafo.

## 5. Slack: notificación

- **Resource**: Message → **Operation**: Send
- **Channel**: por ejemplo `#ventas`
- **Text**:
  ```
  📩 *Nuevo email de {{ $('Edit Fields').item.json.nombre }}*
  *Email:* {{ $('Edit Fields').item.json.email }}
  *Asunto:* {{ $('Edit Fields').item.json.asunto }}
  🔗 <{{ $json.url }}|Ver en Notion>
  ```

Uso `$('Edit Fields')` porque, después del nodo de Notion, `$json` contiene la respuesta de Notion y no los datos del email. A cambio, puedes usar `$json.url` para incluir el enlace directo a la página creada.

**Credenciales de Slack:** tu app necesita el permiso `chat:write`, y debes invitar al bot al canal con `/invite @tubot`.

## Consejos adicionales

- **Rendimiento:** si recibes muchos emails, agrega un filtro en el Gmail Trigger (**Filters → Search**) con `subject:(propuesta OR cotizacion OR cotización)`. Así el filtro se aplica en Gmail y n8n procesa menos datos. Conserva igualmente el nodo Filter como respaldo.
- **Orden:** con Slack después de Notion, solo recibes la notificación si el registro se guardó correctamente.
