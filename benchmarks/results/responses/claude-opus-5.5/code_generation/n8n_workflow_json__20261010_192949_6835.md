## Cómo usarlo

**1. Importar**
En n8n, crea un workflow nuevo, haz clic en los tres puntos (⋯) y elige **Import from File**. También puedes pegar el JSON directamente en el lienzo con `Ctrl+V`.

**2. Configurar credenciales**
- **OpenAI**: abre el nodo "Clasificar con OpenAI" y selecciona o crea tu credencial con tu API key.
- **Slack**: en los 3 nodos de Slack, selecciona tu credencial. El bot necesita el scope `chat:write` y debe estar invitado a los canales `#support`, `#sales` y `#general` (en cada canal, ejecuta `/invite @tu-bot`).

**3. Probar**
```bash
curl -X POST https://TU-N8N/webhook-test/clasificar-mensaje \
  -H "Content-Type: application/json" \
  -d '{"email": "cliente@ejemplo.com", "message": "Hola, quiero saber el precio del plan empresarial"}'
```
Este mensaje debería llegar a `#sales`.

> Usa `/webhook-test/` mientras pruebas con el botón "Test workflow". Cuando actives el workflow, cambia a `/webhook/`.

## Detalles de diseño

- **`temperature: 0` y `maxTokens: 5`**: hacen que la clasificación sea determinista y que la respuesta sea solo una palabra.
- **Nodo "Normalizar Categoría"**: limpia la respuesta de la IA (mayúsculas, puntos, espacios). Si el modelo devuelve algo inesperado, asigna `otro` por defecto, así ningún mensaje se pierde.
- **Recuperación de datos originales**: el nodo de OpenAI reemplaza el JSON de salida, así que el nodo Code recupera `email` y `message` desde "Extraer Datos".

Si tu versión de n8n es antigua y el nodo de OpenAI no carga correctamente, puedes reemplazarlo por un nodo **HTTP Request** contra `https://api.openai.com/v1/chat/completions`. En ese caso, la normalización debe leer `choices[0].message.content` en lugar de `message.content`.
