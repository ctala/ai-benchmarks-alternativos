### 🔍 Análisis de los Bugs

1. **División por cero (`ZeroDivisionError`)**
   - **Causa:** Si ninguna orden tiene el estado `'pending'`, la lista `processed` queda vacía. Al ejecutar `average = total / len(processed)`, Python intenta dividir por `0`, lo que lanza una excepción.
   - **Solución:** Verificar si hay órdenes procesadas antes de dividir, o usar un operador condicional para asignar `0.0` cuando el contador es `0`.

2. **Mutación del diccionario original (Side Effect)**
   - **Causa:** En Python, las listas almacenan referencias a objetos. Al hacer `order['final_price'] = ...` y `order['status'] = ...`, se modifican directamente los diccionarios dentro de la lista `orders` que se pasó como argumento. Esto es peligroso porque altera datos que podrían estar siendo usados en otras partes del programa.
   - **Solución:** Trabajar con una copia independiente de cada diccionario (`order.copy()` o `dict(order)`) antes de modificarlo y añadirlo a `processed`.

3. **Contador incorrecto (`'count'`)**
   - **Causa:** El retorno usa `len(orders)`, que cuenta **todas** las órdenes recibidas, incluidas las que no se procesaron (ej. `'shipped'`, `'cancelled'`, etc.). Lógicamente, `'count'` debe reflejar cuántas órdenes se procesaron en realidad.
   - **Solución:** Usar `len(processed)` para el campo `'count'`.

```python
def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        if order['status'] == 'pending':
            # 1. Crear una copia para evitar mutar el diccionario original
            processed_order = order.copy()
            
            discount = processed_order['total'] * 0.1 if processed_order['total'] > 100 else 0
            final_price = processed_order['total'] - discount
            
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'
            
            total += final_price
            processed.append(processed_order)

    # 2. Contador correcto y protección contra división por cero
    count = len(processed)
    average = total / count if count > 0 else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count  # 3. Ahora refleja solo las órdenes realmente procesadas
    }
```
