# Análisis y Corrección de Bugs en `process_orders()`

A continuación se detallan los tres bugs identificados en el código, su explicación y una versión corregida.

---

## 🐛 Bug 1: Posible división por cero

**Problema:**
```python
average = total / len(processed)
```
Si ninguna orden tiene `'status': 'pending'`, entonces `processed` será una lista vacía (`len(processed) == 0`) y esta operación provocará un error `ZeroDivisionError`.

**Solución:**
Verificar si `processed` está vacío antes de calcular el promedio. Si está vacío, devolver `0` o `None` para evitar el error.

---

## 🐛 Bug 2: Mutación del diccionario original

**Problema:**
```python
order['final_price'] = final_price
order['status'] = 'processed'
```
Estas líneas modifican directamente el objeto `order` recibido en la lista de entrada. Esto altera datos externos al alterar el estado de los diccionarios originales, lo cual es una mala práctica.

**Solución:**
Crear una copia profunda de cada orden antes de modificarla, utilizando `copy.deepcopy(order)`, para evitar mutaciones no deseadas.

---

## 🐛 Bug 3: Contador incorrecto

**Problema:**
```python
'count': len(orders)
```
Este campo indica el número total de órdenes recibidas, no el número de órdenes realmente procesadas.

**Solución:**
Cambiarlo a `len(processed)` para reflejar correctamente cuántas órdenes fueron procesadas.

## ✅ Versión Corregida del Código

```python
import copy

def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        if order.get('status') == 'pending':
            discount = order['total'] * 0.1 if order.get('total', 0) > 100 else 0
            final_price = order['total'] - discount
            
            # Crear una copia profunda para evitar mutar el original
            processed_order = copy.deepcopy(order)
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'
            
            total += final_price
            processed.append(processed_order)

    # Calcular promedio seguro contra división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Corregido
    }
```
