## Respuesta completa

1. **Cómo funciona un modelo de lenguaje (LLM)**  
Un LLM analiza el contexto y calcula qué fragmento de texto tiene más probabilidad de venir después, una y otra vez, hasta formar una respuesta. Es como un restaurador de mosaicos que ha visto millones de murales: observa las piezas ya puestas y elige la siguiente tesela que mejor encaja con el patrón, aunque no “vea” la imagen como una persona.

2. **Qué es una API**  
Una API es una forma estandarizada para que dos sistemas se pidan cosas y se entreguen resultados sin revelar toda su maquinaria interna. Es como el panel de un ascensor de carga: tú pulsas “planta 7” siguiendo un formato concreto, y el edificio mueve todo por dentro sin que tengas que entrar al cuarto de motores.

3. **Qué es el fine-tuning de un modelo**  
El fine-tuning ajusta un modelo ya entrenado con ejemplos específicos para que adopte mejor un estilo, tarea o conocimiento de un sector. Es como contratar una orquesta excelente para un circo: ya saben tocar, pero ensayan las rutinas concretas hasta aprender cuándo acelerar, cuándo callar y qué tono usar en cada número.

4. **Qué es un rate limit**  
Un rate limit pone un máximo de solicitudes que alguien puede hacer durante un periodo para evitar saturación, abusos o costes descontrolados. Es como una fuente pública con un grifo temporizado: todos pueden llenar su botella, pero nadie puede dejar el grifo abierto toda la tarde y secar el agua para los demás.

5. **Qué es el prompt engineering**  
El prompt engineering consiste en diseñar instrucciones, contexto, restricciones y formato para obtener mejores resultados de un modelo. Es como preparar la hoja de rodaje para un equipo de especialistas: no basta con decir “haz una escena de acción”; debes indicar el lugar, el objetivo, los límites de seguridad y cómo quieres recibir la toma final.
