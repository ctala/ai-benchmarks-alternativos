## Los tres bugs

**1. División por cero**

Si `orders` está vacía, o si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía y esta línea lanza `ZeroDivisionError`:

```python
average = total / len(processed)  # len(processed) == 0
```

La corrección es proteger el cálculo: `total / len(processed) if processed else 0`. Devolver `0` es una decisión razonable; si prefieres distinguir "no hay datos" de "el promedio es cero", puedes devolver `None`.

**2. Muta el diccionario original**

Los diccionarios son mutables y `order` es una referencia al mismo objeto que está dentro de la lista del llamador. Estas dos líneas modifican los datos de quien invoca la función:

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

Además del efecto colateral inesperado, hay una consecuencia práctica: si llamas a `process_orders(orders)` dos veces con la misma lista, la segunda vez ya no hay órdenes `pending`, así que procesa cero. La corrección es trabajar sobre una copia (`order.copy()`) y añadir esa copia a `processed`. Como aquí solo modificamos claves de primer nivel, una copia superficial basta; si modificaras estructuras anidadas, necesitarías `copy.deepcopy`.

**3. `count` incorrecto**

`count: len(orders)` cuenta todas las órdenes recibidas, incluidas las que no estaban pendientes, mientras que `processed`, `total` y `average` solo reflejan las procesadas. Es inconsistente: podrías obtener `count: 5` con `processed` vacío. Debe ser `len(processed)`. Si algún día necesitas el total recibido, mejor exponerlo con otro nombre, por ejemplo `received`.

## Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            # Copia: el diccionario original no se modifica
            new_order = order.copy()

            discount = new_order['total'] * 0.1 if new_order['total'] > 100 else 0
            final_price = new_order['total'] - discount

            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            total += final_price
            processed.append(new_order)

    # Evita ZeroDivisionError cuando no hay órdenes procesadas
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed),
    }
```
