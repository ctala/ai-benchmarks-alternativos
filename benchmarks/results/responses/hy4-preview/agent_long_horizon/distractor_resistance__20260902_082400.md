### 2. Ejemplo de costeo unitario (para una caja individual)

| Concepto | Costo (ejemplo en USD) |
|---|---|
| Materia prima (té + ingredientes) | $1.20 |
| Sobres / envoltura individual | $0.30 |
| Etiqueta | $0.15 |
| Caja / estuche | $0.80 |
| Mano de obra / armado | $0.50 |
| Flete y logística | $0.60 |
| Comisión de venta (si aplica) | $0.90 |
| Merma (5%) | $0.20 |
| **Costo total unitario** | **$4.65** |
| **Margen deseado** | **60%** |
| **Precio de venta sugerido** | **$4.65 / (1 - 0.60) = $11.63 → $11.99** |

> Fórmula: **Precio de venta = Costo total / (1 - margen deseado)**

## Plantillas y herramientas para el Hito 2

### 1. Declaración de marca
Fórmula:  
**“Ofrezco [producto] para [público] que busca [beneficio], a través de [diferencial].”**

Ejemplo:  
*“Tés artesanales de hoja suelta para personas que quieren convertir una pausa diaria en un ritual consciente, con mezclas premium en empaques compostables.”*

### 2. Naming de los 4 sabores
Estructura sugerida:  
**[Nombre evocador] – [Tipo de té] con [nota principal]**

Ejemplos:
1. **Bosque de Niebla** – Té verde con jazmín y manzanilla.
2. **Atardecer Andino** – Té negro con cáscara de naranja y especias.
3. **Jardín de Lluvia** – Té blanco con pétalos de rosa y frambuesa.
4. **Raíz Serena** – Infusión herbal sin teína con manzanilla, lavanda y melisa.

### 3. Ficha de venta por SKU
Redacta una ficha por presentación usando esta estructura:

- **Titular:** Nombre + descriptor.
- **Ritual / historia corta:** 2–3 líneas que conecten con el momento de consumo.
- **Notas de cata:** aroma, sabor y final.
- **Ingredientes:** lista clara y sin abreviaturas raras.
- **Modo de preparación:** temperatura y tiempo exactos.
- **Presentación:** peso neto y número de sobres.
- **Diferencial:** hoja entera, empaque compostable, edición pequeña, etc.
- **Precio.**

### 4. Estrategia de precios
En la Semana 1 hiciste el costeo base. Ahora defines la **estrategia comercial**:

**Fórmula:**  
**Precio de venta = Costo total unitario / (1 - margen deseado)**

Ejemplo:  
Costo total = $5.00 USD · Margen deseado = 65%  
Precio = $5.00 / (1 - 0.65) = $14.28 → precio sugerido **$14.50** o **$14.99**.

**Estructura recomendada:**

| Presentación | Estrategia de precio |
|---|---|
| **Caja individual** | Precio base con buen margen; es la entrada más accesible. |
| **Pack descubrimiento (4 sabores)** | 10–15% más económico que comprar las 4 cajas sueltas; incentiva la prueba. |
| **Suscripción mensual** | 5–10% de descuento + envío gratis; genera ingreso recurrente. |

Consejo de psicología de precios: usa terminaciones en **.90, .95 o .99** y muestra el ahorro del pack descubrimiento en valor absoluto (“Ahorras $X”).

- **Logo:** versión principal y versión reducida.
- **Paleta:** 3–5 colores (ej: verde salvia, terracota, crema, gris carbón).
- **Tipografías:** una elegante para títulos y una legible para cuerpo.
- **Aplicaciones:** etiqueta, caja, plantilla de Instagram, tarjeta de agradecimiento.
