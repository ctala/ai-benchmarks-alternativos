# 3. Nodo Code: extraer y filtrar

Agrega un nodo **Code**.

Nombre recomendado:

```text
Extraer y filtrar
```

Modo:

```text
Run Once for All Items
```

Pega este código:

```javascript
const items = $input.all();
const output = [];

const parseFrom = (value) => {
  if (!value) return { name: '', email: '' };

  if (typeof value === 'object') {
    return {
      name: value.name || value.displayName || '',
      email: value.email || value.address || value.value || '',
    };
  }

  const str = String(value).trim();

  const angle = str.match(/^(.*?)<([^>]+)>/);
  if (angle) {
    return {
      name: angle[1].replace(/["']/g, '').trim(),
      email: angle[2].trim(),
    };
  }

  const emailMatch = str.match(/[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}/i);
  return {
    name: '',
    email: emailMatch ? emailMatch[0] : str,
  };
};

const getHeader = (headers, name) => {
  if (!Array.isArray(headers)) return '';

  const target = String(name).toLowerCase();
  const header = headers.find(
    (h) => String(h?.name || '').toLowerCase() === target
  );

  return header?.value || '';
};

for (const item of items) {
  const data = item.json || {};
  const headers = data.payload?.headers || [];

  const subjectRaw =
    data.subject ??
    data.Subject ??
    getHeader(headers, 'Subject');

  const subject = String(subjectRaw || 'Sin asunto').trim();

  const fromRaw =
    data.from ??
    data.From ??
    getHeader(headers, 'From');

  const parsedFrom = parseFrom(fromRaw);

  const fromEmail = parsedFrom.email
    ? String(parsedFrom.email).trim()
    : null;

  const fromName = parsedFrom.name
    ? String(parsedFrom.name).trim()
    : fromEmail
      ? fromEmail.split('@')[0]
      : 'Desconocido';

  const rawDate =
    data.date ??
    data.Date ??
    data.internalDate ??
    getHeader(headers, 'Date');

  let receivedAt;

  try {
    receivedAt = rawDate
      ? new Date(rawDate).toISOString()
      : new Date().toISOString();
  } catch (error) {
    receivedAt = new Date().toISOString();
  }

  const normalizedSubject = subject
    .toLowerCase()
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '');

  const matches = /propuesta|cotizacion/.test(normalizedSubject);

  if (matches) {
    output.push({
      json: {
        fromName,
        fromEmail,
        subject,
        receivedAt,
        source: 'Gmail',
        matchType: normalizedSubject.includes('propuesta')
          ? 'propuesta'
          : 'cotizacion',
      },
    });
  }
}

return output;
```

Este nodo hace tres cosas:

1. Extrae:
   - nombre del remitente
   - email del remitente
   - asunto
   - fecha

2. Normaliza el asunto para que coincida con:
   - `propuesta`
   - `Propuesta`
   - `PROPUESTA`
   - `cotizacion`
   - `cotización`
   - `Cotización`
   - `COTIZACION`

3. Si el asunto no contiene esas palabras, devuelve vacío y el workflow se detiene.

# 5. Crear la base de datos en Notion

En Notion, crea una base de datos con estas propiedades:

| Propiedad | Tipo |
|---|---|
| Asunto | Title |
| Nombre | Text |
| Email | Email |
| Fecha | Date |
| Origen | Text o Select |
| Tipo | Text o Select |

Ejemplo:

```text
Asunto → Title
Nombre → Text
Email → Email
Fecha → Date
Origen → Text
Tipo → Text
```

Importante:

- Comparte la base de datos con tu integración de Notion.
- Copia el ID de la base de datos.

El ID normalmente se ve en la URL de Notion, algo así:

```text
https://www.notion.so/tuworkspace/TuBaseDeDatos-1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d?v=...
```

El ID sería:

```text
1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d
```

```text

       ↓

       ↓

       ↓
```

Pero la mejor opción es conectar **Code** a ambos nodos:

```text
                    → [Slack]
[Gmail Trigger] → [Code]
                    → [Notion]
```

Así Slack y Notion reciben exactamente los mismos datos limpios.

# 8. Flujo final

Cuando llegue un email:

1. Gmail Trigger detecta el correo.
2. El nodo Code revisa el asunto.
3. Si contiene `propuesta` o `cotizacion`:
   - extrae los datos del remitente
   - prepara los campos
4. Envía una notificación a Slack.
5. Crea una nueva página/fila en Notion.

Si el asunto no contiene esas palabras, el workflow no hace nada.
