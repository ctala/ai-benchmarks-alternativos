- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada

## Respuesta completa



Aquí tienes una query usando CTEs y funciones de ventana. Asumo que:

- El revenue se toma de `orders.total`.
- Solo cuentan las órdenes `completed` de los últimos 6 meses.
- La `categoria_mas_comprada` es la categoría con mayor cantidad total comprada (`SUM(quantity)`), desempate por revenue y luego por nombre de categoría.

```sql
WITH completed_orders AS (
    SELECT
        o.id AS order_id,
        o.customer_id,
        o.total
    FROM orders AS o
    WHERE o.status = 'completed'
      AND o.created_at >= DATE_SUB(NOW(), INTERVAL 6 MONTH)
      -- En PostgreSQL: AND o.created_at >= CURRENT_TIMESTAMP - INTERVAL '6 months'
),

customer_metrics AS (
    SELECT
        customer_id,
        COUNT(*) AS total_orders,
        SUM(total) AS total_revenue,
        AVG(total) AS avg_order_value
    FROM completed_orders
    GROUP BY customer_id
    HAVING COUNT(*) >= 3
),

category_sales AS (
    SELECT
        co.customer_id,
        p.category,
        SUM(oi.quantity) AS total_quantity,
        SUM(oi.quantity * oi.unit_price) AS category_revenue
    FROM completed_orders AS co
    JOIN order_items AS oi
      ON oi.order_id = co.order_id
    JOIN products AS p
      ON p.id = oi.product_id
    WHERE p.category IS NOT NULL
    GROUP BY co.customer_id, p.category
),

ranked_categories AS (
    SELECT
        customer_id,
        category AS categoria_mas_comprada,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY total_quantity DESC, category_revenue DESC, category
        ) AS rn
    FROM category_sales
)

SELECT
    c.name,
    c.email,
    c.country,
    cm.total_orders,
    cm.total_revenue,
    cm.avg_order_value,
    rc.categoria_mas_comprada
FROM customer_metrics AS cm
JOIN customers AS c
  ON c.id = cm.customer_id
LEFT JOIN ranked_categories AS rc
  ON rc.customer_id = cm.customer_id
 AND rc.rn = 1
ORDER BY cm.total_revenue DESC
LIMIT 10;
```
