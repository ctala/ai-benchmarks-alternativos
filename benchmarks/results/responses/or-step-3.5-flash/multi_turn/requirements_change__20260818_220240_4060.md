¡Excelente ajuste! Aquí está el flujo actualizado:

## **Workflow: Gmail → Notion + Slack (con filtro)**

### **1. Gmail Trigger**
- **Tipo**: "Gmail Trigger"
- **Configuración**: 
  - `Trigger` → "New Email"
  - `Options` → `Mark as read` (opcional, para no procesar repetidos)
  - `Filters` → Dejar vacío (el filtro lo haremos después)

### **2. Filtro por asunto (IF Node)**
- **Tipo**: "IF"
- **Condiciones**:
  - `{{ $json.subject }}` → `contains` → `propuesta` **OR**
  - `{{ $json.subject }}` → `contains` → `cotizacion`
- *Nota: sensible a mayúsculas/minúsculas. Si quieres ignorar mayúsculas, usa un Function node previo para convertir a minúsculas.*

### **3. Function Node (extracción y formato)**
```javascript
// Extrae datos clave y formatea para Notion
const email = $input.all()[0].json;

// Parsear remitente (ejemplo: "Juan Pérez <juan@empresa.com>")
const fromHeader = email.from;
const emailMatch = fromHeader.match(/<(.+)>/);
const emailAddress = emailMatch ? emailMatch[1] : fromHeader;
const nameMatch = fromHeader.match(/(.+)\s?</);
const senderName = nameMatch ? nameMatch[1].trim() : "Sin nombre";

return {
  nombre: senderName,
  email: emailAddress,
  asunto: email.subject,
  fecha: email.date,
  preview: email.text ? email.text.substring(0, 200) : "",
  threadId: email.threadId
};
```

### **4. Notion: Crear página en base de datos**
- **Tipo**: "Notion"
- **Acción**: "Create Page"
- **Configuración clave**:
  - `Database ID`: ID de tu base de datos en Notion (ej: `https://www.notion.so/.../{DATABASE_ID}`)
  - `Properties`: Mapea según tu base de datos:
    - `Nombre` → `{{ $json.nombre }}` (tipo: Title)
    - `Email` → `{{ $json.email }}` (tipo: Email)
    - `Asunto` → `{{ $json.asunto }}` (tipo: Text)
    - `Fecha` → `{{ $json.fecha }}` (tipo: Date)
    - `Preview` → `{{ $json.preview }}` (tipo: Text)
    - `Thread ID` → `{{ $json.threadId }}` (tipo: Text, para referencia)
- **Requisito previo**: 
  1. En Notion: Crear integración → Conectar a tu base de datos
  2. Copiar `Internal Integration Token` y `Database ID`

### **5. Slack: Notificación**
- **Tipo**: "Slack"
- **Acción**: "Send Message"
- **Configuración**:
  - `Channel` o `User ID`: Canal donde llegarán las alertas (ej: `#proposals`)
  - `Text`: Mensaje personalizado, ej:
    ```
     Nueva propuesta/cotización recibida:
    *De:* {{ $json.nombre }} ({{ $json.email }})
    *Asunto:* {{ $json.asunto }}
    *Fecha:* {{ $json.fecha }}
    🔗 [Ver en Notion]({{ $json.pageUrl }}) ← (Notion devuelve URL al crear página)
    ```
  - `Options` → `Send as user` (si quieres que aparezca como tu usuario)

## **Configuraciones previas necesarias:**

### **Notion:**
1. En tu workspace de Notion:
   - Settings → Integrations → + New integration → Nombrar (ej: "N8N Leads")
   - Copiar el `Internal Integration Token`
2. En tu base de datos:
   - Compartir → Invitar → Buscar tu integración → Conceder permisos
   - Copiar el `Database ID` desde la URL

### **Slack:**
1. Crear app en https://api.slack.com/apps
2. Add features → "Bots" → Install to workspace
3. Copiar `Bot User OAuth Token` (empieza con `xoxb-`)
4. Invitar el bot al canal con `/invite @nombredelbot`
