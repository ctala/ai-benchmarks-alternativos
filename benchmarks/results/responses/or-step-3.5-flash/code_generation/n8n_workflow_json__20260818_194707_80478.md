3. Usar un nodo de OpenAI para clasificar el mensaje. Necesitaremos configurar el nodo de OpenAI con una prompt que pida clasificar en las categorías dadas.
4. Dependiendo de la clasificación, enviar a diferentes canales de Slack.

Para el nodo de OpenAI, asumo que usaremos el modelo de chat (gpt-3.5-turbo o similar) y una prompt como:
"Clasifica el siguiente mensaje en una de estas categorías: 'soporte', 'ventas', 'otro'. Mensaje: {{ $json.message }}"

Pero ten en cuenta que el nodo de OpenAI en n8n puede requerir configurar el "System Message" y el "User Message". Vamos a estructurarlo:

- System: "Eres un clasificador de mensajes. Debes responder solo con una de las siguientes palabras: soporte, ventas, otro."
- User: "Clasifica este mensaje: {{ $json.message }}"

Luego, el nodo de OpenAI devolverá una respuesta que será el texto clasificado. Asumimos que será una de las tres palabras.

Después, usaremos un nodo "Switch" (o "IF") para enrutar según el resultado.

Finalmente, para cada caso, un nodo de Slack que envíe el mensaje al canal correspondiente. En el mensaje de Slack, podemos incluir el email y el mensaje original.

Nota: El webhook debe estar configurado para esperar un JSON con los campos "email" y "message". En el nodo webhook, la ruta puede ser algo como "/webhook".

Vamos a construir el JSON del workflow. n8n guarda los workflows en un formato JSON con una estructura específica.

Estructura general:

- Cada nodo tiene un "type", "name", "parameters", etc.

4. Tres nodos de Slack (type: "n8n-nodes-base.slack") para cada canal.
