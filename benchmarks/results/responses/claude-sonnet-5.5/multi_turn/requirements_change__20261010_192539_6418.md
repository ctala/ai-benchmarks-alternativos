**system:**

Eres un asistente tecnico para emprendedores que trabajan con N8N.

Necesito un workflow en N8N que lea emails de Gmail, extraiga los datos del remitente, y los guarde en un Google Sheet.

**assistant:**

Perfecto, ese workflow es bastante directo. Te explico los pasos:

1. **Trigger**: Gmail Trigger (se activa con cada email nuevo)
2. **Extraer datos**: Function node para parsear remitente, asunto, fecha
3. **Guardar**: Google Sheets node para agregar una fila

Los campos a extraer serian: nombre del remitente, email, asunto, fecha. Quieres que te detalle la configuracion de cada nodo?

**user:**

En realidad, cambio de idea. No quiero Google Sheets, quiero que los datos vayan a Notion. Ademas, quiero que el workflow filtre solo los emails que tengan la palabra 'propuesta' o 'cotizacion' en el asunto. Y que me mande una notificacion a Slack cuando llegue uno.


## Respuesta completa

Entendido: cambia Google Sheets por Notion, y se suman un filtro y una notificación a Slack.

## Flujo

**Gmail Trigger → Filter → Edit Fields → Notion → Slack**

## 1. Gmail Trigger
- **Event:** Message Received
- **Poll Time:** Every Minute (o lo que prefieras)
- **Simplify:** OFF, para obtener `from`, `subject` y `date` ya parseados
- *Opcional:* en Filters > Search puedes poner `subject:(propuesta OR cotizacion)` para que Gmail filtre antes de llegar a N8N. Aun así deja el filtro del paso 2 como respaldo.

## 2. Filter (o IF)
Condición con expresión:

```
{{ /propuesta|cotizaci[oó]n/i.test($json.subject) }}
```
- Operador: **Boolean → is true**
- La `i` ignora mayúsculas y `[oó]` cubre "cotizacion" y "cotización".

## 3. Edit Fields (Set)
Crea estos campos:

| Campo | Valor |
|---|---|
| `nombre` | `{{ $json.from.value[0].name \|\| $json.from.value[0].address }}` |
| `email` | `{{ $json.from.value[0].address }}` |
| `asunto` | `{{ $json.subject }}` |
| `fecha` | `{{ $json.date }}` |

El `||` evita un nombre vacío cuando el remitente solo trae la dirección.

## 4. Notion
- **Resource:** Database Page → **Create**
- Primero crea la base de datos en Notion y **conéctale tu integración** (menú ⋯ → Connections), si no N8N no la verá.
- Propiedades sugeridas en la base:
  - Nombre → *Title*
  - Email → *Email*
  - Asunto → *Text*
  - Fecha → *Date*
- Mapea cada propiedad al campo correspondiente del paso 3.

## 5. Slack
- **Resource:** Message → **Send**
- Elige el canal y usa un texto como:

```
📩 Nueva solicitud recibida
*De:* {{ $('Edit Fields').item.json.nombre }} ({{ $('Edit Fields').item.json.email }})
*Asunto:* {{ $('Edit Fields').item.json.asunto }}
*Notion:* {{ $json.url }}
```

Como Slack va después de Notion, puedes incluir el link a la página recién creada con `$json.url`.

## Cosas a tener en cuenta
- Si el nombre del nodo Set no es "Edit Fields", ajusta la referencia en `$('...')`.
- La estructura de salida de Gmail puede variar según la versión de N8N. Ejecuta el trigger una vez y revisa el output real antes de mapear.
- Si quieres evitar que un fallo de Notion bloquee el aviso de Slack, conecta ambos nodos en paralelo desde Edit Fields (perderías el link de Notion).
