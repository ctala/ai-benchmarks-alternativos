## Bugs que indicas (confirmados)

### 1. División por cero
Si `orders` está vacía, o ninguna orden tiene estado `'pending'`, entonces `processed` queda vacío y `total / len(processed)` lanza `ZeroDivisionError`.

**Corrección:** comprobar que haya elementos antes de dividir. Devuelvo `0`, pero `None` también sería válido si quieres distinguir "sin datos" de "promedio cero".

### 2. Muta los diccionarios originales
`order['final_price'] = ...` y `order['status'] = 'processed'` modifican el diccionario del llamador. Esto tiene consecuencias reales: si llamas a la función dos veces con la misma lista, la segunda vez no procesa nada, porque las órdenes ya no están `'pending'`. Eso además dispara el bug 1.

**Corrección:** crear una copia de cada orden y modificar solo la copia. `{**order, ...}` es una copia superficial. Si las órdenes contienen estructuras anidadas (listas o dicts), usa `copy.deepcopy(order)`.

### 3. `count` incorrecto
`len(orders)` cuenta todas las órdenes, incluidas las que no se procesaron, así que no coincide con `processed` ni con `total`/`average`. Debe ser `len(processed)`.

Si además quieres saber cuántas órdenes llegaron en total, añade otra clave como `'received'`.

## Bugs adicionales que encontré

### 4. `KeyError` con datos incompletos
`order['status']` falla si falta la clave. Usar `order.get('status')` es más robusto. Para `'total'`, conviene validar explícitamente.

### 5. Precisión con dinero
`order['total'] * 0.1` con floats acumula errores (por ejemplo `0.30000000000000004`). Lo mínimo es redondear a 2 decimales. Lo ideal para dinero es usar `Decimal` o trabajar en centavos.

## Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order.get('status') != 'pending':
            continue

        if 'total' not in order:
            raise ValueError(f"La orden no tiene 'total': {order}")

        order_total = order['total']
        discount = order_total * 0.1 if order_total > 100 else 0
        final_price = round(order_total - discount, 2)

        # Copia: no se modifica el diccionario original
        new_order = {**order, 'final_price': final_price, 'status': 'processed'}

        total += final_price
        processed.append(new_order)

    count = len(processed)
    average = round(total / count, 2) if count else 0

    return {
        'processed': processed,
        'total': round(total, 2),
        'average': average,
        'count': count,
    }
```
