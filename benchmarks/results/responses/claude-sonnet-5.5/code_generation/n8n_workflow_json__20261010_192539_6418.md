## Antes de usarlo

1. **Importa el JSON** en n8n con *Workflows → Import from File/URL*, o pegándolo con Ctrl+V en el canvas.
2. **Configura las credenciales** de OpenAI y de Slack. Los IDs `REEMPLAZAR_...` son placeholders, así que vuelve a seleccionar tus credenciales en cada nodo.
3. **Revisa Slack:**
   - El bot necesita el scope `chat:write` y debe estar invitado a los canales (`/invite @tu_bot`).
   - Si el modo "name" te da problemas, cambia el canal a *From list* o *By ID*.
4. **Prueba el workflow:**
   ```bash
   curl -X POST https://TU_N8N/webhook-test/clasificar-mensaje \
     -H "Content-Type: application/json" \
     -d '{"email":"cliente@ejemplo.com","message":"Hola, quiero una cotización para 50 licencias"}'
   ```
5. **Activa el workflow** cuando termines las pruebas, para que use la URL de producción `/webhook/...`.

Si tu versión de n8n es antigua y no reconoce `typeVersion` 1.8 del nodo OpenAI, vuelve a añadir el nodo manualmente y copia el prompt. El resto del flujo seguirá funcionando.
