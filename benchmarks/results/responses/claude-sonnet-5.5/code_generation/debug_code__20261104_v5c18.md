# Análisis de bugs

## Bug 1: División por cero
```python
average = total / len(processed)  # ZeroDivisionError si processed está vacío
```
Si `orders` está vacío o ninguna orden tiene estado `'pending'`, `len(processed)` es 0 y el programa lanza `ZeroDivisionError`.

**Solución:** devolver 0 (o `None`) cuando no haya órdenes procesadas.

## Bug 2: Mutación de los diccionarios originales
```python
order['final_price'] = final_price
order['status'] = 'processed'
```
Estas líneas modifican el diccionario del llamador. Esto tiene un efecto en cadena: si llamas a la función dos veces con la misma lista, la segunda vez ya no hay órdenes `pending` y se dispara el Bug 1. Además, `processed` contiene referencias a los mismos objetos originales.

**Solución:** trabajar con una copia (`{**order, ...}` o `order.copy()`).

## Bug 3: `count` incorrecto
```python
'count': len(orders)  # cuenta TODAS las órdenes, no las procesadas
```
Si hay 10 órdenes y solo 3 son `pending`, devuelve 10 aunque `processed` tenga 3 elementos, lo que es inconsistente con `total` y `average`.

## Bugs adicionales

- **`KeyError`:** `order['status']` y `order['total']` fallan si falta alguna clave. Conviene usar `.get()` o validar.
- **Precisión con dinero:** los `float` acumulan errores (`0.1 * 330` → `33.0` puede salir como `32.99999...`). Lo mínimo es redondear a 2 decimales; lo ideal es usar `Decimal`.
- **Números mágicos:** `100` y `0.1` están "hardcodeados"; mejor como constantes con nombre.

# Versión corregida

```python
DISCOUNT_THRESHOLD = 100
DISCOUNT_RATE = 0.1


def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order.get('status') != 'pending':
            continue

        order_total = order.get('total')
        if order_total is None:
            continue  # o: raise ValueError("Orden sin 'total'")

        discount = order_total * DISCOUNT_RATE if order_total > DISCOUNT_THRESHOLD else 0
        final_price = round(order_total - discount, 2)

        # Copia: no mutamos el diccionario original
        processed_order = {
            **order,
            'final_price': final_price,
            'status': 'processed',
        }

        processed.append(processed_order)
        total += final_price

    count = len(processed)
    average = round(total / count, 2) if count else 0

    return {
        'processed': processed,
        'total': round(total, 2),
        'average': average,
        'count': count,
    }
```
