### Bug 1: División por cero si no hay órdenes pendientes
**Problema:** Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía. Al calcular `average = total / len(processed)`, se divide por cero, lo que lanza una excepción `ZeroDivisionError`.

**Solución:** Verificar que `processed` no esté vacío antes de dividir. Si está vacío, el promedio debe ser `0`.

### Bug 2: Mutación del diccionario original
**Problema:** En Python, al iterar `for order in orders`, la variable `order` es una **referencia** al diccionario original dentro de la lista. Al hacer `order['status'] = 'processed'` y `order['final_price'] = final_price`, se están modificando directamente los diccionarios de entrada. Esto es un efecto secundario no deseado.

**Solución:** Crear una copia superficial (`order.copy()`) del diccionario, modificar la copia y agregar esa copia a la lista `processed`.

### Bug 3: Contador incorrecto (`count`)
**Problema:** El valor `'count': len(orders)` devuelve la cantidad total de órdenes recibidas, no la cantidad de órdenes que fueron realmente procesadas (las que estaban en estado `pending`).

**Solución:** Cambiarlo por `len(processed)` para reflejar cuántas órdenes se procesaron efectivamente.

### Código corregido

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            # Crear una copia para no mutar el diccionario original
            new_order = order.copy()
            
            discount = new_order['total'] * 0.1 if new_order['total'] > 100 else 0
            final_price = new_order['total'] - discount
            
            new_order['final_price'] = final_price
            new_order['status'] = 'processed'
            
            total += final_price
            processed.append(new_order)

    # Evitar división por cero si no se procesó ninguna orden
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Ahora cuenta las órdenes efectivamente procesadas
    }
```
