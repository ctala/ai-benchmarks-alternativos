### Explicación de los Bugs

1.  **División por cero (`ZeroDivisionError`)**
    *   **Problema:** En la línea `average = total / len(processed)`, si la lista `processed` está vacía (porque no hubo órdenes 'pending' o la lista de entrada estaba vacía), `len(processed)` será 0. Intentar dividir por 0 lanza una excepción en Python y detiene el programa.
    *   **Solución:** Verificar si hay elementos en `processed` antes de dividir. Si está vacío, el promedio debe ser 0 (o `None`).

2.  **Mutación del diccionario original (Efecto secundario)**
    *   **Problema:** Los diccionarios en Python son objetos mutables. Al hacer `order['final_price'] = ...` y `order['status'] = ...`, estás modificando directamente el diccionario que fue pasado como argumento a la función. Esto es peligroso porque el código que llamó a la función podría esperar que sus datos originales permanezcan inalterados.
    *   **Solución:** Crear una copia del diccionario `order` (usando `.copy()`) antes de modificarlo y agregar esa copia a la lista `processed`.

3.  **Conteo incorrecto (`count`)**
    *   **Problema:** El retorno incluye `'count': len(orders)`. Esto devuelve el número total de órdenes recibidas, no el número de órdenes que realmente se procesaron. Dado que el reporte incluye `total` y `average` de las órdenes *procesadas*, el `count` debería ser coherente con esos datos.
    *   **Solución:** Cambiar `len(orders)` por `len(processed)`.

def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        # Validación básica para evitar errores si faltan claves (opcional pero recomendado)
        if order.get('status') == 'pending':
            # BUG 2 CORREGIDO: Creamos una copia para no mutar el original
            order_copy = order.copy()
            
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount
            
            order_copy['final_price'] = final_price
            order_copy['status'] = 'processed'
            
            total += final_price
            processed.append(order_copy)

    # BUG 1 CORREGIDO: Evitamos división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        # BUG 3 CORREGIDO: Contamos las procesadas, no las totales
