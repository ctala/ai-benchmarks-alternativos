### 🔷 BLOQUE 1: ¡LA ERA DEL ASISTENTE DE IA PARA STARTUPS!
**⏱ Duración:** 20 minutos (0:00 – 0:20)
**📊 Slides:** 10

#### 🎯 Objetivo:
Romper el hielo, generar energía, y establecer el por qué esto es URGENTE para su startup.

#### 📝 Contenido y dinámica:

| Tiempo | Actividad | Tipo |
|---|---|---|
| 0:00-0:05 | **Icebreaker energético:** "Levanta la mano si tu startup ya pierde tiempo respondiendo las MISMAS preguntas. Ahora si tu startup no tiene suficiente equipo para atender a todos los clientes..." | Charla interactiva |
| 0:05-0:12 | **La historia:** Por qué los asistentes de IA ya no son cosa de grandes empresas. Datos reales de startups latinoamericanas que ya lo usan. Mostrar 2-3 ejemplos visuales de asistentes funcionando | Charla + demo rápida |
| 0:12-0:17 | **El "Before & After":** Mostrar en pantalla un asistente de IA para atención al cliente — el mensaje del cliente, la respuesta automática, el tiempo ahorrado. Que sientan el "wow" | Demo en vivo |
| 0:17-0:20 | **Expectativas del workshop:** "En 3 horas vas a tener tu propio asistente funcionando. Sin código. Sin excusas. ¿Listos?" | Charla |

#### 🗝 Key takeaway:
> *"No necesitas ser programador para tener un asistente de IA. Necesitas saber QUÉ problema resolver y la herramienta correcta. Hoy vas a hacer ambos."*

### 🔷 BLOQUE 2: ANATOMÍA DE UN ASISTENTE DE IA
**⏱ Duración:** 25 minutos (0:20 – 0:45)
**📊 Slides:** 12

#### 🎯 Objetivo:
Que entiendan los componentes clave de un asistente de IA de forma simple y visual, y definan QUÉ va a hacer el suyo.

#### 📝 Contenido y dinámica:

| Tiempo | Actividad | Tipo |
|---|---|---|
| 0:20-0:30 | **"El asistente es como un empleado virtual":** Explicar los 5 componentes con analogías humanas: 1) **El cerebro** (modelo de IA), 2) **Las instrucciones** (prompt/system), 3) **Las herramientas** (integraciones), 4) **La memoria** (base de conocimiento), 5) **La interfaz** (dónde vive: WhatsApp, web, app) | Charla con diagrama visual |
| 0:30-0:42 | **EJERCICIO: "Tu Canvas del Asistente"** — Cada persona llena la plantilla impresa: | Ejercicio individual |
| | • **¿Qué problema resuelve?** (ej: responder FAQs, calificar leads, agendar citas) | |
| | • **¿Quién es tu usuario?** (cliente, prospecto, empleado) | |
| | • **¿Dónde vive?** (WhatsApp, web, Instagram DM) | |
| | • **¿Qué debe saber?** (precios, servicios, políticas) | |
| | • **¿Qué NO debe hacer?** (dar descuentos, prometer cosas) | |
| 0:42-0:45 | **Share rápido:** 3 personas muestran su canvas en 30 seg. Cada uno. Feedback rápido. | Discusión grupal |

#### 🗝 Key takeaway:
> *"Un asistente de IA es solo 5 piezas. Si puedes explicar tu idea en un post-it, puedes construir un asistente."*

### 🔷 🔥 BLOQUE 5: EJERCICIO PRINCIPAL — CONSTRUYE TU ASISTENTE (HANDS-ON)
**⏱ Duración:** 45 minutos (1:35 – 2:20)
**📊 Slides:** 6 (slides de referencia, no para presentar — se dejan en pantalla)

#### 🎯 Objetivo:
Que CADA asistente construya su propio asistente de IA funcional en Voiceflow, usando su caso de uso real.

#### 📝 Contenido y dinámica:

**Este es el corazón del workshop.** El facilitador circula, ayuda, resuelve dudas.

| Tiempo | Actividad | Tipo |
|---|---|---|
| 1:35-1:40 | **Setup:** Abrir Voiceflow, crear proyecto nuevo, revisar el "Canvas" que llenaron en el Bloque 2. Instrucciones claras en pantalla (checklist paso a paso) | Instrucción |
| 1:40-1:55 | **Paso 1-3: Estructura básica** | Ejercicio hands-on |
| | ☐ Mensaje de bienvenida personalizado para SU startup | |
| | ☐ Conectar el "cerebro" (LLM) con un prompt que incluya: su startup, su tono de voz, lo que debe y no debe decir | |
| | ☐ Cargar 5-10 preguntas frecuentes de SU negocio como base de conocimiento | |
| 1:55-2:10 | **Paso 4-5: Flujos inteligentes** | Ejercicio hands-on |
| | ☐ Agregar al menos 1 flujo de captura de datos (ej: "Déjanos tu email" / "Agenda una llamada") | |
| | ☐ Configurar 1 acción condicional (ej: si pregunta sobre precios → responder con catálogo) | |
| 2:10-2:20 | **Paso 6: Publicar y probar** | Ejercicio hands-on |
| | ☐ Publicar el asistente | |
| | ☐ Probarlo con 3 preguntas reales de su negocio | |
| | ☐ Compartir el link en el chat grupal del grupo (Slack/WhatsApp del workshop) | |

#### 🛠️ Hoja de trucos de prompts (entregada impresa):
```
PROMPT BASE PARA TU ASISTENTE:
"Eres el asistente virtual de [NOMBRE DE TU STARTUP].
Tu misión es [QUÉ HACE].
Tono: [AMIGABLE / PROFESIONAL / ENTREMEDIO].
Responde en [IDIOMA].
SIEMPRE: [3 cosas que debe hacer]
NUNCA: [3 cosas que debe evitar]
Si no sabes la respuesta, di: [FRASE DE ESCAPE]
Si el usuario pide algo fuera de tu alcance, [QUÉ HACER]."
```

#### 🗝 Key takeaway:
> *"Acabas de construir tu primer asistente de IA. No es perfecto, pero FUNCIONA. Y eso es todo lo que importa para empezar."*

## ⚡ CONSEJOS DE FACILITACIÓN

| # | Consejo |
|---|---|
| 1 | **Nunca más de 10 minutos de charla seguida.** Alternar siempre con demo o ejercicio. |
| 2 | **El Bloque 5 es sagrado.** Si se atrasa, recorta el Bloque 7 (errores comunes) — pero NUNCA el ejercicio principal. |
| 3 | **Pre-selecciona 4-5 personas** para el Show & Tell (pregunta en el pre-work quién quiere mostrar). |
| 4 | **Ten 2-3 asistentes de apoyo** (mentores técnicos) para ayudar en el Bloque 5. Ratio ideal: 1 ayudante cada 8-10 personas. |
| 5 | **Mantén el timer visible** siempre. Los emprendedores respetan los tiempos. |
| 6 | **Usa lenguaje de emprendedor**, no de ingeniero. En vez de "prompt engineering" → "instrucciones para tu asistente". En vez de "LLM" → "el cerebro de IA". |
