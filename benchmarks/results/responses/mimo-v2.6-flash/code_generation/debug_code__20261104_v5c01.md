## Análisis de los 3 Bugs

---

### Bug 1: División por cero

**Problema:**
```python
average = total / len(processed)  # Si processed está vacío → ZeroDivisionError
```
Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía y `len(processed)` es `0`, lo que provoca un `ZeroDivisionError`.

**Corrección:**
```python
average = total / len(processed) if processed else 0
```

---

### Bug 2: Mutación del diccionario original

**Problema:**
```python
order['final_price'] = final_price  # Modifica el diccionario original
order['status'] = 'processed'       # Modifica el diccionario original
```
Las líneas `order['final_price'] = ...` y `order['status'] = 'processed'` modifican directamente los diccionarios que están dentro de la lista `orders` que se pasó como parámetro. Esto tiene **efectos secundarios**: si el llamador vuelve a usar la lista `orders` después de llamar a `process_orders`, verá las órdenes ya modificadas (con `status` cambiado y `final_price` añadido).

**Corrección:** crear una copia del diccionario antes de modificarlo.
```python
order = order.copy()  # Copia superficial antes de modificar
```

---

### Bug 3: `count` devuelve el total de órdenes, no las procesadas

**Problema:**
```python
'count': len(orders)  # Cuenta TODAS las órdenes, no solo las procesadas
```
El campo `count` debería reflejar cuántas órdenes fueron procesadas, no cuántas entraron en total. `len(orders)` incluye las que no tenían `status == 'pending'`.

**Corrección:**
```python
'count': len(processed)
```

## Versión Corregida Completa

```python
def process_orders(orders):
    total = 0
    processed = []
    for order in orders:
        if order['status'] == 'pending':
            order = order.copy()  # Bug 2: copia para no mutar el original
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount
            order['final_price'] = final_price
            order['status'] = 'processed'
            total += final_price
            processed.append(order)

    average = total / len(processed) if processed else 0  # Bug 1: evitar división por cero

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Bug 3: contar solo las procesadas
    }
```
