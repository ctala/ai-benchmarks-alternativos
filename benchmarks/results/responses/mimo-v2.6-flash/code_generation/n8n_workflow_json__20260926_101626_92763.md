## 🔧 Pasos de configuración

| Paso | Acción |
|------|--------|
| **1** | Importa el JSON en n8n (`Workflows → Import from File`) |
| **2** | Crea credencial **OpenAI** y reemplaza `REPLACE_WITH_YOUR_OPENAI_CREDENTIAL_ID` |
| **3** | Crea credencial **Slack** y reemplaza `REPLACE_WITH_YOUR_SLACK_CREDENTIAL_ID` |
| **4** | Activa el workflow y copia la URL del webhook |
| **5** | Envía una prueba con `curl` |

## 🧪 Ejemplo de prueba

```bash
curl -X POST https://TU_INSTANCIA_N8N/webhook/classify-email \
  -H "Content-Type: application/json" \
  -d '{
    "email": "juan@empresa.com",
    "message": "Tengo un error al intentar iniciar sesión, me dice que la contraseña es incorrecta"
  }'
```

> **Nota:** Si el mensaje contiene un error técnico → llegará a **#support**. Si menciona precios o compra → **#sales**. Si no encaja en ninguna → **#general**.
