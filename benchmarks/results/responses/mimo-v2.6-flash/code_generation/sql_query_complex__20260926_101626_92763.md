# Query SQL — Top 10 Clientes por Revenue (Últimos 6 Meses)

```sql
-- ============================================================
-- CTE 1: Total de revenue por orden (evita duplicación)
-- ============================================================
WITH order_totals AS (
    SELECT
        o.id          AS order_id,
        o.customer_id,
        SUM(oi.quantity * oi.unit_price) AS order_revenue
    FROM orders o
    JOIN order_items oi ON oi.order_id = o.id
    WHERE o.status   = 'completed'
      AND o.created_at >= DATEADD(MONTH, -6, GETDATE())
    GROUP BY o.id, o.customer_id
),

-- ============================================================
-- CTE 2: Estadísticas agregadas por cliente
-- ============================================================
customer_stats AS (
    SELECT
        c.id,
        c.name,
        c.email,
        c.country,
        COUNT(ot.order_id)              AS total_orders,
        SUM(ot.order_revenue)           AS total_revenue,
        AVG(ot.order_revenue)           AS avg_order_value
    FROM customers c
    JOIN order_totals ot ON ot.customer_id = c.id
    GROUP BY c.id, c.name, c.email, c.country
    HAVING COUNT(ot.order_id) >= 3       -- mínimo 3 ordenes completadas
),

-- ============================================================
-- CTE 3: Categoría más comprada por cliente (por cantidad)
-- ============================================================
category_ranks AS (
    SELECT
        c.id             AS customer_id,
        p.category,
        SUM(oi.quantity) AS total_qty,
        ROW_NUMBER() OVER (
            PARTITION BY c.id
            ORDER BY SUM(oi.quantity) DESC
        ) AS rn
    FROM customers c
    JOIN orders o       ON o.customer_id = c.id
    JOIN order_items oi ON oi.order_id   = o.id
    JOIN products p     ON p.id          = oi.product_id
    WHERE o.status      = 'completed'
      AND o.created_at >= DATEADD(MONTH, -6, GETDATE())
    GROUP BY c.id, p.category
)

-- ============================================================
-- RESULTADO FINAL
-- ============================================================
SELECT
    cs.name,
    cs.email,
    cs.country,
    cs.total_orders,
    cs.total_revenue,
    cs.avg_order_value,
    cr.category           AS categoria_mas_comprada
FROM customer_stats cs
JOIN category_ranks cr
  ON cr.customer_id = cs.id
 AND cr.rn = 1                              -- solo la #1
ORDER BY cs.total_revenue DESC
LIMIT 10;
```

## Notas importantes

| Aspecto | Detalle |
|---|---|
| **`DATEADD`** | Función de **SQL Server**. Alternativas: `DATE_SUB(CURDATE(), INTERVAL 6 MONTH)` en MySQL, `CURRENT_DATE - INTERVAL '6 months'` en PostgreSQL |
| **`avg_order_value`** | Se calcula desde la CTE `order_totals` (promedio por **orden**, no por ítem) para evitar distorsión |
| **`categoria_mas_comprada`** | Usa `ROW_NUMBER()` para elegir **una sola** categoría en caso de empate |
| **`HAVING ≥ 3`** | Se aplica en `customer_stats` **antes** del JOIN final, optimizando el resultado |
| **`total_revenue`** | `SUM(orden_revenue)` es correcto porque `order_totals` ya agrupó por orden → sin duplicación |
