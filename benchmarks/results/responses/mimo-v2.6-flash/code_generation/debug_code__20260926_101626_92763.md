# Análisis de Bugs y Corrección

## Bug 1: División por cero

**Explicación:** Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía. Al ejecutar `len(processed)` se obtiene `0`, causando una `ZeroDivisionError`.

```python
# ❌ Crash si processed = []
average = total / len(processed)
```

---

## Bug 2: Mutación del diccionario original

**Explicación:** `order['final_price'] = final_price` y `order['status'] = 'processed'` modifican directamente el diccionario original de la lista `orders`. Esto significa que el caller pierde acceso al estado previo de sus órdenes. Si luego reutiliza `orders`, verá los datos ya mutados.

```python
# ❌ El diccionario de la lista original cambia
order['final_price'] = final_price
order['status'] = 'processed'
```

---

## Bug 3: `count` incorrecto

**Explicación:** El campo `count` devuelve `len(orders)` (todas las órdenes recibidas), pero debería reflejar las órdenes **efectivamente procesadas**, es decir `len(processed)`. Devuelve un valor engañoso si habían órdenes no-pending.

```python
# ❌ Dice "10 procesadas" cuando solo 3 eran pending
'count': len(orders)   # ← debería ser len(processed)
```

## ✅ Versión Corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            # Corrección Bug 2: copia el diccionario en vez de mutar el original
            order_copy = order.copy()

            discount = order_copy['total'] * 0.1 if order_copy['total'] > 100 else 0
            final_price = order_copy['total'] - discount

            order_copy['final_price'] = final_price
            order_copy['status'] = 'processed'

            total += final_price
            processed.append(order_copy)

    # Corrección Bug 1: evitar división por cero
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        # Corrección Bug 3: contar solo las procesadas
        'count': len(processed)
    }
```
