# Workflow: Emails filtrados → Notion + Slack

## Arquitectura del workflow

```
[Gmail Trigger] → [IF: Filtro por asunto] → [Function: Extraer datos] → [Notion] → [Slack]
```

---

## 1. Gmail Trigger

| Campo | Valor |
|---|---|
| **Credential** | Tu cuenta de Gmail |
| **Poll Times** | Cada 1 minuto (o lo que necesites) |
| **Filters** | `is:unread` (para no procesar repetidos) |

---

## 2. IF Node — Filtro por asunto

Configura **2 condiciones** con operador **OR**:

```
Condition 1: {{ $json.subject }}  CONTAINS  "propuesta"
Condition 2: {{ $json.subject }}  CONTAINS  "cotizacion"
```

> ⚠️ Si quieres que sea **case-insensitive**, usa `toLower($json.subject)` en el valor del campo:

```javascript
{{ $json.subject.toLowerCase().includes('propuesta') }}
```

- **true** → pasa al siguiente nodo
- **false** → termina el flujo (no hace nada)

---

## 3. Function Node — Extraer datos

```javascript
const email = $input.first().json;

const from = email.from || email.fromAddress || '';
const nameMatch = from.match(/^(.*?)\s*<(.+)>$/);

const output = {
  remitente: nameMatch ? nameMatch[1].trim() : from,
  email: nameMatch ? nameMatch[2] : from,
  asunto: email.subject || '',
  fecha: email.date || new Date().toISOString(),
  cuerpo: email.textPlain || email.textHtml || '',
  messageId: email.id || ''
};

return [{ json: output }];
```

## Cosas a tener en cuenta

- **Case sensitivity**: si los emails llegan como "PROPUESTA", el filtro no va a matchear. Usa `toLower()` para evitar eso.
- **Slack antes que Notion**: si quieres que la notificación salga aunque Notion falle, mueve el Slack **antes** del nodo Notion.
- **Deduplicación**: si no usas `is:unread`, podrías procesar el mismo email varias veces.
