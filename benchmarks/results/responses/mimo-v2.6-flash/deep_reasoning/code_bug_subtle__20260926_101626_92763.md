# El Bug: MAD = 0 Hace que el Threshold se Anule

## El Código Pasa Sin Errores, Pero Devuelve Resultados Incorrectos

### Cuándo falla exactamente

El bug aparece cuando **más de la mitad de los datos son idénticos** (es decir, una mayoría estricta de valores iguales al mediano). Esto causa una cadena en cascada:

```
MAD = 0  →  threshold = 3 * 0 = 0  →  Solo sobreviven valores EXACTAMENTE iguales al mediano
```

### Ejemplo concreto que demuestra el bug:

```python
remove_outliers_and_average([1, 1, 1, 1, 2])
```

Paso a paso:

| Paso | Resultado |
|---|---|
| `sorted` | `[1, 1, 1, 1, 2]` |
| `median` | `1` (índice 2 del array ordenado) |
| `deviations` | `[0, 0, 0, 0, 1]` |
| `MAD` | `0` (la mediana de `[0,0,0,0,1]` es `0`) |
| `threshold` | `3 * 0 = 0` |
| `filtered` | `[1, 1, 1, 1]` ← **¡el 2 se elimina!** |
| **Retorna** | **`1.0`** en lugar de **`1.2`** |

### Por qué es incorrecto

El `2` está a **solo 1 unidad** del mediano. No es un outlier en absoluto. Debería retornar:

$$\frac{1+1+1+1+2}{5} = 1.2$$

Pero devuelve `1.0`, que es simplemente **el propio mediano**.

### Caso más dramático

```python
remove_outliers_and_average([5, 5, 5, 5, 6])
# MEDIO ORIGINAL: 5.2 (correcto)
# RESULTADO:      5.0 (¡incorrecto!)

remove_outliers_and_average([0, 0, 0, 0, 1, 2])
# MEDIO ORIGINAL: 0.5 (correcto)
# RESULTADO:      0.0 (¡incorrecto!)
```

### La causa raíz

El MAD (Median Absolute Deviation) es una medida de dispersión. Cuando una **mayoría estricta** de los datos son idénticos:

```
MAD = mediana([desviaciones]) = mediana([0, 0, 0, 0, ..., pequeño]) = 0
```

Y al multiplicarlo por 3 para obtener el threshold:

```python
threshold = 3 * 0  # = 0
```

La condición de filtrado `abs(x - median) <= threshold` se convierte en `abs(x - median) <= 0`, es decir, **solo sobreviven los valores exactamente iguales al mediano**, independientemente de qué tan cercanos estén los demás datos.

### La función degenera

En esos casos, la función deja de ser *"quitar outliers y promediar el resto"* y se convierte en *"retornar el mediano"*, haciendo que todo el proceso de filtrado y promediado sea inútil.
