Escribe una query SQL que muestre:
- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada

## Respuesta completa

Asumiendo que tanto el revenue como las 3 órdenes mínimas corresponden a órdenes **completadas durante los últimos 6 meses**:

```sql
WITH completed_orders AS (
    SELECT
        o.id,
        o.customer_id,
        o.total
    FROM orders o
    WHERE o.status = 'completed'
      AND o.created_at >= CURRENT_DATE - INTERVAL '6 months'
),

customer_metrics AS (
    SELECT
        c.id AS customer_id,
        c.name,
        c.email,
        c.country,
        COUNT(co.id) AS total_orders,
        SUM(co.total) AS total_revenue,
        AVG(co.total) AS avg_order_value
    FROM customers c
    JOIN completed_orders co
        ON co.customer_id = c.id
    GROUP BY
        c.id,
        c.name,
        c.email,
        c.country
    HAVING COUNT(co.id) >= 3
),

category_totals AS (
    SELECT
        co.customer_id,
        p.category,
        SUM(oi.quantity) AS total_quantity,
        ROW_NUMBER() OVER (
            PARTITION BY co.customer_id
            ORDER BY SUM(oi.quantity) DESC, p.category
        ) AS category_rank
    FROM completed_orders co
    JOIN order_items oi
        ON oi.order_id = co.id
    JOIN products p
        ON p.id = oi.product_id
    GROUP BY
        co.customer_id,
        p.category
)

SELECT
    cm.name,
    cm.email,
    cm.country,
    cm.total_orders,
    cm.total_revenue,
    cm.avg_order_value,
    ct.category AS categoria_mas_comprada
FROM customer_metrics cm
LEFT JOIN category_totals ct
    ON ct.customer_id = cm.customer_id
   AND ct.category_rank = 1
ORDER BY cm.total_revenue DESC
LIMIT 10;
```

La `categoria_mas_comprada` se determina por la suma de unidades (`quantity`) compradas por categoría. En caso de empate, se selecciona la categoría cuyo nombre aparece primero alfabéticamente.
