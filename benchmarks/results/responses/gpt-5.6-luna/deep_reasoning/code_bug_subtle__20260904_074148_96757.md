## Respuesta completa

El bug está en el caso de `data` vacío:

```python
if len(data) < 3:
    return sum(data) / len(data)
```

Si `data == []`, entonces:

```python
sum([]) == 0
len([]) == 0
```

y se intenta calcular `0 / 0`, lo que produce:

```python
ZeroDivisionError: division by zero
```

Falla exactamente cuando `remove_outliers_and_average` recibe una lista vacía. El caso no llega a `find_median`, porque la condición `len(data) < 3` se cumple inmediatamente.

Una corrección posible sería:

```python
def remove_outliers_and_average(data):
    if not data:
        raise ValueError("data no puede estar vacío")

    if len(data) < 3:
        return sum(data) / len(data)
    ...
```

Además, cuando la MAD es cero, el umbral también es cero:

```python
threshold = 3 * mad  # 0
```

En ese caso solo se conservan los valores exactamente iguales a la mediana. Eso no provoca necesariamente una excepción, pero puede descartar todos los valores distintos de la mediana, aunque sean datos válidos. Por ejemplo:

```python
[1, 1, 1, 2, 100]
```

tiene mediana `1` y MAD `0`, por lo que solo se conservan los `1`.
