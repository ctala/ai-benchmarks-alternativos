# Análisis de los bugs

## Bug 1: División por cero

```python
average = total / len(processed)
```

Si `orders` está vacía, o ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía y `len(processed)` es `0`, lo que lanza un `ZeroDivisionError`:

```python
process_orders([])  # ZeroDivisionError
process_orders([{'status': 'shipped', 'total': 50}])  # ZeroDivisionError
```

**Solución:** usar un condicional para devolver `0` (o `None`, según la semántica que prefieras) cuando no hay órdenes procesadas.

## Bug 2: Mutación del diccionario original

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

Estas líneas modifican los diccionarios que recibió la función, un **efecto secundario** inesperado para el llamador. Consecuencias:

- Los datos del caller cambian silenciosamente.
- Si llamas `process_orders(orders)` una segunda vez con los mismos datos, no procesa nada (todas las órdenes ya quedaron con `'processed'`), dando resultados inconsistentes.
- Hace el código más difícil de depurar y testear.

**Solución:** crear una copia de cada orden antes de modificarla (`order.copy()` es suficiente aquí porque solo cambias claves de primer nivel; si hubiera estructuras anidadas necesitarías `copy.deepcopy`).

## Bug 3: `count` incorrecto

```python
'count': len(orders)
```

Cuenta **todas** las órdenes, pero el resto del resultado (`total`, `average`, `processed`) solo se refiere a las órdenes pendientes. Si tienes 5 órdenes y solo 2 están pending, obtienes `count: 5` con `processed: [2 elementos]` — inconsistente y engañoso.

**Solución:** usar `len(processed)`.

# Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []
    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            new_order = order.copy()  # no muta el original
            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            total += final_price
            processed.append(new_order)

    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # consistente con el resto del resultado
    }
```
