## Respuesta completa

**Bugs identificados**

1. **División por cero**: Si no hay órdenes con `status == 'pending'`, `processed` queda vacío y `total / len(processed)` lanza `ZeroDivisionError`.

2. **Mutación del diccionario original**: Se modifican in-place `order['final_price']` y `order['status']`. Los diccionarios son mutables y se pasan por referencia, así que se alteran los datos originales de `orders` (efecto secundario no deseado).

3. **`count` incorrecto**: Devuelve `len(orders)` (todas las órdenes) en lugar de `len(processed)` (solo las procesadas).

**Versión corregida**

```python
def process_orders(orders):
    total = 0
    processed = []
    for order in orders:
        if order.get('status') == 'pending':
            # Copia para no mutar el original
            processed_order = order.copy()
            discount = processed_order['total'] * 0.1 if processed_order['total'] > 100 else 0
            final_price = processed_order['total'] - discount
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'
            total += final_price
            processed.append(processed_order)

    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```

Cambios principales: se usa `.copy()` (o `{**order}`) para no mutar, se protege la división, y `count` usa `len(processed)`. Se añadió `.get()` por robustez ante claves faltantes.
