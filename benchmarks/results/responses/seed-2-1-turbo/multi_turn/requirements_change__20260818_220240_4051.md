#### 3. Nodo 3: Code (extraer datos del remitente)
El trigger de Gmail trae el remitente como un texto tipo `Juan Pérez <juan@empresa.com>`. Este nodo separa el nombre del email y limpia la información:
- Buscá el nodo `Code` (antes se llamaba Function).
- Dejá activado el modo `Run once per item`.
- Pegá este código listo para usar:
```javascript
// Extraer nombre y email del remitente
const remitenteCompleto = $json.from;
const regexRemitente = /^(?<nombre>.*?)\s*<(?<email>[^>]+)>$/;
const match = remitenteCompleto.match(regexRemitente);

let nombreRemitente = '';
let emailRemitente = '';

if (match) {
  nombreRemitente = match.groups.nombre.trim();
  emailRemitente = match.groups.email.trim();
} else {
  // Si el remitente no tiene nombre, usa el email como nombre
  emailRemitente = remitenteCompleto.trim();
  nombreRemitente = emailRemitente;
}

// Limpiar el cuerpo del email (sin HTML, y limitado para no exceder límites de Notion)
const cuerpoEmail = $json.textPlain || $json.textHtml?.replace(/<[^>]*>/g, '') || 'Sin cuerpo';
const cuerpoResumen = cuerpoEmail.slice(0, 1900) + (cuerpoEmail.length > 1900 ? '...' : '');

// Enlace directo al email en Gmail
const enlaceEmail = `https://mail.google.com/mail/u/0/#inbox/${$json.id}`;

// Devolver datos estructurados para los próximos nodos
return {
  json: {
    nombreRemitente,
    emailRemitente,
    asunto: $json.subject,
    fechaRecepcion: $json.date,
    cuerpoResumen,
    enlaceEmail,
    idEmail: $json.id
  }
};
```
- Prueba el nodo: Verificá que el nombre y el email se separen correctamente.
