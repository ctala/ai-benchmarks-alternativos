## Entrada exacta (lo que recibió el modelo)

**user:**

Tengo estas tablas:
- orders (id, customer_id, total, status, created_at)
- customers (id, name, email, country, created_at)
- order_items (id, order_id, product_id, quantity, unit_price)
- products (id, name, category, price)

Escribe una query SQL que muestre:
- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada
- Ordena por total_revenue DESC
- Solo clientes con al menos 3 ordenes completadas (status = 'completed')


## Respuesta completa

Aquí tienes la consulta en SQL estándar (compatible con PostgreSQL, MySQL 8.0+, etc.):

```sql
WITH customer_orders AS (
    -- 1. Métricas de órdenes por cliente en los últimos 6 meses
    SELECT 
        customer_id,
        COUNT(id) AS total_orders,
        SUM(total) AS total_revenue,
        AVG(total) AS avg_order_value
    FROM orders
    WHERE status = 'completed'
      AND created_at >= CURRENT_DATE - INTERVAL '6 month'
    GROUP BY customer_id
    HAVING COUNT(id) >= 3
),
customer_category_ranking AS (
    -- 2. Ranking de categorías más compradas por cliente (por cantidad de unidades)
    SELECT 
        o.customer_id,
        p.category,
        ROW_NUMBER() OVER (
            PARTITION BY o.customer_id 
            ORDER BY SUM(oi.quantity) DESC
        ) AS rn
    FROM orders o
    INNER JOIN order_items oi ON o.id = oi.order_id
    INNER JOIN products p ON oi.product_id = p.id
    WHERE o.status = 'completed'
      AND o.created_at >= CURRENT_DATE - INTERVAL '6 month'
    GROUP BY o.customer_id, p.category
)
-- 3. Resultado final con datos de clientes y Top 10 por revenue
SELECT 
    c.name,
    c.email,
    c.country,
    co.total_orders,
    ROUND(co.total_revenue, 2) AS total_revenue,
    ROUND(co.avg_order_value, 2) AS avg_order_value,
    ccr.category AS categoria_mas_comprada
FROM customer_orders co
INNER JOIN customers c ON co.customer_id = c.id
LEFT JOIN customer_category_ranking ccr 
       ON co.customer_id = ccr.customer_id 
      AND ccr.rn = 1
ORDER BY co.total_revenue DESC
LIMIT 10;
```

### Detalles clave de la solución:
1. **Separación por CTEs (`WITH`)**: Evita el problema del producto cartesiano que duplicaría los montos de `orders` al hacer `JOIN` con `order_items`.
2. **Filtro de 3 órdenes**: Aplicado mediante `HAVING COUNT(id) >= 3` solo para órdenes completadas en el rango de fechas.
3. **Categoría más comprada**: Calculada usando la función de ventana `ROW_NUMBER()` particionada por cliente y ordenada por la suma de unidades compradas (`SUM(oi.quantity) DESC`).
4. **Compatibilidad de fechas**: Si usas **SQL Server (T-SQL)**, cambia `INTERVAL '6 month'` por `DATEADD(month, -6, GETDATE())` y el `LIMIT 10` por `SELECT TOP 10`.
