## Respuesta completa

La decisión entre facturar por adelantado o contra entrega para un cliente nuevo y desconocido depende de balancear la seguridad para tu negocio y la flexibilidad para el cliente. Aquí hay puntos clave:
- **Facturación por adelantado**: Reduce el riesgo de impago (especialmente útil si no tienes historial con el cliente), pero podría percibirse como menos conveniente para el cliente y afectar la conversión inicial.
- **Facturación contra entrega**: Puede ser más atractiva para el cliente al generar confianza, pero aumenta el riesgo de no recibir el pago o de demoras.

Una estrategia intermedia podría ser solicitar un pago parcial por adelantado (como un depósito) y el resto contra entrega, para mitigar riesgos sin ser demasiado restrictivo. También es recomendable evaluar si hay formas de verificar la solvencia del cliente (por ejemplo, referencias comerciales, si es posible) antes de decidir.

Las herramientas disponibles en este sistema están orientadas a gestionar facturas y clientes existentes, no a proporcionar asesoramiento comercial generalizado, pero puedes usarlas para emitir facturas o enviar recordatorios una vez que definas el método de pago.
