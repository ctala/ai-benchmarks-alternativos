## 🛠️ Paso a Paso Detallado (Configuración Exacta)
Primero, **pasos preparatorios obligatorios**:
1. Crear una **Integración de Notion** (https://www.notion.so/my-integrations) → Copia el `Token de Integración`
2. Crea una **Base de Datos en Notion** con estos campos (tipos exactos):
   - `Remitente Nombre` (Texto)
   - `Remitente Email` (Email)
   - `Asunto Email` (Texto)
   - `Fecha Recepción` (Fecha)
   - `Contexto` (Texto Largo)
   - `Estado` (Selección: Opciones = `Pendiente`, `Aprobada`, `Rechazada`)
3. **Comparte la Base de Datos de Notion** con tu Integración (Botón *Share* → Escribe el nombre de la Integración → Permiso *Editar*)
4. Crea una **App de Slack** (si no tienes) con permiso `chat:write` (para enviar mensajes)

---

### 1. Nodo 1: Gmail Trigger (Evento: Nuevo Email)
**Autenticación**: Conecta tu cuenta Gmail via OAuth2 (N8N lo guía automáticamente)
**Configuración**:
- Carpeta: `INBOX` (evita spam)
- Marcar como leído: `No` (para revisar luego)
- Filtro Opcional (evita spam): Agrega en *Advanced Options* → `Label IDs` = `INBOX` (excluye `SPAM`)

**Datos que devuelve**: `fromName`, `fromEmail`, `subject`, `receivedDate`, `snippet`, `id`

---

### 2. Nodo 2: Filter (Filtrar Asuntos)
*Usamos **Match Any Condition** (OR) para aceptar cualquiera de las palabras, sin importar mayúsculas/minúsculas o acentos*
**Configuración**:
- Tipo de Filtro: `Match Any Condition`
- Condición Única (usa **Regex** para cubrir acentos y case):
  - Campo: `{{ $json.subject }}`
  - Operador: `Matches Regex`
  - Valor: `/(propuesta|cotizaci[oó]n)/i`
  *¿Qué cubre?* → `propuesta`, `Propuesta`, `PROPUESTA`, `cotizacion`, `Cotización`, etc.

**Rama Falsa**: Agrega un nodo **Stop and Respond** para no gastar ejecuciones en emails que no cumplen el filtro.

---

### 3. Nodo 3: Set (Formatear Datos Limpios)
*Usamos `Set` (no código) para limpiar datos y adaptarlos a Notion/Slack. Marca **Remove Other Fields** para eliminar datos innecesarios*
**Campos a Agregar**:
| Nombre Campo          | Valor (Expresión N8N)                                                                 |
|-----------------------|----------------------------------------------------------------------------------------|
| `remitente_nombre`    | `{{ $json.fromName }}`                                                                 |
| `remitente_email`     | `{{ $json.fromEmail }}`                                                                |
| `asunto_email`        | `{{ $json.subject }}`                                                                  |
| `fecha_recepcion`     | `{{ DateTime.fromISO($json.receivedDate).toFormat('dd/MM/yyyy HH:mm') }}` (Formato legible) |
| `contexto_snippet`    | `{{ $json.snippet }}` (Primeros 100 caracteres del email para contexto)               |
| `email_id`            | `{{ $json.id }}` (ID único de Gmail para evitar duplicados luego)                     |

---

### 4. Nodo 4: Notion (Crear Item en Base de Datos)
**Autenticación**: Usa el `Token de Integración de Notion` que copiaste antes
**Configuración**:
- Tipo de Acción: `Create Database Item`
- Base de Datos: Selecciona la que compartiste (o pega su ID: sacalo del URL de Notion → `https://notion.so/[workspace]/[ID_BD]?v=...`)
- **Mapeo de Campos de Notion**:
  | Campo Notion          | Valor (Expresión N8N)                                                                 |
  |-----------------------|----------------------------------------------------------------------------------------|
  | `Remitente Nombre`    | `{{ $json.remitente_nombre }}`                                                         |
  | `Remitente Email`     | `{{ $json.remitente_email }}`                                                          |
  | `Asunto Email`        | `{{ $json.asunto_email }}`                                                             |
  | `Fecha Recepción`     | `{{ $json.fecha_recepcion }}`                                                          |
  | `Contexto`            | `{{ $json.contexto_snippet }}`                                                         |
  | `Estado`              | `Pendiente` (Valor predeterminado)                                                     |

*Nota: Notion devuelve el `url` del item creado (lo usaremos en Slack)*

---

### 5. Nodo 5: Slack (Enviar Notificación)
**Autenticación**: Conecta tu cuenta Slack via OAuth2 (N8N lo guía) o usa un `Bot Token` (`xoxb-...`)
**Configuración**:
- Destino: Elige un canal (ej: `#leads-propuestas`) o un DM (ej: `@tu_usuario`)
- Tipo de Mensaje: **Blocks** (Formato más bonito en Slack)
- **Código de Bloques Slack (JSON)**:
```json
[
  {
    "type": "header",
    "text": {
      "type": "plain_text",
      "text": "🚨 Nueva Propuesta/Cotización Recibida",
      "emoji": true
    }
  },
  {
    "type": "section",
    "fields": [
      {
        "type": "mrkdwn",
        "text": "*Remitente:*\n{{ $json.remitente_nombre }} ({{ $json.remitente_email }})"
      },
      {
        "type": "mrkdwn",
        "text": "*Asunto:*\n{{ $json.asunto_email }}"
      },
      {
        "type": "mrkdwn",
        "text": "*Fecha:*\n{{ $json.fecha_recepcion }}"
      },
      {
        "type": "mrkdwn",
        "text": "*Ver en Notion:*\n<{{ $json.url }}|Abrir Página>"
      }
    ]
  }
]
```
*Nota: `{{ $json.url }}` es el enlace directo al item de Notion creado en el paso anterior*

1. **Evitar Duplicados en Notion**: Agrega un nodo `Notion Search Database Item` después del `Set` para buscar por `email_id` → Filtra solo si no hay resultados.
2. **Cuerpo Completo del Email**: Agrega un nodo `Gmail Get Email` (usa `{{ $json.id }}` como ID) para extraer el cuerpo HTML/texto plano y guardarlo en Notion.
3. **Manejo de Errores**: Agrega un `Error Trigger` para que si el workflow falla (ej: Notion no responde), te envíe un mensaje a Slack o email.
4. **Filtro de Spam Adicional**: En el `Gmail Trigger`, agrega una condición en el `Filter` para excluir emails con etiqueta `SPAM`:
   - Campo: `{{ $json.labels }}` → Operador: `Does Not Contain` → Valor: `SPAM`
