## **Gestión de Riesgos (Realista)**
| Riesgo | Mitigación |
|--------|------------|
| Diseño UI se retrasa por aprobaciones | Dev1 empieza con estructura Tailwind usando wireframes aprobados (sin esperar UI final) |
| Integración Mailchimp falla | Usar **Formspree** como formulario backup (sin dependencia de CRM) |
| Pruebas UX muestran problemas grandes | Limitar pruebas a 5 usuarios, centrarse solo en PV y CTA (no detalles secundarios) |
| Velocidad de landing es baja | Usar TinyPNG para imágenes, CDN de Netlify, eliminar animaciones pesadas |
