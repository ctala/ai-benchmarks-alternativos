### Cómo Usar Este Workflow
#### 1. Importar en N8N
1. Abre tu instancia de N8N
2. Haz clic en **Workflows > Import Workflow**
3. Pega el JSON anterior y confirma

#### 2. Configurar Credenciales (Obligatorio)
N8N te pedirá crear credenciales para dos nodos:
##### a. OpenAI
- Crea una credencial de **OpenAI API Key** (usa tu clave de [OpenAI Platform](https://platform.openai.com/api-keys))
- El modelo usado es `gpt-3.5-turbo` (económico y suficiente para clasificación)

##### b. Slack
- Crea una credencial de **Slack API** (Bot Token)
- Necesitas un Bot de Slack con permisos:
  - `chat:write:bot` (para enviar mensajes)
  - `channels:read` (para ver canales públicos)
- Invita al Bot a los canales: `#support`, `#sales`, `#general` (escribe `/invite @NombreDelBot` en cada canal)

#### 3. Probar el Webhook
1. En el nodo **Webhook: Recibir POST**, copia la URL que genera N8N (ej: `https://tu-n8n.com/webhook/clasificar-mensajes-soporte-ventas`)
2. Envía un POST con herramientas como **Postman** o **curl** con el siguiente body JSON:
```json
{
  "email": "usuario@ejemplo.com",
  "message": "Necesito ayuda con mi pedido, no llegó el envío"
}
```

### Explicación Técnica del Flujo
| Paso | Nodo | Función |
|------|------|---------|
| 1 | Webhook POST | Escucha solicitudes POST con `email` y `message` en el body JSON |
| 2 | Set (Extraer Campos) | Limpia y extrae explícitamente `email` y `message` para evitar errores de formato |
| 3 | OpenAI | Clasifica el mensaje con un prompt **determinista** (temperature=0) para devolver solo `soporte`, `ventas` o `otro` |
| 4 | Switch | Rutea el flujo según la clasificación de OpenAI (usa `.trim()` para eliminar espacios accidentales) |
| 5 | Slack Nodos | Envía un mensaje formateado con Markdown al canal correspondiente, incluyendo email y mensaje original |
