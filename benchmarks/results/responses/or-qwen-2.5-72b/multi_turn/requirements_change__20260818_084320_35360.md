## Respuesta completa

¡Claro! Vamos a configurar un workflow en N8N que haga exactamente lo que necesitas:

1. **Trigger**: Gmail Trigger (se activa con cada email nuevo)
2. **Filtro**: Filtra los emails que contengan 'propuesta' o 'cotización' en el asunto.
3. **Extraer datos**: Function node para parsear los datos del remitente y el asunto.
4. **Guardar en Notion**: Crea una nueva entrada en una base de datos de Notion.
5. **Notificación en Slack**: Envía una notificación a un canal de Slack.

### Paso 1: Configurar el Trigger de Gmail

1. **Agrega el nodo Gmail**:
   - **Trigger Type**: `New Email`
   - **Resource**: `Email`
   - **Operation**: `On New Email`
   - Configura la conexión a tu cuenta de Gmail.

### Paso 2: Filtrar los Emails

1. **Agrega el nodo `Filter`**:
   - **Filter Type**: `String`
   - **Filter Operation**: `Contains`
   - **Filter Value**: `{{ $json["subject"] }}`
   - **Filter Condition**: `propuesta` o `cotización`
   - Usa la opción "Add Filter" para agregar ambas condiciones (propuesta y cotización) y establece el operador lógico a `OR`.

### Paso 3: Extraer los Datos del Remitente

1. **Agrega el nodo `Function`**:
   - **Function Code**:
     ```javascript
     // Parsear los datos del remitente y el asunto
     const remitente = items[0].json.from;
     const asunto = items[0].json.subject;
     const fecha = items[0].json.date;

     // Crear un objeto con los datos
     const parsedData = {
         remitente,
         asunto,
         fecha
     };

     return [items.map(item => ({ ...item.json, ...parsedData }))];
     ```

### Paso 4: Guardar en Notion

1. **Agrega el nodo `Notion`**:
   - **Resource**: `Database`
   - **Operation**: `Create`
   - Configura la conexión a tu cuenta de Notion.
   - **Database ID**: ID de la base de datos en Notion donde quieres guardar los datos.
   - **Properties**:
     - **Remitente**: `{{ $json["remitente"] }}`
     - **Asunto**: `{{ $json["asunto"] }}`
     - **Fecha**: `{{ $json["fecha"] }}`

### Paso 5: Notificación en Slack

1. **Agrega el nodo `Slack`**:
   - **Resource**: `Channel`
   - **Operation**: `Send Message`
   - Configura la conexión a tu cuenta de Slack.
   - **Channel**: ID o nombre del canal donde quieres enviar la notificación.
   - **Message**:
     ```plaintext
     Nuevo email recibido:
     Remitente: {{ $json["remitente"] }}
     Asunto: {{ $json["asunto"] }}
     Fecha: {{ $json["fecha"] }}
     ```
