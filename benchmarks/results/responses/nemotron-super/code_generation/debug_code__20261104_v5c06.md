### 1. División por cero si no hay órdenes pendientes

**El problema:**  
Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía (`len(processed) == 0`). Al ejecutar:

```python
average = total / len(processed)
```

Python lanza una excepción `ZeroDivisionError`.

**La corrección:**  
Validar que exista al menos una orden procesada antes de dividir. Si no hay ninguna, se puede asignar `0` (o `None`, según lo que necesite tu aplicación).

---

### 2. Muta el diccionario original

**El problema:**  
En Python, los diccionarios son objetos mutables y se pasan por referencia. Al hacer:

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

estás modificando el diccionario original que está fuera de la función. Esto genera efectos secundarios no deseados en el resto del programa.

**La corrección:**  
Crear una copia superficial del diccionario antes de modificarlo, por ejemplo con `order.copy()` o `{**order}`, y trabajar sobre esa copia.

---

### 3. `'count'` debería ser `len(processed)`, no `len(orders)`

**El problema:**  
El diccionario de retorno reporta:

```python
'count': len(orders)
```

Eso cuenta **todas** las órdenes recibidas, no solo las que realmente se procesaron. Como la clave se llama `count` dentro de un resultado de procesamiento, lo esperado es que refleje cuántas órdenes pasaron por el proceso.

**La corrección:**  
Cambiarlo a `'count': len(processed)`.

## Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        if order['status'] == 'pending':
            # Creamos una copia para no mutar el diccionario original
            order_copy = order.copy()
            
            discount = order_copy['total'] * 0.1 if order_copy['total'] > 100 else 0
            final_price = order_copy['total'] - discount
            
            order_copy['final_price'] = final_price
            order_copy['status'] = 'processed'
            
            total += final_price
            processed.append(order_copy)
    
    count = len(processed)
    # Evita la división por cero cuando no hay órdenes procesadas
    average = total / count if count > 0 else 0
    
    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count
    }
```
