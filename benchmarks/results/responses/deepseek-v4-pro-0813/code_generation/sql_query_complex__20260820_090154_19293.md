## Respuesta completa

Aquí tienes una consulta SQL que calcula el top 10 de clientes por revenue total en los últimos 6 meses, considerando solo órdenes completadas y clientes con al menos 3 órdenes completadas.

```sql
WITH completed_orders AS (
    SELECT
        id,
        customer_id,
        total
    FROM orders
    WHERE status = 'completed'
      AND created_at >= CURRENT_DATE - INTERVAL '6 months'
),

customer_base AS (
    SELECT
        c.id,
        c.name,
        c.email,
        c.country,
        COUNT(DISTINCT co.id) AS total_orders,
        SUM(co.total) AS total_revenue,
        AVG(co.total) AS avg_order_value
    FROM customers c
    JOIN completed_orders co ON co.customer_id = c.id
    GROUP BY c.id, c.name, c.email, c.country
    HAVING COUNT(DISTINCT co.id) >= 3
),

category_sales AS (
    SELECT
        co.customer_id,
        p.category,
        SUM(oi.quantity) AS total_quantity
    FROM completed_orders co
    JOIN order_items oi ON oi.order_id = co.id
    JOIN products p ON p.id = oi.product_id
    GROUP BY co.customer_id, p.category
),

category_ranked AS (
    SELECT
        customer_id,
        category,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY total_quantity DESC, category
        ) AS rn
    FROM category_sales
)

SELECT
    cb.name AS nombre,
    cb.email,
    cb.country AS pais,
    cb.total_orders,
    cb.total_revenue,
    cb.avg_order_value,
    cr.category AS categoria_mas_comprada
FROM customer_base cb
LEFT JOIN category_ranked cr
    ON cr.customer_id = cb.id
   AND cr.rn = 1
ORDER BY cb.total_revenue DESC
LIMIT 10;
```

**Notas y supuestos:**

- La columna `orders.total` se usa como revenue de la orden.
- `categoria_mas_comprada` se determina por la **cantidad total comprada** en esa categoría. Si quieres que sea por monto de venta, cambia `SUM(oi.quantity)` por `SUM(oi.quantity * oi.unit_price)`.
- Los últimos 6 meses se calculan con `CURRENT_DATE - INTERVAL '6 months'`. Si usas MySQL, puedes usar `CURRENT_DATE - INTERVAL 6 MONTH`; en SQL Server sería `DATEADD(month, -6, GETDATE())`.
- La consulta asume que `orders.created_at` es la fecha de creación de la orden y que las órdenes completadas tienen `status = 'completed'`.
- Se usa `ROW_NUMBER()` para obtener una sola categoría por cliente; en caso de empate en cantidad, se elige alfabéticamente la primera categoría.
