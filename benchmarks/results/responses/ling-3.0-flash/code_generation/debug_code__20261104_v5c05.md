### Bug 1: División por cero si no hay órdenes 'pending'

**Problema:** Si la lista `orders` no contiene ninguna orden con `status == 'pending'`, la lista `processed` quedará vacía. En ese caso, `total / len(processed)` intentará dividir entre cero, lanzando un `ZeroDivisionError`.

**Corrección:** Usar un condicional para calcular el promedio solo si `processed` no está vacío, o asignar un valor por defecto (como `0`):

```python
average = total / len(processed) if processed else 0
```

---

### Bug 2: Mutación del diccionario original

**Problema:** Las líneas `order['final_price'] = final_price` y `order['status'] = 'processed'` modifican directamente el diccionario `order` original que se recibe como parámetro. Esto significa que después de llamar a la función, los datos originales del llamante habrán sido alterados, lo cual es un efecto secundario inesperado y propenso a errores.

**Corrección:** Crear una copia del diccionario antes de modificarlo, usando `order.copy()`:

```python
order_copy = order.copy()
order_copy['final_price'] = final_price
order_copy['status'] = 'processed'
processed.append(order_copy)
```

---

### Bug 3: `'count'` usa `len(orders)` en lugar de `len(processed)`

**Problema:** El campo `'count'` en el diccionario retornado representa el número de órdenes **procesadas**, pero se calcula con `len(orders)`, que es el total de órdenes recibidas (incluyendo las que no eran 'pending'). Esto genera información incorrecta.

**Corrección:** Cambiar `len(orders)` por `len(processed)`:

```python
'count': len(processed)
```

```python
def process_orders(orders):
    total = 0
    processed = []
    for order in orders:
        if order['status'] == 'pending':
            # Bug 2 fix: crear copia para no mutar el original
            order_copy = order.copy()
            discount = order_copy['total'] * 0.1 if order_copy['total'] > 100 else 0
            final_price = order_copy['total'] - discount
            order_copy['final_price'] = final_price
            order_copy['status'] = 'processed'
            total += final_price
            processed.append(order_copy)

    # Bug 1 fix: proteger contra división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        # Bug 3 fix: contar solo las procesadas
        'count': len(processed)
    }
```
