### ✍️ **Comparación: Notion vs Obsidian para escribir blog posts**

| Criterio | **Notion** | **Obsidian** |
|---------|------------|--------------|
| **Edición visual** | ✅ Excelente: WYSIWYG (lo ves como quedará), sin aprender Markdown. Ideal para no tecleadores. | ⚠️ Solo en modo Markdown (o con plugins como *Markdown+*). Más rápido una vez dominado, pero curva inicial. |
| **Estructura de contenido** | ✅ Muy buena: plantillas de post, secciones, checklist, notas de investigación adjuntas. | ✅ Excelente si usás *templates* y Dataview (ej: tabla con título, keywords, borradores, estado). |

| **Exportación a publicar** | ✅ Fácil: exportar a PDF, Word, HTML (con plugins), o copiar y pegar en WordPress/Substack. | ✅✅ Muy limpia: Markdown es el estándar para blogs (WordPress, Ghost, Substack, Medium aceptan Markdown o se convierte fácil). |
| **Velocidad al escribir** | ⚠️ Buena, pero puede volverse lenta con muchas propiedades/bases de datos. | ✅✅ Muy rápida una vez configurado: te enfocás solo en el texto (sin menús ni barras). |

## 🔍 **SEO en NOTION: plugins y estrategias prácticas**

### ✅ **No hay plugins nativos de SEO en Notion**, pero podés implementar un sistema *muy efectivo* con su base de datos y propiedades.

### 🛠️ **Cómo hacer SEO en Notion (sin plugins)**

#### 1. **Crea una base de datos “Posts” con propiedades clave:**
| Propiedad | Tipo | Ejemplo |
|----------|------|---------|
| `Título` | Texto | “Cómo organizar tu día sin agotarte” |
| `URL amigable` | Texto | `/productividad-para-emprendedores` |
| `Keyword principal` | Select | `productividad emprendedores` |
| `Keywords secundarias` | Texto | `hábitos, gestión del tiempo, rutina diaria` |
| `Estado` | Select | `Borrador`, `Revisión`, `Publicado`, `Optimizado` |
| `Meta descripción` | Texto | `Descubrí 5 sistemas probados para recuperar 10h/semana sin sacrificar resultados. Ideal para emprendedores sobrecargados.` |
| `Título SEO` | Texto | `Productividad para Emprendedores: 5 Sistemas que Funcionan en 2025` |
| `Enlaces internos` | Relation | (relacionás otros posts de tu blog) |
| `Fecha de publicación` | Date | — |

📌 *Ventaja:* Tenés todo el metadata SEO visible en una tabla. Podés filtrar por “Estado = Optimizado” y ver qué posts necesitan mejora.

#### 2. **Plugins útiles (sí existen algunos):**
- **Property Tables** (por @brianpetro):  
  → Te permite ver/editar propiedades directamente desde la página (como un formulario). Ideal para completar meta descripción o keywords al escribir.  
  🔗 Instalación: [Notion Blocks](https://www.notion.so/blocks/property-tables)  
  ✅ *Ideal para ti:* te ahorra ir a la tabla cada vez.

- **Dataview (vía integración externa)**:  
  → No es nativo, pero podés usar [Notion-enhancer](https://github.com/notion-enhancer/notion-enhancer) (solo desktop) para añadir Dataview.  
  ⚠️ Requiere un poco de configuración técnica.

#### 3. **Flujo recomendado para SEO en Notion:**
1. Escribís el post en Notion (como draft).  
2. Usás la tabla “Posts” para completar:  
   - Título SEO  
   - Meta descripción  
   - Keywords (principal + secundarias)  
3. Al publicar (en WordPress, Substack, etc.), **copiás el contenido y pegás manualmente** (o usás integración con Zapier a herramientas como Ghost).  
4. En la plataforma de publicación (ej: WordPress), completás el campo SEO con esos datos (Yoast, RankMath, etc.).

> 💡 *Tip profesional:* Guardá una **guía de estilo SEO** en Notion con:  
> - Longitud ideal de títulos (50–60 caracteres)  
> - Meta descripción (150–160 caracteres)  
> - Uso de keywords en: primer párrafo, subtítulos, CTA  
> - Palabras a evitar (ej: “usted” si tu tono es cercano)
