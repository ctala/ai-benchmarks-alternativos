1. **Cómo funciona un modelo de lenguaje (LLM)**  
   Un LLM no entiende el mundo; simplemente calcula cuál es la siguiente palabra más probable a partir de enormes cantidades de texto. Es como un chef que nunca ha probado la comida, pero ha leído millones de recetas: sabe qué ingrediente suele seguir a otro, así que puede “cocinar” frases que parecen pensadas, aunque en realidad no siente el sabor.

2. **Qué es una API**  
   Una API es el mostrador por el que tu aplicación pide datos o acciones a otra aplicación sin entrar en su cocina. Imagina un búho mensajero en un juego de rol: le entregas un sobre con una orden concreta, él vuela al castillo ajeno, hace el trámite dentro y regresa con la respuesta; tú no necesitas saber qué pasó adentro, solo aprender el formato del mensaje.

3. **Qué es el fine-tuning de un modelo**  
   El fine-tuning consiste en ajustar un modelo ya entrenado para que domine una tarea o estilo específico de tu negocio. Es como contratar a un músico callejero que ya toca todos los géneros y ensayar con él solo las canciones de tu boda: no aprende música desde cero, pero recalbra su repertorio para sonar como si fuera el músico de tu evento.

4. **Qué es un rate limit**  
   Un rate limit es el máximo de peticiones que puedes hacer a un servicio en un periodo de tiempo. Es como una máquina expendedora que solo acepta cinco monedas por minuto: si le metes más, se atasca o devuelve el cambio; debes espaciar tus pedidos para que no colapse y siga sirviendo a todos.

5. **Qué es el prompt engineering**  
   El prompt engineering es diseñar la pregunta o instrucción para sacar la mejor respuesta posible del modelo. Es como darle órdenes a un ilusionista extremadamente literal: si le dices “sácame un conejo de la chistera”, te lo saca; si le dices “sácame algo que sorprenda a mis clientes”, puede salirte una paloma o confeti. La magia existe, pero depende de cómo formules el deseo.
