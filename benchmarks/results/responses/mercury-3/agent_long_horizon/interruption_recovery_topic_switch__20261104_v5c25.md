---

### 🔍 Si usas Obsidian

No hay un plugin "SEO" mágico, pero sí puedes armar un flujo de optimización con estos plugins:

- **Templater**: crea una plantilla para cada blog post con campos en el frontmatter (o "metadatos") como `title`, `description`, `keywords`, `slug`, `canonical`, etc. Así cada nota ya nace con la estructura SEO lista.
- **Dataview**: te permite crear tablas o listas con todas tus notas, mostrando el estado de cada post (si tiene descripción, si falta keyword, etc.). Es ideal para auditar tu contenido.
- **Readability Score**: calcula la legibilidad de tu texto. Aunque no es SEO puro, Google valora textos fáciles de leer.
- **Word Count**: para controlar la extensión de tus posts (suele recomendarse mínimo 1,500 palabras para SEO).
- **Obsidian Git** o **Obsidian Sync**: para publicar en tu web mediante GitHub o servicios de publicación estática (como Hugo o Jekyll). Ahí ya puedes usar plugins de SEO del propio generador.

**En resumen:** Obsidian te ayuda a *preparar* el contenido optimizado, pero el análisis SEO real (puntuación, sitemaps, meta tags) lo harás en tu plataforma de publicación.

---

### 🗂️ Si usas Notion

Notion no tiene plugins como tal, pero puedes:

- **Crear una base de datos editorial** con campos para `SEO Title`, `Meta Description`, `Keyword Principal`, `URL deseada`, etc. Así cada post tiene su ficha SEO.
- **Integrar con herramientas externas** mediante la API de Notion (por ejemplo, con Zapier o Make) para enviar el contenido a tu CMS.
- **Usar notiones o embeds** de herramientas como Semrush o Ahrefs (aunque suelen ser solo enlaces, no análisis directo).

**En resumen:** Notion es excelente para *organizar* tu estrategia SEO (calendario, keywords, briefs), pero no hace análisis automático.

---

### 🌐 Si tu blog está en WordPress (lo más común)

Ahí es donde realmente necesitas plugins SEO. Te recomiendo:

- **Yoast SEO** o **Rank Math**: son los más populares. Te dan análisis en tiempo real del contenido, meta descripciones, sitemaps, migas de pan, y más.
- **Ahrefs** o **Semrush** (son herramientas SaaS, no plugins de WordPress, pero tienen extensiones para el navegador y se integran con WordPress): para investigación de keywords y análisis de competencia.
- **WP Rocket** (para velocidad) y **Smush** (para comprimir imágenes): la velocidad también es un factor SEO.
