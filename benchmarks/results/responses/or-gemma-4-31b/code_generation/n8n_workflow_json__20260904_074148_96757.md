1.  **Importar:** Copia el JSON anterior, ve a n8n, crea un nuevo workflow y presiona `Ctrl + V` (o `Cmd + V`).
2.  **Credenciales:**
    *   Haz clic en el nodo **OpenAI Model** y selecciona o crea tu credencial de OpenAI API Key.
    *   Haz clic en los nodos de **Slack** y selecciona tu credencial de Slack (asegúrate de que el Bot de Slack tenga permisos para escribir en esos canales).
3.  **Canales de Slack:**
    *   En los nodos de Slack, he puesto los nombres de los canales (`support`, `sales`, `general`). Si tus canales tienen nombres diferentes, cámbialos en el campo "Channel".
4.  **Prueba el Webhook:**
    *   Activa el workflow o dale a "Execute Workflow".
    *   Envía un POST a la URL del webhook con este cuerpo JSON:
        ```json
        {
          "email": "cliente@ejemplo.com",
          "message": "Hola, mi pedido no ha llegado y quiero saber dónde está."
        }
        ```
    *   *Resultado esperado:* El AI Agent detectará que es "soporte" y el Switch lo enviará al canal `#support`.
