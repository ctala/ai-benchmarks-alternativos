    ```json
    }
    ```
2.  **AI Classifier (AI Agent):**
    *   Utiliza el nodo **AI Agent** conectado a un modelo de **OpenAI (gpt-4o-mini)**.
    *   El prompt está diseñado para forzar a la IA a responder con una sola palabra (`soporte`, `ventas` u `otro`), eliminando la ambigüedad para que el siguiente nodo pueda procesarlo.
    *   Se ha configurado la `temperature` en `0` para que la respuesta sea determinista y no creativa.
3.  **Route by Category (Switch):**
    *   Evalúa la salida del nodo de IA (`$json.output`).
    *   Tiene 3 rutas principales basadas en la coincidencia exacta de texto.
4.  **Slack Nodes:**
    *   Hay tres nodos de Slack configurados para canales distintos.
    *   He utilizado expresiones para recuperar los datos originales del Webhook (`$('Webhook').item.json.body.email`) ya que el nodo de IA solo pasa la clasificación, no el cuerpo original del mensaje.
