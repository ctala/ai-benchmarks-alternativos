# Análisis de Bugs y Versión Corregida

## Bug 1: División por cero

```python
average = total / len(processed)
```

**Problema:** Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía, `len(processed)` es `0`, y se lanza `ZeroDivisionError`.

**Solución:** Proteger el cálculo verificando que `processed` no esté vacío, o devolver `0` (o `None`) cuando no haya órdenes procesadas.

---

## Bug 2: Mutación del diccionario original

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

**Problema:** Se modifican directamente los diccionarios que el llamador pasó como argumento. Esto es un **efecto secundario** indeseado: el código que invoca `process_orders` verá sus órdenes originales alteradas (cambiando `status` a `'processed'` y añadiendo `final_price`), aunque el contrato lógico de la función sugiere que solo debería *leer* las órdenes y devolver un resultado.

**Solución:** Crear una copia del diccionario (por ejemplo, con `{**order, ...}`) antes de modificarlo.

---

## Bug 3: `count` incorrecto

```python
'count': len(orders)
```

**Problema:** Se devuelve el número total de órdenes recibidas, incluyendo las que **no** estaban `pending`. Esto es inconsistente con `processed` y `total`, que solo reflejan las órdenes realmente procesadas. El `count` debería representar cuántas órdenes se procesaron.

**Solución:** Usar `len(processed)`.

---

## Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Bug 2: copia inmutable del original, sin mutar
            new_order = {
                **order,
                'final_price': final_price,
                'status': 'processed',
            }

            total += final_price
            processed.append(new_order)

    # Bug 1: protección contra división por cero
    average = total / len(processed) if processed else 0

    # Bug 3: count refleja órdenes procesadas, no totales
    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed),
    }
```
