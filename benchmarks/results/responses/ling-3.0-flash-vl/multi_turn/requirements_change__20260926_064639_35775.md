## Flujo del Workflow

```
Gmail Trigger → IF (Filtro de asunto) → Notion (Crear página) → Slack (Notificación)
```

---

### Nodo 1: Gmail Trigger
- **Operación:** `On New Email` (se activa con cada correo nuevo)
- **Configuración:** Deja los valores por defecto o selecciona la bandeja de entrada específica si lo necesitas.
- Esto te entregará datos como: `from`, `subject`, `date`, `body`, etc.

---

### Nodo 2: IF (Filtro de asunto)
Usa un nodo **IF** para verificar que el asunto contenga **"propuesta"** o **"cotizacion"** (sin importar mayúsculas/minúsculas).

**Configuración:**
- **Condition:** `String`
- **Value 1:** `{{ $json.subject }}`
- **Operation:** `Contains` → `propuesta`
- Marca la casilla **"Ignore Case"** (ignorar mayúsculas/minúsculas)

Para el segundo caso, puedes usar un segundo nodo IF encadenado o, más limpiamente, usar **una sola condición con regex**:

**Opción recomendada (un solo IF con regex):**
- **Condition:** `Regular Expression`
- **Value 1:** `{{ $json.subject }}`
- **Regular Expression:** `(?i)(propuesta|cotizacion)`

> El `(?i)` hace que sea case-insensitive. Si el asunto coincide, el email pasa por la rama **True**. La rama **False** puedes dejarla vacía o conectarla a un nodo de "descartar".

---

### Nodo 3: Notion – Crear página en base de datos
- **Operación:** `Create a Page` (en una base de datos existente)
- **Database ID:** Selecciona o pega el ID de la base de datos de Notion donde guardarás los datos.

**Propiedades a crear en la base de datos de Notion:**

| Propiedad en Notion | Valor desde N8N |
|---|---|
| **Remitente (Nombre)** | `{{ $json.from.name }}` |
| **Email del remitente** | `{{ $json.from.email }}` |
| **Asunto** | `{{ $json.subject }}` |
| **Fecha del email** | `{{ $json.date }}` |
| **Cuerpo del mensaje** | `{{ $json.text || $json.body }}` |

> **Tip:** Antes del nodo de Notion, puedes agregar un nodo **Set** para limpiar o renombrar los campos y tenerlos más ordenados.

---

### Nodo 4: Slack – Enviar notificación
- **Recurso:** `Message`
- **Operación:** `Send a Message`
- **Channel:** Selecciona el canal (ej: `#notificaciones-emails` o el ID del canal)

**Mensaje de ejemplo:**
```
📩 *Nuevo email de propuesta/cotización recibido*

👤 Remitente: {{ $json.from.name }} ({{ $json.from.email }})
📌 Asunto: {{ $json.subject }}
📅 Fecha: {{ $json.date }}
```

> Puedes usar bloques de Slack (Block Kit) para un formato más visual si lo prefieres.
