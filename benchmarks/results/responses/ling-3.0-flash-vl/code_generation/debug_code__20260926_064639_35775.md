## Identificación y corrección de bugs

---

### Bug 1: División por cero si no hay órdenes 'pending'

**Problema:** Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía. Entonces `len(processed)` es `0`, y la línea:

```python
average = total / len(processed)
```

lanza un `ZeroDivisionError`.

**Corrección:** Verificar si `processed` no está vacía antes de calcular el promedio:

```python
average = total / len(processed) if processed else 0
```

---

### Bug 2: El código muta los diccionarios originales

**Problema:** Las líneas:

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

modifican directamente el diccionario `order` que pertenece a la lista original `orders`. Esto es un efecto secundario no deseado: después de llamar a la función, las órdenes originales habrán cambiado.

**Corrección:** Crear una copia del diccionario antes de modificarlo:

```python
processed_order = order.copy()
processed_order['final_price'] = final_price
processed_order['status'] = 'processed'
```

Y luego operar sobre `processed_order` en lugar de `order`.

---

### Bug 3: `'count'` usa `len(orders)` en vez de `len(processed)`

**Problema:** El campo `'count'` retorna `len(orders)`, que es el número total de órdenes recibidas, no el número de órdenes que fueron procesadas. Dado que el diccionario de retorno contiene `processed`, `total` y `average` (todos referidos a órdenes procesadas), `count` debería reflejar cuántas se procesaron.

**Corrección:**

```python
'count': len(processed)
```

## Código corregido

```python
def process_orders(orders):
    total = 0
    processed = []
    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount
            # Bug 2: crear copia para no mutar el original
            processed_order = order.copy()
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'
            total += final_price
            processed.append(processed_order)

    # Bug 1: proteger contra división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        # Bug 3: contar procesadas, no todas
        'count': len(processed)
    }
```
