## 2. Impacto Estimado en Churn (Benchmarks SaaS)

### Benchmarks de referencia
- **Churn mensual saludable SaaS B2B:** 2-5% (ProfitWell/Recurly)
- **Tu churn actual (7%):** Ya está **por encima del promedio**, señal de vulnerabilidad
- **Regla general:** Un aumento de precio del 20-30% genera aumento de churn de 1-2 puntos porcentuales
- **Tu caso (+48%):** Aumento estimado de churn: **+2 a +5 puntos porcentuales**

### Factores que MITIGAN el aumento de churn:
✅ Tu precio nuevo ($89) sigue **por debajo del promedio alto** del mercado ($29-$149)
✅ Si hay mejoras de producto que justifiquen el precio, la percepción de valor aumenta
✅ Clientes con alto engagement = menor probabilidad de churn

### Factores que AGRAVAN el aumento de churn:
⚠️ Un aumento del 48% es agresivo (no gradual)
⚠️ Sin mejoras visibles del producto, se siente como "cobrar más por lo mismo"
⚠️ El mercado de inventario tiene alternativas ( spreadsheets, otros SaaS)

## 4. Mi Recomendación con Números Concretos

### Veredicto: **SÍ sube el precio, pero NO a $89 de golpe.**

### Plan recomendado: Incremental en dos pasos

**FASE 1 — Inmediata (Mes 0):** $60 → **$69/mes** (+15%)
- Aplicar solo a **nuevos clientes**
- Benchmark: aumentos del 15% generan +0.5-1 punto de churn
- Churn estimado: 7.5%
- Clientes perdidos: ~3-5
- MRR nuevo (nuevos): +$9/cliente
- **MRR combinado estimado: ~$12,500** (+4.2%)

**FASE 2 — Mes 6 (tras validar estabilidad):** $69 → **$89/mes** (+29% adicional)
- Aplicar con grandfathering a clientes antiguos (ver estrategia abajo)
- Si churn se mantuvo ≤8% en Fase 1, proceder
- Churn estimado post-Fase 2: 9-10%
- Clientes esperados: ~165-175
- **MRR estimado: ~$15,000-16,000** (+25-33% vs actual)

### Métricas objetivo para aprobar cada fase:
| Checkpoint | Métrica | Umbral mínimo |
|---|---|---|
| Post-Fase 1 (mes 3) | Churn mensual | ≤ 8.5% |
| Post-Fase 1 (mes 3) | NPS/encuestas | ≥ 30 |
| Post-Fase 1 (mes 3) | Clientes activos | ≥ 190 |
| Pre-Fase 2 (mes 6) | Churn mensual | ≤ 8.0% |
| Pre-Fase 2 (mes 6) | MRR | ≥ $12,400 |

### Proyección a 12 meses (escenario realista ajustado):
| | Actual | Con plan escalonado |
|---|---|---|
| Precio promedio | $60 | ~$79 (blend) |
| Clientes | 200 (declinando) | ~140-160 |
| MRR | $12,000 | ~$12,500-14,500 |
| LTV/CAC | 7.0x | 7.5-9.0x |

**Mejor alternativa complementaria:** En paralelo, invierte **$3,000-5,000 en mejoras de producto** que justifiquen el precio (nuevo dashboard, reportes, integraciones). Esto puede reducir el churn en 1-2 puntos y aumentar la conversión de la Fase 2.

## 5. Estrategia de Implementación Recomendada

### Estrategia: **Grandfathering Gradual con Tiers**

```
┌─────────────────────────────────────────────────────────┐
│           MODELO DE IMPLEMENTACIÓN                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  NUEVOS CLIENTES (siempre)                             │
│  → Precio $69 desde Mes 0                              │
│  → $89 desde Mes 6                                     │
│                                                         │
│  CLIENTES EXISTENTES (grandfathering)                  │
│                                                         │
│  Tier A: >12 meses de antigüedad                       │
│  → Bloqueo de precio a $60 hasta Mes 12               │
│  → Luego migración a $79 (descuento lealtad 11%)      │
│                                                         │
│  Tier B: 6-12 meses de antigüedad                      │
│  → Bloqueo a $60 hasta Mes 6                           │
│  → Migración a $79 con 3 meses gratis (valor percibido│
│    = $79×9 = $711 vs $60×9 = $540 → se sienten          │
│    beneficiados)                                       │
│                                                         │
│  Tier C: <6 meses de antigüedad                        │
│  → Migración inmediata a $69                            │
│  → Son los más recientes y menos comprometidos          │
│                                                         │
│  MONITOREO SEMANAL                                     │
│  → Dashboard de churn por cohorte                      │
│  → Alerta si cohorte pierde >3% en un mes              │
│  → Check-in proactivo con clientes de Tier A y B       │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### Por qué NO usar otros modelos:

| Estrategia | ¿Por qué NO? |
|---|---|
| **Big Bang** ($60→$89 a todos) | Riesgo pesimista: pierdes 30-60 clientes de golpe |
| **Radical (sin grandfather)** | Genera resentimiento y churn masivo |
| **Solo nuevos** | Deja $12K/mes sobre la mesa en 200 clientes existentes |
| **Free trial extendida** | No aplica para clientes actuales, solo sirve para adquisición |

### Checklist de implementación:

- [ ] **Semana 1-2:** Definir mejoras de valor que acompañen el aumento (changelog, nuevas features)
- [ ] **Semana 3:** Crear comunicación para clientes (email + in-app)
- [ ] **Semana 4:** Lanzar Fase 1 a nuevos clientes únicamente
- [ ] **Mes 1-3:** Monitorear métricas semanalmente, encuestas NPS
- [ ] **Mes 3:** Evaluar datos vs. umbrales de checkpoints
- [ ] **Mes 4-5:** Preparar migración gradual (Tier B y C)
- [ ] **Mes 6:** Lanzar Fase 2 con grandfathering
- [ ] **Mes 9:** Evaluar nuevamente, considerar tercer escalón a $99 si métricas son saludables
- [ ] **Mes 12:** Revisar pricing completo vs. competidores

### Comunicación clave para clientes:
> *"Hemos invertido en [X mejoras específicas] que han incrementado el valor de la plataforma. Para alinear el precio con el valor entregado, los nuevos clientes ahora pagan $69/mes. Tu plan actual no cambia — como cliente valued, mantienes tu precio actual durante [X meses]."*
