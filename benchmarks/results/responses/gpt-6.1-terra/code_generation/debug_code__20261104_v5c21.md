## Respuesta completa

### Bugs

1. **División por cero:** si no hay órdenes pendientes, `processed` queda vacío y `total / len(processed)` falla. Se devuelve un promedio de `0` en ese caso.
2. **Mutación de las órdenes originales:** asignar `final_price` y cambiar `status` modifica los diccionarios recibidos. Se crea una copia antes de modificarlos.
3. **Conteo incorrecto:** `len(orders)` cuenta todas las órdenes, no solo las procesadas. Debe usarse `len(processed)`.

### Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            processed_order = order.copy()
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'

            total += final_price
            processed.append(processed_order)

    count = len(processed)
    average = total / count if count else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count
    }
```
