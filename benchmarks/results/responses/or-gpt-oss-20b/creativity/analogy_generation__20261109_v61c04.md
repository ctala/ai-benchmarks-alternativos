**1. Modelo de lenguaje (LLM)**  
El LLM es como un karaoke universal que ha memorizado la letra de cada canción del planeta. Cuando le cantas una frase, el sistema “escucha” el ritmo y genera una nueva letra que encaja perfectamente con tu melodía. Así, sin saber de antemano la respuesta exacta, logra improvisar de forma coherente y sorprendente.  

**2. API**  
Una API funciona como un traductor de negocios: tú le das una orden en el idioma de tu aplicación y el traductor la convierte al idioma que el servicio interno entiende, devolviéndote el resultado ya listo para usar. No necesitas saber cómo está construido el servicio; solo le dices qué necesitas y él se encarga de la conversación.  

**3. Fine‑tuning de un modelo**  
El fine‑tuning es como un DJ que toma una pista base y la remezcla añadiendo sus propios efectos y beats. Al “entrenar” el modelo con un dominio específico, le das la “personalidad” de tu negocio, de modo que sus salidas suenen como si las hubiera creado el propio DJ.  

**4. Rate limit**  
Un rate limit es como el número máximo de personas que puede entrar a un club nocturno por hora. Si intentas pasar más rápido, la puerta se cierra temporalmente; el sistema garantiza que la “capacidad” no se agote antes de que la próxima ronda de usuarios pueda entrar.  

**5. Prompt engineering**  
El prompt engineering es como preparar una caja de herramientas personalizada para un proyecto. Si eliges las herramientas correctas y las organizas de forma lógica, el trabajo se realiza más rápido y sin errores; de lo contrario, el proyecto puede caer en la confusión y la sobrecarga de información.
