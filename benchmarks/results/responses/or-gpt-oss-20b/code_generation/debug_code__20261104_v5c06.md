## 1. Bug #1 – **División por cero**

```python

```

Si ninguno de los pedidos tiene `status == 'pending'`, la lista `processed` queda vacía (`len(processed) == 0`).  
Dividir por cero lanza una excepción `ZeroDivisionError`.

**Solución:** comprobar si la lista está vacía antes de hacer la división.  
Una práctica común es devolver `0.0` (o `None`) cuando no hay pedidos procesados.

## Código corregido

```python
def process_orders(orders):
    """
    Procesa los pedidos que están en estado 'pending'.

    Devuelve un diccionario con:
        - processed: lista de pedidos procesados (sin mutar los originales)
        - total: suma de los precios finales
        - average: precio medio de los pedidos procesados
        - count: número de pedidos procesados
    """
    total = 0.0
    processed = []

    for order in orders:
        if order.get('status') == 'pending':
            # Copiamos el pedido para no mutar el original
            new_order = order.copy()

            # Calculamos el descuento
            total_amount = new_order.get('total', 0.0)
            discount = 0.1 * total_amount if total_amount > 100 else 0.0
            final_price = total_amount - discount

            # Añadimos las nuevas claves
            new_order.update({
                'final_price': final_price,
                'status': 'processed'
            })

            total += final_price
            processed.append(new_order)

    # Evitamos la división por cero
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```
