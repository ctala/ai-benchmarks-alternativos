## 3. Glosario de 8 Términos Internos Clave

| Término | Definición |
|---------|------------|
| **CRM** | Sistema de gestión de relaciones con clientes. Aquí se registran leads, oportunidades, seguimientos y cierres de ventas. |
| **Pipeline** | Conjunto de oportunidades de venta en diferentes etapas, desde el primer contacto hasta el cierre. |
| **KPI** | Indicador clave de desempeño. En ventas incluye métricas como llamadas diarias, reuniones agendadas y tasa de cierre. |
| **Lead** | Potencial cliente que ha mostrado interés en nuestros productos o servicios. |
| **QBR** | Reunión trimestral de revisión de negocios. Se analiza el desempeño del trimestre y se planifica el siguiente. |
| **Up-sell** | Estrategia para ofrecer al cliente actual un producto o servicio de mayor valor. |
| **Cross-sell** | Vender productos complementarios al que ya adquirió el cliente. |
| **SLA** | Acuerdo de nivel de servicio. Define los tiempos y compromisos que el equipo de ventas debe cumplir con cada cliente. |
