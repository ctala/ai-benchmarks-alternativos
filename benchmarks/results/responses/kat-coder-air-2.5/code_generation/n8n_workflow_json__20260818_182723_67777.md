## ⚙️ Configuración de Credenciales

| Credencial | Dónde configurar |
|---|---|
| **OpenAI** | `credentials.openaiApi` → API Key de OpenAI |
| **Slack** | `credentials.slackApi` → OAuth Token con scopes `chat:write` |
| **Header Auth** | `credentials.httpHeaderAuth` → Para proteger el webhook |

```json
POST https://tu-instancia-n8n/webhook/clasificar-mensaje

{
  "email": "cliente@ejemplo.com",
  "message": "Mi pedido no ha llegado, necesito ayuda"
}
```

> **Nota:** Los campos `"id"` en cada nodo son identificadores únicos. Al importarlo en n8n, asegúrate de que las credenciales estén configuradas con el mismo nombre que se indica en `"name"` dentro de cada `"credentials"`.
