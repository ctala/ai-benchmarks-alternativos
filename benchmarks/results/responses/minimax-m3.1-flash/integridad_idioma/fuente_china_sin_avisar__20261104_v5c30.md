# Zhipu AI presenta GLM-5.2 con una ventana de contexto de un millón de tokens

La compañía china Zhipu AI, conocida oficialmente como Beijing Zhipu Huazhang Technology Co., Ltd., anunció el lanzamiento de GLM-5.2, su nuevo modelo de lenguaje grande. La presentación, comunicada por la empresa, destaca tres mejoras: ampliar la cantidad de información que el sistema puede procesar en una sola operación, reducir el costo de las inferencias y fortalecer su desempeño en tareas de programación y conexión con herramientas digitales.

El cambio más visible es la ampliación de la ventana de contexto: pasa de 200 mil a un millón de tokens. En términos simples, un token es una unidad de texto que el modelo utiliza para leer y generar contenido; cuanto mayor es la ventana, más texto, código o datos puede considerar en una misma solicitud. Este avance permite trabajar con documentos extensos, bases de código o historiales de conversación sin dividirlos manualmente en fragmentos.

Zhipu AI afirma que el costo de inferencia —el procesamiento que realiza el modelo para responder a una solicitud— se redujo cerca de 40% en comparación con la versión anterior. Para las empresas que integran el modelo mediante interfaces de programación, la降幅 puede traducirse en menores costos operativos o permitir el uso de cargas de trabajo más exigentes. Sin embargo, la empresa no describió la metodología de cálculo, las condiciones de uso ni los precios definitivos.

La compañía también señala que GLM-5.2 mejora de manera notable la generación de código y la invocación de herramientas, dos funciones relevantes para el desarrollo de software y la automatización de procesos. La primera permite crear o modificar fragmentos de programación mediante instrucciones en lenguaje natural; la segunda ayuda al modelo a utilizar sistemas externos, buscar información o ejecutar acciones dentro de aplicaciones.

GLM-5.2 ya está disponible en varias plataformas de servicios en la nube y se ofrece a clientes corporativos mediante API. Según Zhipu AI, más de 3.000 empresas utilizan sus servicios de modelos. La cifra indica una base de clientes corporativos ya consolidada, aunque la compañía no publicó detalles sobre el tipo de organizaciones, el volumen de uso o su distribución geográfica.

Para empresas latinoamericanas, el modelo podría ser de interés en áreas como análisis de documentos, atención al cliente, desarrollo de software y herramientas de conocimiento interno, siempre que la API esté disponible en sus países. Una ventana de contexto mayor puede reducir la pérdida de información al procesar archivos largos, mientras que la reducción de costos podría facilitar aplicaciones de gran volumen.

El anuncio no incluye evaluaciones independientes, resultados de pruebas comparativas, precios, nombres de las plataformas en la nube ni información detallada sobre privacidad y gestión de datos.
