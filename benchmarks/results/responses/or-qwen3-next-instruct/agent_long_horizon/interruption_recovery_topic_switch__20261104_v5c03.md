## ✅ **Notion vs Obsidian: Comparación directa para tu caso**

| Criterio | **Notion** | **Obsidian** |
|--------|------------|--------------|
| **Tipo de herramienta** | App todo-en-uno (base de datos, wiki, calendario, tareas, CRM) | App de notas en Markdown, enfocada en **redes de ideas** (linked notes) |
| **Interfaz** | Visual, arrastrar y soltar, muy personalizable con bloques | Minimalista, texto puro, estilo “editor de código” |
| **Conexión de ideas** | Con links entre páginas, pero no automáticos ni visuales | ✅ **Links bidireccionales + Grafo visual** (¡tu cerebro en mapa!) |
| **Exportación / Reutilización** | Exporta a PDF, HTML, Word — pero pierde estructura | ✅ Exporta Markdown puro → ideal para copiar a WordPress, Notion, Canva, etc. |
| **Sin conexión (offline)** | Solo parcialmente (requiere cuenta y login) | ✅ 100% offline — tus notas están en tu disco duro |
| **Sincronización** | En la nube (Notion servers) | En tu nube (Dropbox, iCloud, Syncthing, etc.) — tú controlas tus datos |
| **Escalabilidad para cursos** | Excelente para organizar: módulos, lecciones, calendarios, bases de alumnos | Excelente para **desarrollar contenido**: conectar temas, descubrir patrones, crear estructuras de curso desde ideas sueltas |
| **Curva de aprendizaje** | Media (hay muchos templates, pero puede volverse caótico) | Alta al principio (Markdown, links, plugins), pero **muy poderosa una vez dominada** |
| **Costo** | Gratis hasta 5 GB; planes Pro ($8/mes) | ✅ **Gratis para uso personal** (sin límites) |
| **Ideal si…** | Quieres un “centro de operaciones” donde todo esté en un solo lugar (tareas, clientes, contenido, calendario) | Quieres que **tus ideas crezcan como un organismo vivo**, y que el contenido del curso surja naturalmente de ellas |

## 🚫 ¿Cuándo NO usar Obsidian?
- Si no te sientes cómodo con texto plano (Markdown).
- Si necesitas una interfaz visual con arrastrar y soltar para organizar tu día.
- Si quieres una app que haga todo: tareas, calendario, CRM, base de datos… en una sola pantalla.

## 🚫 ¿Cuándo NO usar Notion?
- Si quieres tener **total propiedad de tus datos** (no quieres que Notion los cierre mañana).
- Si tus ideas son caóticas y necesitas ver cómo se conectan (Notion no muestra relaciones como Obsidian).
- Si quieres trabajar sin internet todo el tiempo.
