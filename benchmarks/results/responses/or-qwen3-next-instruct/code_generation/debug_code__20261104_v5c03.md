### 🔍 **Bugs identificados y explicación:**

#### **Bug 1: División por cero si no hay órdenes pendientes**
- **Problema**: Si ninguna orden tiene `status == 'pending'`, la lista `processed` estará vacía (`len(processed) == 0`). Luego, al intentar calcular `average = total / len(processed)`, se produce un `ZeroDivisionError`.
- **Solución**: Debemos verificar si `processed` está vacío antes de hacer la división. Si está vacío, el promedio debe ser `0` o `None`, dependiendo del contexto. Aquí, por lógica de negocio, es razonable retornar `0.0` como promedio cuando no se procesó ninguna orden.

#### **Bug 2: Muta el diccionario original**
- **Problema**: El código modifica directamente los diccionarios de la lista `orders` (añade `'final_price'` y cambia `'status'`). Esto es un efecto secundario peligroso: quien llame a la función perderá los datos originales, lo cual puede romper otras partes del sistema.
- **Solución**: Debemos crear una **copia profunda** (deep copy) de cada orden antes de modificarla, o bien crear un nuevo diccionario con los datos actualizados, sin alterar los originales. Usaremos `dict()` para hacer una copia superficial (suficiente aquí, ya que no hay anidamientos complejos).

#### **Bug 3: `'count'` debería ser `len(processed)`, no `len(orders)`**
- **Problema**: El campo `'count'` en el retorno indica cuántas órdenes se procesaron, pero el código devuelve `len(orders)`, que es el total de órdenes recibidas, incluyendo las que no son `'pending'`. Esto es engañoso y incorrecto según el propósito de la función.
- **Solución**: Cambiar `'count'` a `len(processed)` para reflejar correctamente cuántas órdenes fueron procesadas.

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Copiar el pedido original y modificar solo los campos necesarios
            processed_order = dict(order)
            processed_order['status'] = 'processed'
            processed_order['final_price'] = final_price

            total += final_price
            processed.append(processed_order)

    # Evitar división por cero
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```
