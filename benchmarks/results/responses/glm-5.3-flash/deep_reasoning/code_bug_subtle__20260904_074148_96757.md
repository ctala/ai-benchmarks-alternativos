# El bug

**`remove_outliers_and_average` falla con `data = []` (lista vacía): lanza `ZeroDivisionError`.**

```python
if len(data) < 3:
    return sum(data) / len(data)  # len([]) == 0 → división por cero
```

La condición `len(data) < 3` incluye el caso `len(data) == 0`, pero el promedio de una lista vacía no está definido. Con `data = [1, 2]` funciona (devuelve 1.5), con `data = [1]` funciona (devuelve 1.0), pero con `data = []` explota.

# Caso secundario (más sutil): `mad == 0`

```python
mad = find_median([abs(x - median) for x in data])
threshold = 3 * mad  # 3 * 0 = 0
```

Si **más de la mitad de los datos son idénticos**, la mediana de las desviaciones absolutas es 0, y por lo tanto `threshold = 0`. Ejemplo:

```python
data = [5, 5, 5, 5, 100]
# median = 5
# desviaciones = [0, 0, 0, 0, 95] → mad = 0
# threshold = 0 → filtered = [5, 5, 5, 5]  (100 es descartado, correcto aquí)
```

En este caso el filtrado "funciona", pero hay un efecto colateral: **cualquier valor aunque sea mínimamente distinto de la mediana es eliminado**, incluso valores razonables:

```python
data = [5, 5, 5, 5, 5, 5.1]
# median = 5, mad = 0, threshold = 0
# filtered = [5, 5, 5, 5, 5] → promedio = 5.0 (5.1 eliminado injustificadamente)
```

Esto no es un crash, pero sí un comportamiento incorrecto: con `mad = 0` el filtro se vuelve degenerado y solo conserva valores exactamente iguales a la mediana.

# Resumen

| Entrada | Comportamiento |
|---|---|
| `[]` | `ZeroDivisionError` 💥 |
| Mayoría de valores idénticos + algunos outliers | Filtra todo lo distinto de la mediana, incluso valores normales |
| Resto | Funciona correctamente |

**Fix sugerido:**

```python
def remove_outliers_and_average(data):
    if not data:
        raise ValueError("data no puede estar vacía")
    if len(data) < 3:
        return sum(data) / len(data)

    median = find_median(data)
    mad = find_median([abs(x - median) for x in data])
    threshold = 3 * mad if mad > 0 else 0  # o usar otra estrategia cuando mad == 0

    filtered = [x for x in data if abs(x - median) <= threshold]
    return sum(filtered) / len(filtered)
```
