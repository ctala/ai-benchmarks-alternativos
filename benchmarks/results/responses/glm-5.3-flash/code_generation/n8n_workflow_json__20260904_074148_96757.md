## Cómo funciona

1. **Webhook** — Escucha peticiones POST en `/webhook/clasificar-mensaje`
2. **Extraer Campos** — Nodo Code que valida y extrae `email` y `message` del body
3. **Clasificar con IA** — OpenAI (gpt-4o-mini con temperature 0) clasifica el mensaje respondiendo solo con la categoría
4. **Preparar Canal** — Normaliza la respuesta de la IA y mapea al canal correspondiente
5. **Router por Categoría** — Nodo Switch con 3 salidas que dirige al Slack correcto
6. **Nodos Slack** — Envían el mensaje formateado al canal correspondiente
7. **Responder** — Devuelve una respuesta JSON al cliente del webhook
