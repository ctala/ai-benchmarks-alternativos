## Cómo dejarlo funcionando

1. **Importa** el JSON en n8n (Workflows → ⋯ → Import from Clipboard).
2. **Credenciales**: abre los nodos con el tag `REEMPLAZAR` y selecciona tus credenciales de **OpenAI** y **Slack** (se reutilizan en los 3 nodos de Slack al elegir la misma).
3. **Permisos de Slack**: invita al bot a los canales con `/invite @tu-bot`, o cambia `mode: "name"` por IDs de canal (`C0123456789`) en el `channelId`.
4. **Activa** el workflow y haz POST a la URL de producción.

## Notas de diseño

- **Nodo "Normalizar Clasificación"**: hace el enrutado robusto. Aunque OpenAI responda con texto extra (ej. `"Clasificación: soporte"`), el `includes()` detecta la categoría. Todo lo que no sea soporte/ventas cae en `otro`.
- **Switch con fallback**: la tercera salida ("otro") es la salida de fallback del Switch, así ningún mensaje se queda sin ruta.
- **Modelo**: usa `gpt-4o-mini` por costo/velocidad; cámbialo en el nodo "Clasificar con IA" si lo necesitas.
- Si tu versión de n8n no tiene el nodo de OpenAI, sustitúyelo por un nodo **HTTP Request** contra `https://api.openai.com/v1/chat/completions` con el mismo prompt.
