### 1. División por cero si no hay órdenes pendientes
**Explicación**: Si no hay ninguna orden con `status == 'pending'`, la lista `processed` estará vacía. Al intentar calcular el promedio (`average = total / len(processed)`), se producirá una división por cero.

**Solución**: Verificar si `processed` tiene elementos antes de calcular el promedio. Si no hay órdenes procesadas, el promedio debería ser 0.

### 2. Muta el diccionario original
**Explicación**: El código modifica directamente los diccionarios de `orders` al asignar `order['final_price']` y `order['status'] = 'processed'`. Esto es una mala práctica porque puede afectar el estado de los datos originales fuera de la función.

**Solución**: Crear una copia profunda de cada orden antes de modificarla, usando `copy.deepcopy()` para evitar mutar el original.

### 3. `'count'` debería ser `len(processed)`, no `len(orders)`
**Explicación**: El campo `count` en el resultado devuelve la cantidad total de órdenes (`len(orders)`), pero debería devolver la cantidad de órdenes procesadas (`len(processed)`), ya que es lo que tiene sentido en el contexto de la función.

**Solución**: Cambiar `len(orders)` por `len(processed)` en el retorno.

def process_orders(orders):
    total = 0

    for order in orders:
