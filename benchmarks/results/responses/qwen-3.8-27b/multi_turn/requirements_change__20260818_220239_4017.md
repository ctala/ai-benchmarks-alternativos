## Workflow: Gmail → Filtro → Notion + Slack

### Nodo 1: Gmail Trigger
- **Trigger Type**: `New Email`
- **Credential**: Tu cuenta de Gmail
- **Folder**: `INBOX` (o la carpeta que prefieras)
- **Poll Times**: Cada 1 minuto (o lo que necesites)

### Nodo 2: IF (Filtro de asunto)
- **Condition**:
  - `{{ $json.subject }}` **contains** `propuesta`
  - **OR**
  - `{{ $json.subject }}` **contains** `cotización`
- **True** → sigue al nodo 3
- **False** → termina (o a un nodo de log si quieres)

> ⚠️ Si quieres que sea case-insensitive, usa un **Code node** antes del IF:
> ```javascript
> const subject = $input.first().json.subject.toLowerCase();
> const keywords = ['propuesta', 'cotización', 'cotizacion'];
> const match = keywords.some(kw => subject.includes(kw));
> return [{ json: { ...$input.first().json, match } }];
> ```
> Y el IF verifica `{{ $json.match }}` **equals** `true`

### Nodo 3: Code (Extraer datos)
```javascript
const email = $input.first().json;
return [{
  json: {
    nombre: email.fromName || email.from.split('<')[0].trim(),
    email_remitente: email.from.split('<')[1].replace('>', ''),
    asunto: email.subject,
    fecha: email.date,
    snippet: email.snippet?.substring(0, 200) || ''
  }
}]
```

### Nodo 4: Notion (Crear página en una Database)
- **Operation**: `Create Page`
- **Database ID**: El de tu base en Notion (ej: `Propuestas recibidas`)
- **Parent Type**: `Database`
- **Properties** (mapea los campos):
  - `Title` → `{{ $json.asunto }}`
  - `Remitente` (Rich Text) → `{{ $json.nombre }}`
  - `Email` (Rich Text) → `{{ $json.email_remitente }}`
  - `Fecha` (Date) → `{{ $json.fecha }}`
  - `Resumen` (Rich Text) → `{{ $json.snippet }}`

### Nodo 5: Slack (Enviar notificación)
- **Operation**: `Send Message`
- **Channel**: `#notificaciones` (o el que uses)
- **Message**:
```
📩 Nueva propuesta/cotización recibida

👤 {{ $json.nombre }} ({{ $json.email_remitente }})
📧 Asunto: {{ $json.asunto }}
🕐 Fecha: {{ $json.fecha }}
```
