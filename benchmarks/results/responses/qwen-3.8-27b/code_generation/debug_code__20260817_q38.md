## 1. División por cero si no hay órdenes `pending`

## 2. Muta el diccionario original

Aquí:

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

`order` no es una copia, es el mismo diccionario que está dentro de la lista `orders` recibida por el parámetro.

Eso significa que si el llamador hace esto:

```python
orders = [
    {'status': 'pending', 'total': 150}
]

result = process_orders(orders)
```

Entonces `orders` queda modificado:

```python
orders[0]['status'] == 'processed'
orders[0]['final_price'] == 135.0
```

Ese es un efecto secundario no deseado. Si la función se ejecuta dos veces, la segunda vez ya no encontrará órdenes `pending`, porque la primera vez ya las cambió a `processed`.

### Corrección

Crear una copia de cada orden antes de modificarla.

Una opción simple es:

```python
new_order = order.copy()
```

Pero si el diccionario contiene estructuras anidadas, como listas o diccionarios dentro, lo más seguro es usar `copy.deepcopy`:

```python
import copy

new_order = copy.deepcopy(order)
```

Y luego modificar solo la copia:

```python
new_order['final_price'] = final_price
new_order['status'] = 'processed'
```
