## Respuesta completa



Claro. Te dejo una query usando CTEs. Asumo lo siguiente:

- El **revenue** se toma de `orders.total`.
- Solo se consideran órdenes con `status = 'completed'` en los últimos 6 meses.
- `total_orders` es la cantidad de órdenes completadas en esos últimos 6 meses.
- `categoria_mas_comprada` es la categoría con mayor cantidad de unidades vendidas; si hay empate, se elige la primera alfabéticamente.
- La query de ejemplo es para **PostgreSQL**. Al final te dejo cómo adaptarla a MySQL / SQL Server.

```sql
WITH completed_orders AS (
    SELECT
        o.id AS order_id,
        o.customer_id,
        o.total
    FROM orders AS o
    WHERE o.status = 'completed'
      AND o.created_at >= NOW() - INTERVAL '6 months'
),

customer_totals AS (
    SELECT
        customer_id,
        COUNT(DISTINCT order_id) AS total_orders,
        SUM(COALESCE(total, 0)) AS total_revenue
    FROM completed_orders
    GROUP BY customer_id
    HAVING COUNT(DISTINCT order_id) >= 3
),

category_sales AS (
    SELECT
        co.customer_id,
        p.category,
        SUM(COALESCE(oi.quantity, 0)) AS total_qty
    FROM completed_orders AS co
    JOIN order_items AS oi
      ON oi.order_id = co.order_id
    JOIN products AS p
      ON p.id = oi.product_id
    GROUP BY
        co.customer_id,
        p.category
),

category_ranked AS (
    SELECT
        customer_id,
        category,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY
                total_qty DESC,
                CASE WHEN category IS NULL THEN 1 ELSE 0 END ASC,
                category ASC
        ) AS rn
    FROM category_sales
)

SELECT
    c.name AS nombre,
    c.email AS email,
    c.country AS pais,
    ct.total_orders,
    ROUND(CAST(ct.total_revenue AS NUMERIC), 2) AS total_revenue,
    ROUND(
        CAST(ct.total_revenue AS NUMERIC) / NULLIF(ct.total_orders, 0),
        2
    ) AS avg_order_value,
    cr.category AS categoria_mas_comprada
FROM customer_totals AS ct
JOIN customers AS c
  ON c.id = ct.customer_id
LEFT JOIN category_ranked AS cr
  ON cr.customer_id = ct.customer_id
 AND cr.rn = 1
ORDER BY
    ct.total_revenue DESC,
    c.email ASC
LIMIT 10;
```

### Notas importantes

#### 1. Si usas MySQL 8

Cambia la condición de fecha por:

```sql
AND o.created_at >= NOW() - INTERVAL 6 MONTH
```

Y si `total_revenue` ya viene como `DECIMAL`, puedes simplificar el `CAST`:

```sql
ROUND(ct.total_revenue, 2) AS total_revenue,
ROUND(ct.total_revenue / NULLIF(ct.total_orders, 0), 2) AS avg_order_value
```

#### 2. Si usas SQL Server

Cambia la fecha por:

```sql
AND o.created_at >= DATEADD(MONTH, -6, GETDATE())
```

Y en lugar de `LIMIT 10`, puedes usar:

```sql
ORDER BY
    ct.total_revenue DESC,
    c.email ASC
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY;
```

O también:


#### 3. Si quieres que la categoría más comprada sea por revenue, no por cantidad

Modifica `category_sales` así:

```sql
category_sales AS (
    SELECT
        co.customer_id,
        p.category,
        SUM(oi.quantity * oi.unit_price) AS total_category_revenue
    FROM completed_orders AS co
    JOIN order_items AS oi
      ON oi.order_id = co.order_id
    JOIN products AS p
      ON p.id = oi.product_id
    GROUP BY
        co.customer_id,
        p.category
)
```

Y en `category_ranked`, ordena por:

```sql
ORDER BY
    total_category_revenue DESC,
    CASE WHEN category IS NULL THEN 1 ELSE 0 END ASC,
    category ASC
```

#### 4. Si el revenue debe calcularse desde `order_items` en vez de `orders.total`

En `customer_totals` puedes hacer algo así:

```sql
customer_totals AS (
    SELECT
        co.customer_id,
        COUNT(DISTINCT co.order_id) AS total_orders,
        COALESCE(SUM(oi.quantity * oi.unit_price), 0) AS total_revenue
    FROM completed_orders AS co
    LEFT JOIN order_items AS oi
      ON oi.order_id = co.order_id
    GROUP BY co.customer_id
    HAVING COUNT(DISTINCT co.order_id) >= 3
)
```
