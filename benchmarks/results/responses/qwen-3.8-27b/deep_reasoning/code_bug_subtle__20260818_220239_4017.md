## Respuesta completa



El bug **sutil** del bloque de outliers es el **caso degenerado en que la MAD vale `0`**.

### Exactamente cuándo falla

Falla cuando:

- la **MAD** (`median absolute deviation`) sale `0`,
- pero **no todos los datos son iguales**.

Eso ocurre, por ejemplo, cuando una **mayoría estricta** de los valores es igual a la mediana y hay al menos un valor distinto.

Ejemplo:

```python
data = [1, 1, 1, 2]
```

o, más claro para ver el problema:

```python
data = [1, 1, 1, 1.000001]
```

### Qué pasa paso a paso

Con:

```python
data = [1, 1, 1, 2]
```

1. La mediana es:

```python
median = 1
```

2. Las desviaciones absolutas son:

```python
[abs(x - median) for x in data]
# [0, 0, 0, 1]
```

3. La MAD es la mediana de esas desviaciones:

```python
mad = find_median([0, 0, 0, 1])
# mad = 0
```

4. Entonces:

```python
threshold = 3 * mad
# threshold = 0
```

5. El filtro queda así:

```python
filtered = [x for x in data if abs(x - median) <= threshold]
# abs(x - 1) <= 0
```

Eso solo deja pasar valores **exactamente iguales a la mediana**:

```python
filtered = [1, 1, 1]
```

Y la función devuelve:

```python
1.0
```

Es decir, **descarta silenciosamente el valor distinto**, aunque sea muy pequeño.

Con:

```python
data = [1, 1, 1, 1.000001]
```

también devuelve:

```python
1.0
```

aunque `1.000001` no parece un outlier en absoluto.

### Por qué falla

Porque cuando `mad == 0`, el umbral también es `0`:

```python
threshold = 3 * 0  # 0
```

Y la condición:

```python
abs(x - median) <= threshold
```

se convierte en:

```python
abs(x - median) <= 0
```

o equivalentemente:

```python
x == median
```

Así que **cualquier desviación positiva, por pequeña que sea, se trata como outlier** y se elimina.

El problema no es el algoritmo en general, sino que el código **no gestiona el caso degenerado de escala cero**.

### Cómo corregirlo

Hay que detectar explícitamente `mad == 0`. Por ejemplo:

```python
if mad == 0:
    return sum(data) / len(data)
```

o, mejor, usar otra medida de dispersión cuando la MAD es cero, como el IQR, o devolver la mediana/ media según el comportamiento deseado.

---

### Nota importante: también hay un fallo de borde con lista vacía

Además, el código tiene un fallo más simple si se llama con:

```python
remove_outliers_and_average([])
```

Porque:

```python
if len(data) < 3:
    return sum(data) / len(data)
```

con `data = []` hace:

```python
sum([]) / len([])
# 0 / 0
```

y lanza `ZeroDivisionError`.

También, si se llama directamente:

```python
find_median([])
```

falla porque con `n = 0` entra en la rama par y accede a índices inválidos.

Pero el bug **sutil** del algoritmo de outliers es el caso **`mad == 0` con datos no todos iguales**.
