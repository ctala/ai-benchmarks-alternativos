## Respuesta completa

1. **Modelo de lenguaje (LLM)**  
   **Concepto:** Un LLM es un sistema entrenado con muchísimo texto para aprender patrones de lenguaje y generar respuestas plausibles.  
   **Analogía:** Es como un **mago de cartas** que ha visto millones de mazos barajados: no “sabe” todo, pero cuando le pides una respuesta, baraja lo aprendido y te entrega una carta que encaja con el juego.

2. **API**  
   **Concepto:** Una API es una puerta controlada para que una aplicación use una función externa sin entrar al interior del sistema.  
   **Analogía:** Es como un **menú de restaurante para una cocina robótica**: tú pides “generar texto” o “buscar datos”, y el sistema te trae el plato preparado sin que tengas que cocinar por dentro.

3. **Fine-tuning de un modelo**  
   **Concepto:** El fine-tuning ajusta un modelo ya entrenado con ejemplos específicos para que responda mejor en un dominio, tono o tarea concreta.  
   **Analogía:** Es como ponerle a un **actor de doblaje universal** un guion de tu empresa: conserva su talento, pero aprende tus reglas, tu estilo y las situaciones típicas de tu negocio.

4. **Rate limit**  
   **Concepto:** Un rate limit es un límite de peticiones por tiempo para evitar abuso, saturación o uso excesivo de un servicio.  
   **Analogía:** Es como una **máquina expendedora que solo acepta una moneda cada dos segundos**: si insistes demasiado rápido, las siguientes “monedas” esperan o no se aceptan.

5. **Prompt engineering**  
   **Concepto:** Prompt engineering es diseñar instrucciones claras para guiar al modelo y obtener mejores resultados.  
   **Analogía:** Es como darle al **DJ** el mood exacto: si le dices “música”, tocará cualquier cosa; si le dices género, público, energía, límites y formato, el set empieza a parecerse a lo que querías.
