### 🇨🇱 Chile lanza programa de $50M para startups deep tech

**Por qué importa para emprendedores:** Es una señal clara de que el ecosistema latinoamericano está madurando hacia tecnologías de alto impacto y largo ciclo. Mercado Libre habilitó una API de IA para vendedores que automatiza generación de descripciones, optimización de precios dinámicos y sugerencias de cross-sell. La herramienta se integra directamente en la gestión de inventario y responde a datos de búsqueda en tiempo real.

**Por qué importa para emprendedores:** E-commerce deja de ser solo marketplace. Con esta API, las tiendas pueden competir con equipos de marketing grandes usando IA sin desarrollar infraestructura propia. Ideal para D2C y marketplaces regionales.

### 🤖 Gemma 4 de Google: el modelo open-source que compite con GPT-4o
Google lanzó Gemma 4, su familia open-weight de última generación. Ofrece rendimiento comparable a GPT-4o en tareas de lenguaje y razonamiento, con modelos de 9B y 27B optimizados para correr en GPU consumer y on-premise.

**Por qué importa para emprendedores:** Es una alternativa viable y segura para productos que necesitan privacidad y control de datos. Permite desplegar asistentes, clasificación y extracción de información sin enviar datos a terceros, clave para fintech, salud y legaltech.
