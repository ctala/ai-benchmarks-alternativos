**2. Qué es una API**
Una API es como el **panel de botones de una máquina expendedora** de alta tecnología. Tú no necesitas saber cómo funcionan los engranajes internos, los sensores de peso o el sistema de refrigeración; solo introduces una moneda, presionas "A4" y la máquina te entrega exactamente el producto que pediste. En tecnología, es una válvula de seguridad que imponen los proveedores (como OpenAI o Google) para asegurar que ninguna empresa acapare todos los recursos y el sistema siga funcionando para todos.
