## Respuesta completa

¡Entendido! Cambiar a Notion y añadir filtros y notificaciones hace que el workflow sea mucho más útil para tu negocio. 

Aquí tienes la estructura del nuevo flujo en N8N. El orden lógico será:

**Gmail Trigger** ➡️ **Filtro (IF)** ➡️ **Extracción de Datos (Set)** ➡️ **Notion** ➡️ **Slack**

A continuación, te detallo cómo configurar cada nodo:

### 1. Gmail Trigger (Lectura de correos)
*   **Evento:** `Message Received`
*   **Filtros del trigger:** Puedes dejarlo vacío para que reciba todos y filtrar después, o configurar el propio trigger de Gmail para que solo busque correos no leídos.
*   *Nota:* Asegúrate de tener las credenciales OAuth2 de Gmail conectadas correctamente.

### 2. Nodo IF o Filter (El filtro de palabras clave)
Este nodo decidirá si el correo continúa por el flujo o se descarta.
*   **Condición:** `Boolean`
*   **Operador:** `AND` / `OR` (Usa **OR** para que entre si tiene "propuesta" *o* "cotización").
*   **Regla 1:** Valor 1: `={{ $json.subject.toLowerCase() }}` | Operador: `contains` | Valor 2: `propuesta`
*   **Regla 2:** Valor 1: `={{ $json.subject.toLowerCase() }}` | Operador: `contains` | Valor 2: `cotizacion`
*(Usar `.toLowerCase()` asegura que funcione aunque escriban "Propuesta" o "COTIZACION").*

### 3. Nodo Set / Edit Fields (Extracción de datos del remitente)
Aunque Gmail ya trae los datos, este nodo sirve para limpiar y renombrar las variables para que sean fáciles de leer en Notion y Slack.
*   **Modo:** Manual
*   **Campos a crear:**
    *   `Nombre_Remitente`: `={{ $json.from.name || "Sin nombre" }}`
    *   `Email_Remitente`: `={{ $json.from.value }}`
    *   `Asunto`: `={{ $json.subject }}`
    *   `Fecha_Correo`: `={{ $json.date }}`

### 4. Nodo Notion (Guardado de datos)
*   **Acción:** `Create Page` (o `Append Row` si usas la integración de bases de datos clásica).
*   **Base de datos:** Selecciona la Database de Notion donde quieres guardar los leads.
*   **Propiedades (mapeo desde el nodo Set):**
    *   **Title (Título):** `={{ $json.Asunto }}`
    *   **Email (Rich Text / Email):** `={{ $json.Email_Remitente }}`
    *   **Nombre (Rich Text):** `={{ $json.Nombre_Remitente }}`
    *   **Fecha (Date):** `={{ $json.Fecha_Correo }}`

### 5. Nodo Slack (Notificación inmediata)
*   **Acción:** `Send Message`
*   **Canal:** Selecciona el canal donde quieres recibir las alertas (ej. `#ventas` o `#proyectos`).
*   **Mensaje:** Puedes usar bloques de texto o un mensaje simple como este:
    > 🚨 *Nueva oportunidad detectada*
    > **De:** {{ $json.Nombre_Remitente }} ({{ $json.Email_Remitente }})
    > **Asunto:** {{ $json.Asunto }}
    > 📅 Guardado en Notion.

### 💡 Consejos técnicos para N8N:
1. **Pruebas (Test Execution):** Cuando hagas la primera prueba, Gmail puede tardar unos segundos en hacer el *webhook* o *polling*. Ten paciencia y revisa el nodo Gmail Trigger para ver si el JSON trae la estructura esperada.
2. **Manejo de errores:** Si Notion o Slack fallan (por ejemplo, si cambias el nombre de una propiedad en Notion), el workflow se detendrá. Te recomiendo activar la opción **"Continue On Fail"** en los nodos de Notion y Slack, o conectar un nodo de **Error Trigger** para que te avise si algo falla.
3. **Deduplicación:** Si Gmail envía el mismo correo dos veces por algún rebote, podrías tener duplicados en Notion. Para evitarlo, puedes añadir un nodo **Filter** justo antes de Notion que consulte si el `Email_Remitente` ya existe en tu base de datos (usando la acción *Search Pages* de Notion).
