## Bugs identificados

### 1. División por cero si no hay órdenes `pending`

```python
average = total / len(processed)
```

Si ninguna orden cumple `status == 'pending'`, entonces `processed` queda vacío.

Eso provoca:

```python
ZeroDivisionError: division by zero
```

Hay que calcular el promedio solo si existe al menos una orden procesada.

---

### 2. El código muta el diccionario original

```python
order['final_price'] = final_price
order['status'] = 'processed'
processed.append(order)
```

Aquí se modifica directamente el diccionario que vino en `orders`.

Eso significa que quien llamó a la función verá cambios inesperados en sus datos originales.

Además, `processed.append(order)` guarda una referencia al mismo diccionario original, no una copia independiente.

La solución es crear una copia de la orden antes de modificarla.

---

### 3. `count` devuelve la cantidad total de órdenes, no las procesadas

```python
'count': len(orders)
```

Eso cuenta todas las órdenes recibidas, incluso las que no estaban `pending`.

Lo correcto sería:

```python
'count': len(processed)
```

## Versión corregida

```python
def process_orders(orders):
    total = 0.0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            # Crear una copia para no mutar el diccionario original
            processed_order = dict(order)

            discount = processed_order['total'] * 0.1 if processed_order['total'] > 100 else 0
            final_price = processed_order['total'] - discount

            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'

            total += final_price
            processed.append(processed_order)

    # Evitar división por cero si no hay órdenes procesadas
    average = total / len(processed) if processed else 0.0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```

## Nota opcional sobre copias

En esta corrección se usa:

```python
processed_order = dict(order)
```

Eso crea una copia superficial del diccionario. Para este caso es suficiente porque solo se agregan o modifican claves de primer nivel como `status` y `final_price`.

Si las órdenes tuvieran estructuras internas mutables, por ejemplo listas u otros diccionarios dentro de `order`, y quisieras evitar cualquier mutación indirecta, podrías usar:

```python
import copy

processed_order = copy.deepcopy(order)
```

Pero para el código mostrado, `dict(order)` es una solución simple y correcta.
