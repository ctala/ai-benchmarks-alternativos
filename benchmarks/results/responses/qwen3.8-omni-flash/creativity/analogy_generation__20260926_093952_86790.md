## Respuesta completa

1. **Cómo funciona un LLM** — Un LLM es un historietista que ha calcado millones de viñetas y dibuja la siguiente por pura probabilidad visual. No consulta verdades guardadas; reconstruye la escena porque así suelen continuar las historias. Puede sonar convincente incluso cuando inventa el final.

2. **Qué es una API** — Una API es el interfono de un búnker: hablas desde fuera, das una clave y alguien de dentro ejecuta la tarea sin que veas mapas, guardias ni maquinaria. Solo necesitas entender el código de llamada: “abre compuerta 7”. Hace que sistemas desconocidos se vuelvan usables sin derribar paredes.

3. **Qué es el fine-tuning** — Fine-tuning es meter a un actor de teatro universal en un stage intensivo con el guion, el acento y las reglas de tu compañía. No le arrancas el talento base; le ajustas el micrófono para que hable como tu marca y calle donde tú quieres. Sale menos genio suelto y más especialista contratado.

4. **Qué es un rate limit** — Un rate limit es el regulador de oxígeno de un buceo colectivo: cada persona puede pedir aire, pero la bombona entrega litros por minuto, no caprichos infinitos. Si todos abren la válvula a la vez, el sistema corta o hace esperar para no ahogar a nadie. Es una frontera amable entre demanda y supervivencia técnica.

5. **Qué es el prompt engineering** — Prompt engineering es escribir el libreto y las acotaciones para un improvisador genial: si dices “haz algo útil”, se pierde; si defines personaje, límite, tono, ejemplos y prohibiciones, clava la función. No cambias su talento, reduces el campo de posibilidades. Es dirigir la creatividad, no sustituir al director.
