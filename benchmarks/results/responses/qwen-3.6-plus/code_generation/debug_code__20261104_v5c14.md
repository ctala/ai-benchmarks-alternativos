### 🔍 Explicación de los Bugs

1. **División por cero (`ZeroDivisionError`)**  
   `average = total / len(processed)` falla cuando `processed` está vacío (es decir, cuando no hay órdenes con estado `'pending'`). `len(processed)` devuelve `0` y Python lanza una excepción.  
   ✅ *Solución:* Validar que la lista no esté vacía antes de dividir, o asignar un valor por defecto (`0` o `None`).

2. **Mutación del diccionario original**  
   En Python, los diccionarios se pasan por referencia. Al hacer `order['final_price'] = ...` y `order['status'] = ...`, estás modificando directamente los objetos originales dentro de la lista `orders`. Esto genera efectos secundarios inesperados si esa lista se reutiliza en otra parte del sistema.  
   ✅ *Solución:* Crear una copia superficial del diccionario antes de modificarlo (`order.copy()` o `{**order}`).

3. **`'count'` incorrecto**  
   `'count': len(orders)` devuelve el total de órdenes recibidas, no el número de órdenes que realmente pasaron por el flujo de procesamiento. Semánticamente, el reporte debería reflejar cuántas órdenes fueron transformadas.  
   ✅ *Solución:* Cambiar a `len(processed)`.

```python
def process_orders(orders):
    total = 0.0
    processed = []
    
    for order in orders:
        if order.get('status') == 'pending':
            # 🔧 Bug 2: Evitar mutación creando una copia del diccionario
            new_order = order.copy()
            
            order_total = new_order['total']
            discount = order_total * 0.1 if order_total > 100 else 0
            final_price = order_total - discount
            
            new_order['final_price'] = final_price
            new_order['status'] = 'processed'
            
            total += final_price
            processed.append(new_order)

    # 🔧 Bug 1: Evitar división por cero
    average = total / len(processed) if processed else 0.0

    # 🔧 Bug 3: Contar solo las órdenes procesadas
    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)
    }
```

- `if processed else 0.0`: Forma idiomática en Python para manejar listas vacías sin lanzar excepciones.
- `order.copy()`: Copia superficial suficiente para este caso. Si los diccionarios contuvieran objetos anidados, se usaría `copy.deepcopy()`.
