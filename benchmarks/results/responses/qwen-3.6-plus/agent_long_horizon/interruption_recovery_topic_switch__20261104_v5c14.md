### Turno 5 — modelo

Para colaborar con un editor freelance remoto, **Notion gana por goleada a Obsidian**, pero en la práctica el estándar más eficiente es un **flujo híbrido Notion + Google Docs**. Te lo desgloso con criterios concretos:

| **Obsidian** | ❌ No nativo (requiere Sync, Git o Dropbox) | ⚠️ Plugins limitados, sin modo sugerencia | ⚠️ Manual o vía Git | ❌ Alta (Markdown + lógica de carpetas) | Escritura solitaria + segundo cerebro |
| **Google Docs** | ✅ Excelente, estándar global | ✅ Modo sugerencia, comentarios, historial | ✅ Automático, restaurable con un clic | ✅ Nula | Edición pura + revisión final sin fricción |

### 🛠️ Flujo recomendado (solopreneur + editor remoto + lanzamiento 15/05)
1. **Notion = Centro de mando**  
   - Tablero Kanban con estados: `Idea → Brief listo → En edición → Revisado → Programado`  
   - Cada tarjeta/página incluye: deadline, enlace al Doc, checklist SEO, tono/voz, y notas para el editor.
2. **Google Docs = Espacio de edición**  
   - Compartes el link con permisos de `"Sugerencia"` o `"Comentario"`.  
   - El editor trabaja ahí: es más rápido, evita conflictos de formato y no requiere aprender Markdown ni plugins.
3. **Sincronización**  
   - Cuando el editor entrega, copias el texto final a tu CMS/Notion, marcas `"Revisado"` y programas la publicación.  
   - Mantienes el Doc como respaldo y referencia para futuras actualizaciones.
4. **Timezone-friendly**  
   - Usa `@menciones + fecha límite clara` en Notion.  
   - Define un SLA interno (ej: `"Feedback en 24h hábiles"`, `"Entrega final 48h antes de publicación"`).  
   - No dependas de tiempo real; diseña para asincronía.

⚠️ **Por qué evitar Obsidian aquí**: Obligar a un freelance a adaptarse a Markdown, sincronización manual o Git añade fricción técnica innecesaria. Con fecha fija de lanzamiento, tu prioridad es **flujo limpio, no optimización de herramientas**.

### 🥇 Recomendación principal: **Rank Math**
Es actualmente el estándar para solopreneurs por su versión gratuita robusta, interfaz intuitiva y análisis en tiempo real.

| Plugin | ✅ Por qué elegirlo | ⚠️ Cuándo evitarlo |
|---|---|---|
| **Rank Math** | Análisis de contenido paso a paso, schema automático, sugerencias de keywords, gratis cubre el 90% de lo necesario | Si activas todos los módulos a la vez (te abrumará) |
| **Yoast SEO** | Estabilidad probada, gran documentación, ideal si ya lo usas | Versión free limitada hoy en día, menos features modernas |
| **SEOPress** | Muy ligero, sin bloat, excelente rendimiento | Requiere más configuración manual, menos "guiado" |

### ⚙️ Configuración mínima para tu fase de lanzamiento (máx. 30-40 min)
1. Instala Rank Math → asistente de instalación → elige **"Fácil"**.
2. Activa solo: `Sitemap XML`, `Análisis de contenido`, `Schema básico (Article/Post)`.
3. Desactiva todo lo demás (redes sociales avanzadas, integraciones de analytics, módulos de afiliados, etc.).
4. Usa el semáforo de contenido como **guía, no como dogma**. Prioriza: intención de búsqueda clara, estructura legible (H2/H3), y CTA alineado al curso.

📌 **Nota si no usas WordPress:**
