Una API actúa como un conserje bilingüe de un hotel que recibe tu solicitud en tu idioma, entra a los talleres especializados de la ciudad usando sus propios códigos internos y te entrega el servicio listo para usar. 4. **Qué es un rate limit**
Un rate limit es el protocolo de un archivo histórico que solo permite retirar tres documentos por hora, no por mezquindad, sino porque cada extracción requiere manipulación experta y reubicación cuidadosa. Sin ese ritmo controlado, el sistema se saturaría y nadie podría acceder a la información.

El prompt engineering es el oficio de un soplador de vidrio que no moldea el material con las manos, sino que ajusta con precisión la temperatura, el flujo de aire y el giro del torno para que el cristal fundido adopte la forma exacta que imagina.
