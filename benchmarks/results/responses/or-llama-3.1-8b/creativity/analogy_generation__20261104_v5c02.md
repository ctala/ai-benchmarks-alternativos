**2. Que es una API**

Una API es como un concierge de un hotel de lujo. Cuando llegas a un hotel, el concierge te ayuda a encontrar lo que necesitas, sea un restaurante, un taxi o un servicio de lavandería. El fine-tuning de un modelo es como personalizar un vehículo deportivo. **4. Que es un rate limit**

Un rate limit es como un sistema de control de tráfico en una autopista en hora pico. Al igual que el sistema de control de tráfico limita la cantidad de vehículos que pueden pasar por la autopista en un momento determinado para evitar congestionamientos, un rate limit limita la cantidad de solicitudes que un servidor puede recibir en un período de tiempo determinado para evitar sobrecargar el sistema y evitar problemas de rendimiento.

**5. Que es el prompt engineering**

El prompt engineering es como crear un guion para un actor. Al igual que un guionista escribe un guion para que el actor conozca qué decir y cómo decirlo, el prompt engineering es el proceso de crear un enunciado claro y preciso para que un modelo de lenguaje entienda qué respuesta debe generar. Al igual que un buen guion puede hacer que el actor dé una gran actuación, un buen prompt puede hacer que el modelo de lenguaje dé una respuesta útil y relevante.
