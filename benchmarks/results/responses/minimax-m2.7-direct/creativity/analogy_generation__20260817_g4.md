# 5 Analogías Para Emprendedores (No-Técnicos)

## 1. Cómo funciona un LLM
**Concepto:** Un modelo de lenguaje genera texto prediciendo statistically qué palabra viene después, basándose en patrones aprendidos de millones de textos.

**Analogía:** Es como un compositor de jazz que ha escuchado cada canción jamás escrita: cuando le das una melodía (pregunta), improvisa una respuesta fluida y coherente que *suena* como si la hubiera compuesto en ese momento, aunque en realidad está recombining fragmentos de todo lo que memorizó.

---

## 2. Qué es una API
**Concepto:** Una API es un intermediario de software que permite que dos aplicaciones se comuniquen e intercambien datos.

**Analogía:** Es como una presa hidroeléctrica: tú no necesitas saber cómo funciona la ingeniería interna, simplemente abres la compuerta (haces la petición) y el agua (datos) fluye hacia tu negocio de manera controlada y constante.

---

## 3. Qué es el fine-tuning
**Concepto:** Fine-tuning es tomar un modelo ya entrenado y reentrenarlo con datos específicos para especializarlo en una tarea o industria.

**Analogía:** Es como contratar a un chef francés de clase mundial y enviarlo 6 meses a Perú para aprender específicamente sobre cocina nikkei: ya sabe todo sobre técnica, pero ahora domina *tu* estilo particular.

---

## 4. Qué es un rate limit
**Concepto:** Un rate limit restringe cuántas veces puedes hacer peticiones a un servicio en un período de tiempo determinado.

**Analogía:** Es como una máquina dispensadora de café en una oficina: solo sirve 50 tazas por hora para que alcance para todos; si quieres la #51, debes esperar hasta que se reinicie el contador.

---

## 5. Qué es el prompt engineering
**Concepto:** Es el arte de diseñar y optimizar inputs textuales para obtener outputs más precisos y útiles de un LLM.

**Analogía:** Es como Photography con cámara manual: la IA es una cámara ultracara, pero si no sabes ajustar apertura, ISO y encuadre, tus fotos seguirán siendo mediocres—el prompt es tu técnica fotográfica.
