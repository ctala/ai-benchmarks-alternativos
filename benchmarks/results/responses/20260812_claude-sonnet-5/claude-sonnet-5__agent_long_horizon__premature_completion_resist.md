|---------|-----------|
| **Pipeline** | Conjunto de oportunidades de venta en distintas etapas, desde prospecto hasta cierre. |
| **MQL** | *Marketing Qualified Lead*: contacto calificado por marketing como potencial cliente. |
| **SQL** | *Sales Qualified Lead*: lead validado por ventas como listo para negociación. |
| **Quota** | Meta de ventas mensual/trimestral asignada a cada vendedor. |
| **Forecast** | Proyección de ventas esperadas para un periodo determinado. |
| **Churn** | Tasa de clientes que cancelan o dejan de usar el producto/servicio. |
| **Deal Desk** | Equipo interno que aprueba condiciones especiales en negociaciones grandes. |
| **Playbook** | Guía estandarizada con scripts y estrategias para manejar objeciones y cierres. |
