## Entrada exacta (lo que recibió el modelo)

**user:**

Tengo estas tablas:
- orders (id, customer_id, total, status, created_at)
- customers (id, name, email, country, created_at)
- order_items (id, order_id, product_id, quantity, unit_price)
- products (id, name, category, price)

Escribe una query SQL que muestre:
- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada
- Ordena por total_revenue DESC
- Solo clientes con al menos 3 ordenes completadas (status = 'completed')


## Respuesta completa

Aquí tienes la query (en **PostgreSQL**; si usas MySQL/SQL Server te indico los cambios menores al final):

```sql
WITH base_data AS (
  SELECT 
    c.id AS customer_id,
    c.name,
    c.email,
    c.country,
    o.id AS order_id,
    oi.quantity,
    oi.unit_price,
    p.category
  FROM customers c
  JOIN orders o ON c.id = o.customer_id
  JOIN order_items oi ON o.id = oi.order_id
  JOIN products p ON p.id = oi.product_id
  WHERE o.status = 'completed'
    AND o.created_at >= CURRENT_DATE - INTERVAL '6 months'
),

customer_stats AS (
  SELECT 
    customer_id,
    name AS nombre,
    email,
    country AS pais,
    COUNT(DISTINCT order_id) AS total_orders,
    SUM(quantity * unit_price) AS total_revenue
  FROM base_data
  GROUP BY customer_id, name, email, country
  HAVING COUNT(DISTINCT order_id) >= 3
),

category_ranking AS (
  SELECT 
    customer_id,
    category AS categoria_mas_comprada,
    ROW_NUMBER() OVER (
      PARTITION BY customer_id 
      ORDER BY SUM(quantity) DESC, category ASC
    ) AS rn
  FROM base_data
  GROUP BY customer_id, category
)

SELECT 
  cs.nombre,
  cs.email,
  cs.pais,
  cs.total_orders,
  cs.total_revenue,
  ROUND(CAST(cs.total_revenue AS NUMERIC) / cs.total_orders, 2) AS avg_order_value,
  cr.categoria_mas_comprada
FROM customer_stats cs
JOIN category_ranking cr 
  ON cs.customer_id = cr.customer_id 
  AND cr.rn = 1
ORDER BY cs.total_revenue DESC
LIMIT 10;
```

### Explicación

| Parte | Qué hace |
|-------|----------|
| `base_data` | Une todas las tablas y filtra solo órdenes **completed** de los últimos **6 meses**. |
| `customer_stats` | Agrupa por cliente, cuenta órdenes distintas, suma el revenue (`quantity * unit_price`) y descarta a los que tengan **menos de 3 órdenes**. |
| `category_ranking` | Calcula, para cada cliente, la categoría con mayor **cantidad de productos comprados**. En empate elige la primera alfabéticamente (`category ASC`). |
| `SELECT final` | Une ambos CTEs, calcula el `avg_order_value` y ordena por `total_revenue` descendente mostrando solo el Top 10. |

### Notas para otros motores SQL

- **MySQL**:  
  - Cambia el filtro de fecha a: `o.created_at >= DATE_SUB(NOW(), INTERVAL 6 MONTH)`  
  - Cambia el `ROUND` a: `ROUND(cs.total_revenue / cs.total_orders, 2)`

- **SQL Server**:  
  - Cambia el filtro de fecha a: `o.created_at >= DATEADD(month, -6, GETDATE())`  
  - Usa `TOP (10)` al inicio del `SELECT` en lugar de `LIMIT 10`.

> **Nota sobre la categoría**: asumí que *"categoría más comprada"* es la que acumula mayor **cantidad de unidades** (`SUM(quantity)`). Si prefieres que sea por **mayor gasto** (revenue), cambia el `ORDER BY` dentro del `ROW_NUMBER()` de `category_ranking` a:  
> `ORDER BY SUM(quantity * unit_price) DESC, category ASC`
