1. **Importar**: En n8n ve a **Workflows > Importar > JSON** y pega el código anterior.
2. **Credenciales**: 
   - Configura tu cuenta de **OpenAI**.
   - Configura tu cuenta de **Slack** (necesitas un token de bot con permisos `chat:write` y acceso a los canales).
3. **Probar**: Envía una petición `POST` al webhook con este body JSON:
   ```json
   {
     "email": "usuario@ejemplo.com",
     "message": "Necesito ayuda con mi factura"
   }
   ```
4. **Resultado esperado**: 
   - El mensaje se clasifica por OpenAI.
   - El nodo **Switch** enruta según la palabra devuelta (`soporte`, `ventas` u `otro`).
   - Se publica la notificación en el canal de Slack correspondiente.
