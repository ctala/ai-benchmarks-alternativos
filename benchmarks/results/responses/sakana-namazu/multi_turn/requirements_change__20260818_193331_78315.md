## Respuesta completa

Aquí tienes la arquitectura actualizada. Lo más eficiente es **filtrar directamente en Gmail** antes de que entre a n8n, así no procesas emails innecesarios.

### Arquitectura del Workflow

```
[Gmail Trigger] 
      ↓
[Query nativo: subject:propuesta OR subject:cotizacion]
      ↓
[Set node] → Parsear Remitente (Nombre + Email)
      ↓
[Notion] → Crear entrada en base de datos
      ↓
[Slack] → Notificar al canal
```

---

### Paso 1: Gmail Trigger (con filtro nativo)
En lugar de un nodo Filter después, usa el campo **"Query"** del nodo Gmail para que Google solo devuelva lo que coincide:

```
subject:propuesta OR subject:cotizacion
```

**Configuración clave:**
- **Authentication:** OAuth2 con tu cuenta de Google.
- **Event:** `Message Received` (o `Email Added to Inbox`).
- **Query:** `subject:propuesta OR subject:cotizacion`
- **Additional Fields:** Puedes marcar `Download Attachments` si en el futuro quieres adjuntos.

> **Tip:** Usar la query nativa es mejor porque no consumes operaciones de n8n procesando emails que no te interesan.

---

### Paso 2: Set node (extraer datos del remitente)
El campo `from` de Gmail suele venir así: `Juan Pérez <juan@empresa.com>`. Vamos a separarlo.

Crea un nodo **Code** o **Set** (con expresiones) para generar estas variables:

| Variable | Expresión (modo JSON) |
|---|---|
| `nombre` | `{{ $json.from.replace(/<.*>/, '').trim() \|\| 'Sin nombre' }}` |
| `email` | `{{ $json.from.match(/<(.*)>/)?.[1] \|\| $json.from }}` |
| `asunto` | `{{ $json.subject }}` |
| `fecha` | `{{ $json.date }}` |

Si prefieres el nodo **Code** (JavaScript) para más seguridad:

```javascript
const from = $input.first().json.from || '';
const nombre = from.replace(/<.*>/, '').trim() || 'Sin nombre';
const emailMatch = from.match(/<(.*)>/);
const email = emailMatch ? emailMatch[1] : from;
const asunto = $input.first().json.subject;
const fecha = $input.first().json.date;

return [{ json: { nombre, email, asunto, fecha, link: `https://mail.google.com/mail/u/0/#inbox/${$input.first().json.id}` }}];
```

### Paso 3: Notion (Crear página en Base de Datos)
Primero, en Notion:
1. Crea una base de datos con estas propiedades:
   - **Nombre** (Title)
   - **Email** (Email)
   - **Asunto** (Rich Text)
   - **Fecha** (Date)
   - **Enlace Gmail** (URL)
2. Comparte la base de datos con tu integración de Notion (Internal Integration).

En n8n, agrega el nodo **Notion** → **Create a Database Item**:
- **Credential:** Tu integración de Notion.
- **Database:** Selecciona tu base de datos.
- **Mapeo de propiedades:**
  - `Nombre` → `{{ $json.nombre }}`
  - `Email` → `{{ $json.email }}`
  - `Asunto` → `{{ $json.asunto }}`
  - `Fecha` → `{{ $json.fecha }}`
  - `Enlace Gmail` → `{{ $json.link }}`

---

### Paso 4: Slack (Notificación)
Nodo **Slack** → **Post a Message**:
- **Credential:** Tu app/bot de Slack.
- **Channel:** El ID o nombre del canal (ej. `#leads` o `#ventas`).
- **Text:** Mensaje combinando los datos. Ejemplo:

```
📩 Nuevo email de propuesta recibido

*De:* {{ $json.nombre }} ({{ $json.email }})
*Asunto:* {{ $json.asunto }}
*Fecha:* {{ $json.fecha }}
*Enlace:* {{ $json.link }}
```

Puedes agregar un **botón** en el mensaje de Slack con un Action Block que lleve directo al hilo de Gmail si quieres sofisticarlo.

---

### Checklist para que funcione
1. **Gmail:** Tener habilitada la Gmail API en Google Cloud y el OAuth correcto.
2. **Notion:** La base de datos debe estar compartida con la integración (sino no aparecerá en el dropdown).
3. **Fechas:** Si Notion reclama el formato de fecha, asegúrate de que `$json.fecha` esté en ISO 8601. Si viene de Gmail en otro formato, usa el nodo **Date & Time** para convertirla antes de enviarla a Notion.
4. **Ejecuciones:** Si usas n8n cloud, recuerda que el trigger de Gmail puede necesitar que actives el workflow y lo dejes en modo "Active".
