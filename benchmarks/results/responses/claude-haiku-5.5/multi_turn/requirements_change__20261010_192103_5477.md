## Respuesta completa

Perfecto. Con esos cambios, el flujo queda así:

**Gmail Trigger → IF (filtro) → Code (extraer datos) → Notion (guardar) → Slack (notificar)**

---

### 1. Gmail Trigger
- **Event:** `Message Received`
- **Simplify:** activado, para recibir `from`, `subject` y `date` como campos planos.
- **Filters → Search Query:**
  ```
  subject:(propuesta OR cotizacion OR cotización)
  ```
  Esto ya reduce los emails en origen. Lo reforzamos en el siguiente nodo.

### 2. IF (filtro de seguridad)
Sirve para asegurar la coincidencia exacta y evitar falsos positivos.
- **Condición:** `{{ $json.subject.toLowerCase() }}`
- **Operador:** `contains`
- **Valor:** `propuesta`
- Agrega una segunda condición con **OR** para `cotizacion` y otra para `cotización`.

Rama **true** → sigue el flujo. Rama **false** → no hace nada.

### 3. Code (extraer datos del remitente)
En N8N actual se usa el nodo **Code** (el antiguo *Function* está obsoleto). Modo: *Run Once for Each Item*, lenguaje JavaScript:

```javascript
const from = $json.from || '';
const match = from.match(/^(.*?)\s*<(.+?)>$/);

const email = match ? match[2].trim() : from.trim();
const nombre = match ? match[1].replace(/"/g, '').trim() : email;

return {
  json: {
    nombre: nombre || email,
    email: email,
    asunto: $json.subject,
    fecha: $json.date
  }
};
```

Esto convierte `Juan Pérez <juan@empresa.com>` en nombre y email separados.

### 4. Notion (guardar en base de datos)
- **Resource:** `Database Page`
- **Operation:** `Create`
- **Database:** selecciona tu base de datos (o pega su ID).
- **Properties:** mapea cada campo. Los nombres deben coincidir con las propiedades de tu base de datos:

| Propiedad Notion | Tipo | Valor |
|---|---|---|
| Nombre | Title | `{{ $json.nombre }}` |
| Email | Email | `{{ $json.email }}` |
| Asunto | Text | `{{ $json.asunto }}` |
| Fecha | Date | `{{ $json.fecha }}` |

**Importante:** en Notion, ve a la base de datos → `...` → *Connections* y añade tu integración. Si no, dará error de permisos.

### 5. Slack (notificación)
- **Resource:** `Message`
- **Operation:** `Send`
- **Channel:** el canal donde quieres recibir avisos (por ejemplo `#propuestas`).
- **Text:**
  ```
  📩 Nueva propuesta/cotización recibida
  De: {{ $json.nombre }} ({{ $json.email }})
  Asunto: {{ $json.asunto }}
  ```

Para el bot de Slack, la app debe estar instalada en el workspace y el bot invitado al canal (`/invite @nombre_del_bot`).

### Notas útiles
- **Polling:** el Gmail Trigger revisa cada cierto tiempo (por defecto cada minuto). No es instantáneo, pero es suficiente para este caso.
- **Probar:** envía un email de prueba con "cotización" en el asunto y ejecuta el workflow manualmente antes de activarlo.
- **Acentos:** Gmail no siempre distingue acentos en búsquedas, por eso incluimos ambas variantes; el IF garantiza la coincidencia.
