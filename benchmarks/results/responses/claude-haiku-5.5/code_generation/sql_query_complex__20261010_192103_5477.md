## Respuesta completa

Aquí tienes una query en PostgreSQL. Uso `orders.total` como revenue, cuenta solo los pedidos con `status = 'completed'` de los últimos 6 meses y calcula la categoría más comprada por unidades.

```sql
WITH pedidos_recientes AS (
    SELECT o.id, o.customer_id, o.total
    FROM orders o
    WHERE o.status = 'completed'
      AND o.created_at >= CURRENT_DATE - INTERVAL '6 months'
),
resumen_clientes AS (
    SELECT
        customer_id,
        COUNT(*)                AS total_orders,
        SUM(total)              AS total_revenue,
        AVG(total)              AS avg_order_value
    FROM pedidos_recientes
    GROUP BY customer_id
    HAVING COUNT(*) >= 3
),
categoria_ranking AS (
    SELECT
        pr.customer_id,
        p.category,
        SUM(oi.quantity) AS unidades,
        ROW_NUMBER() OVER (
            PARTITION BY pr.customer_id
            ORDER BY SUM(oi.quantity) DESC, p.category
        ) AS rn
    FROM pedidos_recientes pr
    JOIN order_items oi ON oi.order_id = pr.id
    JOIN products p     ON p.id = oi.product_id
    GROUP BY pr.customer_id, p.category
)
SELECT
    c.name                       AS nombre,
    c.email                      AS email,
    c.country                    AS pais,
    r.total_orders,
    r.total_revenue,
    ROUND(r.avg_order_value, 2)  AS avg_order_value,
    cr.category                  AS categoria_mas_comprada
FROM resumen_clientes r
JOIN customers c
     ON c.id = r.customer_id
LEFT JOIN categoria_ranking cr
       ON cr.customer_id = r.customer_id
      AND cr.rn = 1
ORDER BY r.total_revenue DESC
LIMIT 10;
```

**Notas:**

- **Revenue:** uso `orders.total`. Si prefieres calcularlo desde los artículos, reemplaza `SUM(total)` por `SUM(quantity * unit_price)` y añade el join con `order_items` en el CTE de resumen.
- **Categoría más comprada:** se calcula por unidades. Para usar gasto en lugar de unidades, cambia `SUM(oi.quantity)` por `SUM(oi.quantity * oi.unit_price)` en `categoria_ranking`.
- **Empates de categoría:** se desempatan alfabéticamente por `p.category`.
- **Otros motores:** en MySQL, cambia `CURRENT_DATE - INTERVAL '6 months'` por `CURDATE() - INTERVAL 6 MONTH`. En SQL Server, usa `DATEADD(MONTH, -6, GETDATE())`.
