3. **Canales:** el bot de Slack debe estar invitado a `#support`, `#sales` y `#general` (escribe `/invite @tu-bot` en cada canal).
4. **Activar:** una vez configurado, activa el workflow. La URL del webhook de producción será algo como `https://tu-n8n/webhook/clasificar-mensaje`.

## Notas

- **Ruta de respuesta:** el webhook responde inmediatamente (`onReceived`). Si quieres devolver una respuesta con la clasificación, cambia `responseMode` a `responseNode` y añade un nodo *Respond to Webhook* al final.
- **Clasificación robusta:** la regla usa `contains` y el prompt pide una sola palabra, lo que evita fallos si el modelo añade texto. Cualquier respuesta no reconocida cae en la salida `extra`, que va a `#general`.
- **Versiones de nodos:** los `typeVersion` corresponden a n8n 1.6x o superior. Si tu versión es antigua, el importador puede avisar de incompatibilidades; en ese caso, actualiza n8n.
