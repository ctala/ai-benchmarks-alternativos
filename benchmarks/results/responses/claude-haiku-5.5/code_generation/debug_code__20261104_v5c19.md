## Bugs identificados

### 1. División por cero
```python
average = total / len(processed)
```
Si ninguna orden está en `'pending'`, `processed` queda vacía y `len(processed)` es `0`. Python lanza `ZeroDivisionError`.

**Corrección:** calcular el promedio solo si hay órdenes procesadas. Devuelvo `0.0` como valor por defecto, aunque `None` también sería razonable si prefieres distinguir "sin datos" de "promedio cero".

### 2. Mutación del diccionario original
```python
order['final_price'] = final_price
order['status'] = 'processed'
```
La función modifica las órdenes que recibió, lo que puede causar efectos secundarios inesperados en el código que la llama. Por ejemplo, si el llamador reutiliza la lista, las órdenes ya aparecen como `'processed'`.

**Corrección:** trabajar sobre una copia de cada orden (`{**order, ...}`).

### 3. `count` usa `len(orders)`
```python
'count': len(orders)
```
El diccionario devuelto tiene una clave `'processed'` con las órdenes procesadas, pero `count` cuenta todas las órdenes de entrada, incluidas las que no estaban en `'pending'`. Eso es inconsistente con el resto del resultado. Si `count` debe representar las órdenes procesadas, debe ser `len(processed)`. Si la intención es mostrar el total recibido, conviene renombrarla a `total_orders` para que no haya confusión.

### 4. Problemas adicionales

- **Precisión de punto flotante:** sumar montos monetarios con `float` produce errores de redondeo (por ejemplo, `0.1 + 0.2 != 0.3`). Redondear a 2 decimales ayuda en la mayoría de casos. Para dinero real, lo más correcto es usar `decimal.Decimal`.
- **Lógica de descuento difícil de leer:** no es un bug, pero el cálculo puede expresarse más claramente.

## Versión corregida

```python
def process_orders(orders):
    total = 0.0
    processed = []

    for order in orders:
        if order['status'] != 'pending':
            continue

        # Copia la orden para no mutar el diccionario original
        updated = {**order}

        discount = updated['total'] * 0.1 if updated['total'] > 100 else 0
        final_price = round(updated['total'] - discount, 2)

        updated['final_price'] = final_price
        updated['status'] = 'processed'

        total += final_price
        processed.append(updated)

    # Evita la división por cero
    average = round(total / len(processed), 2) if processed else 0.0

    return {
        'processed': processed,
        'total': round(total, 2),
        'average': average,
        'count': len(processed),  # órdenes efectivamente procesadas
    }
```
