4. **Que es un rate limit**

5. **Que es el prompt engineering**
Es redactar una carta de prenda tan precisa que el sastre sin imaginación pueda cortar la tela perfecta a la primera. No se trata de “pedir con ingenio”, sino de especificar el contexto, el formato, los límites y el ejemplo exacto para que el sistema no adivine, sino que siga tu guía como un operario que monta un mueble con instrucciones impecables.
