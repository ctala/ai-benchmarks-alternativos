## 🔍 Bugs identificados y explicación

### 1. División por cero cuando no hay órdenes `'pending'`
- **Causa:** Si ninguna orden tiene estado `'pending'`, la lista `processed` queda vacía (`len(processed) == 0`). Luego se ejecuta `average = total / len(processed)`, lo que genera un `ZeroDivisionError`.
- **Solución:** Verificar si `processed` no está vacía antes de calcular el promedio. Si está vacía, asignar un valor por defecto (por ejemplo `0` o `None`).

### 2. Mutación del diccionario original
- **Causa:** Dentro del bucle se modifica directamente el diccionario `order` (se agregan las claves `'final_price'` y se cambia `'status'`). Esto altera la lista original de órdenes que se pasó como argumento, lo que puede generar efectos secundarios no deseados (pérdida de datos originales, problemas en otros procesos que usen la misma lista).
- **Solución:** Trabajar con una copia del diccionario (`order.copy()`) para no afectar el original.

### 3. `'count'` debería reflejar solo las órdenes procesadas
- **Causa:** Actualmente `'count'` se calcula como `len(orders)`, que cuenta **todas** las órdenes originales, incluyendo las que no tenían estado `'pending'`. Según la especificación (y el sentido lógico), debería contar únicamente las órdenes que fueron procesadas.
- **Solución:** Cambiar `len(orders)` por `len(processed)`.

## ✅ Código corregido

```python
def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        if order['status'] == 'pending':
            # Copia del diccionario para no mutar el original
            order_copy = order.copy()
            
            # Cálculo del descuento y precio final
            discount = order_copy['total'] * 0.1 if order_copy['total'] > 100 else 0
            final_price = order_copy['total'] - discount
            
            # Actualizar la copia con los nuevos campos
            order_copy['final_price'] = final_price
            order_copy['status'] = 'processed'
            
            total += final_price
            processed.append(order_copy)
    
    # Evitar división por cero
    if processed:
        average = total / len(processed)
    else:
        average = 0  # o None, según se requiera
    
    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Solo las procesadas
    }
```
