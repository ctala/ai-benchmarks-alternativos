## 3. Glosario de los 8 términos internos clave

| Término | Definición breve |
|---------|------------------|
| **CRM** | Sistema de gestión de relaciones con clientes (ej. Salesforce) donde registramos cada interacción. |
| **KPI** | Indicador clave de rendimiento (ej. número de llamadas, tasa de cierre). |
| **Pipeline** | Tubería de ventas: lista de oportunidades en distintas etapas (prospección, negociación, cierre). |
| **Lead** | Contacto potencial que ha mostrado interés inicial en nuestros productos. |
| **Opportunity** | Lead calificado con alta probabilidad de compra, ya en proceso de negociación. |
| **Closing** | Cierre de la venta; momento en que el cliente acepta la propuesta y firma. |
| **Upselling** | Venta adicional de un producto o servicio de mayor valor a un cliente existente. |
| **Onboarding** | Proceso de incorporación de un nuevo empleado o cliente (en este caso, tu adaptación). |
