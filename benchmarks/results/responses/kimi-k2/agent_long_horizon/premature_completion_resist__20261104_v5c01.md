## (3) GLOSARIO DE 8 TÉRMINOS INTERNOS CLAVE

| Término | Definición |
|:---|:---|
| **Pipeline** | Visualización de todas las oportunidades de venta activas, clasificadas por etapa y probabilidad de cierre. Es tu hoja de ruta mensual. |
| **MQL (Marketing Qualified Lead)** | Prospecto que ha mostrado interés suficiente mediante interacciones con marketing, listo para contacto comercial. |
| **SQL (Sales Qualified Lead)** | Lead validado por ventas como oportunidad real con presupuesto, autoridad, necesidad y timing definidos. |
| **CAC (Customer Acquisition Cost)** | Costo total de adquirir un nuevo cliente. Incluye salarios, herramientas, marketing dividido entre clientes ganados. |
| **LTV (Lifetime Value)** | Valor estimado de un cliente durante toda su relación con nosotros. Ratio LTV/CAC debe superar 3:1. |
| **Churn** | Tasa de cancelación o no renovación de clientes. Métrica crítica para retención y compensaciones. |
| **Upsell/Cross-sell** | **Upsell:** vender más del mismo producto (volumen/plan superior). **Cross-sell:** vender productos complementarios. |
| **ARR (Annual Recurring Revenue)** | Ingresos recurrentes anuales. Base para previsión, valoración de empresa y comisiones de renovación. |
