## Respuesta completa

Este código tiene 3 bugs, y están relacionados entre sí:

### Bug 1: División por cero

```python
average = total / len(processed)
```

Si `orders` está vacía, o si ninguna orden tiene `status == 'pending'`, entonces `processed` será `[]` y `len(processed)` será `0`.

Eso provoca:

```python
ZeroDivisionError: division by zero
```

**Corrección:** Calcular el promedio solo si hay elementos, en caso contrario devolver `0`.

```python
average = total / len(processed) if processed else 0
```

### Bug 2: Muta el diccionario original

```python
order['final_price'] = final_price
order['status'] = 'processed'
processed.append(order)
```

En Python, los diccionarios se pasan por referencia. Al modificar `order`, estás modificando también el diccionario original que recibió la función.

Efecto secundario inesperado:

```python
orders = [{'id': 1, 'status': 'pending', 'total': 200}]
process_orders(orders)
print(orders)
# [{'id': 1, 'status': 'processed', 'total': 200, 'final_price': 180.0}]
# ¡La lista original cambió!
```

Esto además hace que una segunda llamada a `process_orders(orders)` ya no procese nada, porque ya no quedan órdenes `pending`.

**Corrección:** Trabajar sobre una copia.

```python
new_order = order.copy()
new_order['final_price'] = final_price
new_order['status'] = 'processed'
processed.append(new_order)
```

> `copy()` hace una copia superficial, suficiente aquí porque los valores son números/strings. Si hubiera diccionarios o listas anidadas, usarías `copy.deepcopy()`.

### Bug 3: `'count'` cuenta las órdenes equivocadas

```python
'count': len(orders)
```

`total` y `average` se calculan solo sobre las órdenes procesadas, pero `count` devuelve **todas** las recibidas (incluidas las `completed`, `cancelled`, etc.).

El resultado es inconsistente: `count != len(processed)`, lo que confunde a quien consume el resultado.

**Corrección:**

```python
'count': len(processed)
```

Si necesitaras ambos datos, lo correcto sería devolverlos con nombres distintos: `'count': len(processed), 'total_orders': len(orders)`.

### Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Copia para no mutar el original
            new_order = order.copy()
            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            total += final_price
            processed.append(new_order)

    # Evita ZeroDivisionError
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Solo las procesadas
    }
```
