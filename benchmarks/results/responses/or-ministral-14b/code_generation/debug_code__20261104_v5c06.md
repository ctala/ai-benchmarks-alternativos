```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Crear una copia del diccionario para evitar mutar el original
            processed_order = order.copy()
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'

            total += final_price
            processed.append(processed_order)

    # Manejar el caso donde no hay órdenes procesadas
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Corregido: solo las procesadas
    }
```

### Mejoras realizadas:
1. **Evitar división por cero**:
   - Se usa un operador ternario (`if processed else 0`) para manejar el caso donde `processed` esté vacío.

2. **No mutar el diccionario original**:
   - Se crea una copia del diccionario (`order.copy()`) antes de modificarla, para evitar alterar los datos originales.

3. **Corregir `count`**:
   - Ahora devuelve `len(processed)` en lugar de `len(orders)`.
