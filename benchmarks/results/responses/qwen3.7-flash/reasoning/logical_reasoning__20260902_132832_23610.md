### 🔹 Paso 1: Traducir las condiciones a expresiones matemáticas
Asignamos una variable a cada equipo: `A, B, C, D, E` representan el número de miembros.
Según el enunciado:
1. `B < A < C`
2. `D = A`
3. `E < A, E < B, E < C, E < D` (E es menor que todos los demás)
4. `A + B + C + D + E = 60`

### 🔹 Paso 2: Sustituir los datos conocidos en la suma total
Sustituimos `B = 10`, `D = A` y `C = 2E` en la ecuación de la suma:
```
A + 10 + 2E + A + E = 60
→ 2A + 3E + 10 = 60
→ 2A + 3E = 50
```

Despejamos `A` en función de `E`:
```
2A = 50 - 3E
→ A = (50 - 3E) / 2   ...(Ecuación 1)
```

### 🔹 Paso 3: Acotar el valor de E usando las desigualdades
De la condición 1 sabemos que: `B < A < C`

```
10 < (50 - 3E)/2 < 2E
```
Resolvemos por partes:

**a) Límite inferior:** `10 < (50 - 3E)/2`
```
20 < 50 - 3E
3E < 30
E < 10
```

**b) Límite superior:** `(50 - 3E)/2 < 2E`
```
50 - 3E < 4E
50 < 7E
E > 50/7 ≈ 7.14
```

Combinando ambas: `7.14 < E < 10`  
Como `E` debe ser un número entero (no pueden haber fracciones de persona), los únicos candidatos son: **E = 8 o E = 9**.
