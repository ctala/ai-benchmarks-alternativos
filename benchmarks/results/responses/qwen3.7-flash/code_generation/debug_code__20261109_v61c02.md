### 🔍 Explicación de los Bugs

#### 1. División por cero
- **Problema:** Si ningún pedido tiene `status == 'pending'`, la lista `processed` permanece vacía. Al ejecutar `average = total / len(processed)`, Python lanza un `ZeroDivisionError`.
- **Solución:** Evaluar si `processed` tiene elementos antes de dividir. Si está vacía, se asigna `0` (o `None`) al promedio.

#### 2. Mutación del estado original
- **Problema:** La función modifica directamente los diccionarios dentro de la lista `orders` (`order['final_price'] = ...` y `order['status'] = 'processed'`). En Python, las listas y diccionarios se pasan por referencia, por lo que estos cambios afectan al objeto original fuera de la función. Esto genera efectos secundarios difíciles de depurar.
- **Solución:** Trabajar sobre una **copia** de cada orden (`order.copy()`) antes de aplicar modificaciones, preservando los datos originales intactos.

#### 3. Campo `'count'` incorrecto
- **Problema:** `'count': len(orders)` devuelve el número total de órdenes recibidas, pero semánticamente debería indicar cuántas fueron **procesadas correctamente**.
- **Solución:** Cambiar a `'count': len(processed)`.

```python
def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        if order['status'] == 'pending':
            # Evitar mutación: trabajar con una copia superficial
            processed_order = order.copy()
            
            discount = processed_order['total'] * 0.1 if processed_order['total'] > 100 else 0
            final_price = processed_order['total'] - discount
            
            processed_order['final_price'] = final_price
            processed_order['status'] = 'processed'
            
            total += final_price
            processed.append(processed_order)

    # Prevenir división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Corrección del bug 3
    }
```

### 💡 Notas adicionales de buenas prácticas
- Se usa `order.copy()` (copia superficial). Dado que los valores esperados son primitivos (`str`, `int`/`float`), es suficiente. Si los diccionarios contuvieran estructuras anidadas, se recomendaría `copy.deepcopy(order)`.
- El uso de `if processed else 0` es idiomático en Python y evita llamadas redundantes a `len()`.
- Si en tu dominio de negocio prefieres que el promedio sea `None` cuando no hay datos procesados, cambia `else 0` por `else None` para evitar confusiones matemáticas.
