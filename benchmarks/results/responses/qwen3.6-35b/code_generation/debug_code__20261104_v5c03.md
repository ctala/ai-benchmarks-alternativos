### 🔍 Explicación de los bugs

1. **División por cero (`ZeroDivisionError`)**  
   Si ninguna orden tiene `status == 'pending'`, la lista `processed` quedará vacía. Al ejecutar `average = total / len(processed)`, Python intentará dividir por `0` y lanzará un error.  
   ✅ **Solución:** Usar una expresión condicional para calcular el promedio solo si hay elementos procesados, devolviendo `0` (o `None`) en caso contrario.

2. **Mutación del diccionario original (Efectos secundarios)**  
   El código modifica directamente los objetos `order` de la lista de entrada (`order['final_price'] = ...`, `order['status'] = ...`) y los añade a `processed`. Esto altera los datos originales fuera de la función, lo cual es una mala práctica porque rompe la transparencia referencial y puede causar bugs en otras partes del programa que usen la misma lista.  
   ✅ **Solución:** Crear una copia de cada orden antes de modificarla, usando `.copy()`.

3. **Contador incorrecto en `'count'`**  
   `'count': len(orders)` devuelve el número total de órdenes recibidas, sin importar si fueron procesadas o no. Según el contexto de la función, debería reflejar cuántas órdenes pasaron el filtro y fueron procesadas.  
   ✅ **Solución:** Cambiar a `'count': len(processed)`.

```python
def process_orders(orders):
    total = 0
    processed = []
    
    for order in orders:
        if order['status'] == 'pending':
            # Bug 2: Crear copia para no mutar el diccionario original
            order_processed = order.copy()
            
            discount = order_processed['total'] * 0.1 if order_processed['total'] > 100 else 0
            final_price = order_processed['total'] - discount
            
            order_processed['final_price'] = final_price
            order_processed['status'] = 'processed'
            
            total += final_price
            processed.append(order_processed)

    # Bug 1: Evitar división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Bug 3: Contar solo las procesadas
    }
```
