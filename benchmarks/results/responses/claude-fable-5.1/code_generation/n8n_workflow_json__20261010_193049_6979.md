## Cómo funciona

| Nodo | Función |
|---|---|
| **Webhook** | Recibe `POST /webhook/clasificar-mensaje` y responde `200` inmediatamente |
| **Extraer Datos** | Saca `body.email` y `body.message` a campos planos |
| **OpenAI - Clasificar** | Prompt de sistema restringe la respuesta a `soporte` / `ventas` / `otro` (temperatura 0 para consistencia) |
| **Normalizar Resultado** | Limpia la respuesta del modelo (trim, minúsculas, sin puntuación) y recupera `email`/`message` del nodo anterior |
| **Switch** | Rama 0 → soporte, rama 1 → ventas, **fallback** → otro (así cualquier respuesta inesperada del modelo cae en `#general`) |
| **Slack ×3** | Publica el mensaje formateado en el canal correspondiente |

## Pasos después de importar

1. **Credenciales**: abre los nodos de OpenAI y Slack y selecciona tus credenciales (los IDs `REEMPLAZAR_...` se sustituirán automáticamente al elegirlas).
2. **Slack**: tu app debe tener los scopes `chat:write` y `chat:write.public` (o estar invitada a los tres canales).
3. **Activa** el workflow para obtener la URL de producción.
4. **Prueba**:

```bash
curl -X POST https://TU-N8N/webhook/clasificar-mensaje \
  -H "Content-Type: application/json" \
  -d '{"email":"cliente@ejemplo.com","message":"La app se cierra cuando intento exportar un PDF"}'
```

Debería llegar a `#support`.

## Variantes opcionales

- **Responder con la categoría al cliente**: cambia `responseMode` del Webhook a `"responseNode"` y añade un nodo *Respond to Webhook* al final de cada rama devolviendo `{{ $json.categoria }}`.
- **Modelo más barato / otro proveedor**: cambia `modelId` a `gpt-3.5-turbo`, o sustituye el nodo OpenAI por un *Basic LLM Chain* con cualquier modelo (Anthropic, Gemini, Ollama…) — el nodo *Normalizar Resultado* solo tendría que leer `$json.text` en vez de `$json.message.content`.
