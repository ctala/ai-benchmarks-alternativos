## Respuesta completa

Los tres bugs que señalas son correctos. Aquí va la explicación de cada uno y la versión corregida.

## Bug 1: División por cero

```python
average = total / len(processed)
```

Si ninguna orden tiene `status == 'pending'`, `processed` queda vacía y `len(processed)` es `0`. Python lanza `ZeroDivisionError`. Es un caso perfectamente normal (una lista vacía o solo órdenes ya procesadas), así que la función fallaría en producción con frecuencia.

**Fix:** calcular el promedio solo si hay elementos; si no, devolver `0` (o `None`, según lo que prefiera el consumidor).

## Bug 2: Mutación del diccionario original

```python
order['final_price'] = final_price
order['status'] = 'processed'
```

Los diccionarios en Python se pasan por referencia. Al modificar `order`, se está alterando el objeto que vive en la lista `orders` del llamador. Esto produce efectos secundarios silenciosos: quien llamó a la función ve sus datos cambiados sin haberlo pedido, y si vuelve a invocar `process_orders` con la misma lista, ya no encontrará órdenes `pending`.

**Fix:** trabajar sobre una copia (`dict(order)` o `order.copy()`; `copy.deepcopy` si hay estructuras anidadas que también se modifiquen).

## Bug 3: `count` cuenta lo incorrecto

```python
'count': len(orders)
```

El resto del resultado (`processed`, `total`, `average`) describe únicamente las órdenes procesadas, pero `count` devuelve el tamaño de la lista de entrada completa. Es inconsistente y engañoso: con 10 órdenes de las cuales 2 son `pending`, el resultado diría `count: 10`.

**Fix:** usar `len(processed)`.

## Bonus: robustez ante claves faltantes

No es un bug estricto del enunciado, pero `order['status']` y `order['total']` lanzan `KeyError` si alguna orden viene incompleta. Usar `.get()` lo hace más tolerante.

## Versión corregida

```python
def process_orders(orders):
    total = 0
    processed = []

    for order in orders:
        if order.get('status') != 'pending':
            continue

        # Copia para no mutar el objeto del llamador
        new_order = dict(order)

        order_total = new_order.get('total', 0)
        discount = order_total * 0.1 if order_total > 100 else 0
        final_price = order_total - discount

        new_order['final_price'] = final_price
        new_order['status'] = 'processed'

        total += final_price
        processed.append(new_order)

    count = len(processed)
    average = total / count if count > 0 else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': count,
    }
```
