## Respuesta completa

Sin problema, el workflow queda así:

**Flujo actualizado:**

1. **Gmail Trigger** → se activa con cada email nuevo
2. **IF node** → filtra por asunto
3. **Set/Code node** → extrae y da formato a los datos
4. **Notion node** → crea una página en la base de datos
5. **Slack node** → envía la notificación

**Detalle de cada nodo:**

**1. Gmail Trigger**
- Event: *Message Received*
- Opcional: en *Filters* puedes poner una query de Gmail directamente: `subject:(propuesta OR cotizacion)`. Esto filtra desde Gmail y te ahorras el nodo IF. Lo dejo como alternativa, pero el IF te da más control.

**2. IF node** (si no usas el filtro de Gmail)
- Condición tipo *String* → *Contains*
- Value 1: `{{ $json.subject.toLowerCase() }}`
- Agregas dos condiciones con **OR**: una para `propuesta` y otra para `cotizacion`
- El `.toLowerCase()` es para que también capture "Propuesta" o "COTIZACIÓN"

**3. Set node** (extracción de datos)
- `nombre`: `{{ $json.from.value[0].name }}`
- `email`: `{{ $json.from.value[0].address }}`
- `asunto`: `{{ $json.subject }}`
- `fecha`: `{{ $json.date }}`
- `resumen`: `{{ $json.text.substring(0, 300) }}` (primeros 300 caracteres del cuerpo, útil para Notion)

**4. Notion node**
- Resource: *Database Page* → Operation: *Create*
- Seleccionas tu base de datos y mapeas las propiedades:
  - Title → nombre o asunto
  - Email (tipo Email) → `{{ $json.email }}`
  - Fecha (tipo Date) → `{{ $json.fecha }}`
  - Asunto (tipo Text) → `{{ $json.asunto }}`
- Antes de esto, crea la base en Notion con esas columnas para que los tipos coincidan.

**5. Slack node**
- Resource: *Message* → Operation: *Send*
- Channel: el que elijas
- Text, por ejemplo:
  ```
  📩 Nueva {{ $json.asunto }}
  De: {{ $json.nombre }} ({{ $json.email }})
  Fecha: {{ $json.fecha }}
  ```

**Dos consideraciones:**

- Si quieres el link directo a la página de Notion en Slack, conecta Slack *después* de Notion y usa `{{ $json.url }}` en el mensaje.
- Si el remitente no tiene nombre configurado, `name` puede venir vacío. Puedes poner un fallback: `{{ $json.from.value[0].name || $json.from.value[0].address }}`
