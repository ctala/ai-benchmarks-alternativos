## Bug 1: División por cero (`ZeroDivisionError`)
**Problema:** Si ninguna orden tiene `status == 'pending'`, la lista `processed` queda vacía. Al calcular `average = total / len(processed)`, se intenta dividir entre 0, lo que lanza una excepción.

**Solución:** Verificar si hay elementos antes de dividir, o usar un valor por defecto (0):
```python
average = total / len(processed) if processed else 0
```

## Bug 2: Mutación del diccionario original (efecto secundario)
**Problema:** Al hacer `order['final_price'] = ...` y `order['status'] = ...`, estás modificando directamente los diccionarios que vienen en la lista `orders` del llamador. Esto altera los datos originales fuera de la función, lo cual suele ser un comportamiento no deseado (las funciones deberían ser "puras" respecto a sus argumentos a menos que se indique lo contrario).

**Solución:** Crear una copia del diccionario antes de modificarlo:
```python
new_order = order.copy()  # o {**order}
new_order['final_price'] = final_price
new_order['status'] = 'processed'
```

## Bug 3: `count` incorrecto
**Problema:** `'count': len(orders)` devuelve el total de órdenes recibidas, incluyendo las que ya estaban procesadas o tenían otro estado. Semánticamente, `count` debería indicar cuántas órdenes fueron efectivamente procesadas en esta llamada.

**Solución:** Usar `len(processed)`:
```python
'count': len(processed)
```

def process_orders(orders):
    total = 0
    processed = []
    for order in orders:
        if order['status'] == 'pending':
            discount = order['total'] * 0.1 if order['total'] > 100 else 0
            final_price = order['total'] - discount

            # Bug 2 corregido: copiamos para no mutar el original
            new_order = order.copy()
            new_order['final_price'] = final_price
            new_order['status'] = 'processed'

            total += final_price
            processed.append(new_order)

    # Bug 1 corregido: evitamos división por cero
    average = total / len(processed) if processed else 0

    return {
        'processed': processed,
        'total': total,
        'average': average,
        'count': len(processed)  # Bug 3 corregido: cuenta solo las procesadas
    }
