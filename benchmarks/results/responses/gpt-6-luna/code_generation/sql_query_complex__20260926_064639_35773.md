- orders (id, customer_id, total, status, created_at)

Escribe una query SQL que muestre:
- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada

- Solo clientes con al menos 3 ordenes completadas (status = 'completed')


## Respuesta completa

Asumiendo PostgreSQL y que «categoría más comprada» significa la categoría con más unidades vendidas, puedes usar:

```sql
WITH completed_orders AS (
    SELECT
        id,
        customer_id,
        total
    FROM orders
    WHERE status = 'completed'
      AND created_at >= CURRENT_TIMESTAMP - INTERVAL '6 months'
      AND created_at < CURRENT_TIMESTAMP
),
customer_totals AS (
    SELECT
        customer_id,
        COUNT(*) AS total_orders,
        SUM(total) AS total_revenue,
        AVG(total) AS avg_order_value
    FROM completed_orders
    GROUP BY customer_id
    HAVING COUNT(*) >= 3
),
category_totals AS (
    SELECT
        co.customer_id,
        p.category,
        SUM(oi.quantity) AS units_purchased
    FROM completed_orders co
    JOIN order_items oi ON oi.order_id = co.id
    JOIN products p ON p.id = oi.product_id
    GROUP BY co.customer_id, p.category
),
ranked_categories AS (
    SELECT
        customer_id,
        category,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY units_purchased DESC, category
        ) AS rn
    FROM category_totals
)
SELECT
    c.name AS nombre,
    c.email AS email,
    c.country AS pais,
    ct.total_orders,
    ct.total_revenue,
    ct.avg_order_value,
    rc.category AS categoria_mas_comprada
FROM customer_totals ct
JOIN customers c ON c.id = ct.customer_id
LEFT JOIN ranked_categories rc
    ON rc.customer_id = ct.customer_id
   AND rc.rn = 1
ORDER BY ct.total_revenue DESC
LIMIT 10;
```

Los importes se calculan usando `orders.total`; la categoría se determina por la suma de `order_items.quantity`. En caso de empate, se elige la categoría cuyo nombre aparece primero.
