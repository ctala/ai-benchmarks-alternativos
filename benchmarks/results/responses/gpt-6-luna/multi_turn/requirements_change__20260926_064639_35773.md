Gmail Trigger → IF (asunto contiene “propuesta” o “cotización”)

### 1. Gmail Trigger

- Conecta tu cuenta de Gmail y elige que se active con emails nuevos.
- Si el nodo ofrece un campo **Search**, puedes reducir los emails que recibe con esta búsqueda:

```text
{subject:propuesta subject:cotizacion subject:cotización}
```

Aun así, añade el nodo **IF** para comprobar el asunto explícitamente.

### 2. IF: filtrar por asunto

Crea una condición de tipo **Boolean** y usa esta expresión:

```javascript
{{ /\b(?:propuesta|cotizaci[oó]n)\b/i.test($json.subject ?? '') }}
```

La condición será verdadera para asuntos que contengan “propuesta”, “cotizacion” o “cotización”, sin distinguir mayúsculas y minúsculas. Continúa desde la salida **true**.

### 3. Notion: guardar los datos

Crea una base de datos en Notion con propiedades como:

- **Asunto** — título
- **Remitente** — texto
- **Email** — email o texto
- **Fecha** — fecha
- **ID Gmail** — texto, opcional

En n8n, usa el nodo **Notion** para crear una página en esa base de datos y asigna los campos. Si Gmail entrega el remitente como `Nombre <correo@dominio.com>`, puedes extraerlo con estas expresiones:

**Nombre:**

```javascript
{{ (($json.from ?? '').match(/^(.*?)\s*<[^>]+>/)?.[1] ?? '').replace(/^"|"$/g, '') }}
```

**Email:**

```javascript
{{ ($json.from ?? '').match(/<([^>]+)>/)?.[1] ?? $json.from ?? '' }}
```

Para los demás campos, normalmente puedes usar:

```javascript
{{ $json.subject }}
{{ $json.date }}
```

Los nombres exactos de las propiedades de Gmail pueden variar según la versión del nodo; comprueba la salida del Gmail Trigger y ajusta las expresiones si es necesario. Comparte también la base de datos con la integración de Notion que hayas conectado en n8n.

### 4. Slack: notificar

Añade un nodo **Slack** configurado para enviar un mensaje a un canal. Por ejemplo:

```text
Nuevo email relacionado con una propuesta o cotización

Asunto: {{ $json.subject }}
Remitente: {{ $json.from }}
Fecha: {{ $json.date }}
```

Conecta este nodo a la salida **true** del IF, igual que el nodo de Notion. Así ambas acciones se ejecutan para cada email que coincida. Si prefieres que Slack solo notifique después de guardar correctamente en Notion, conecta Slack después del nodo de Notion.
