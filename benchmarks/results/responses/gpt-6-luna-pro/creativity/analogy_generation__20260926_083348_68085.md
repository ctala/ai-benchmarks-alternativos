## Respuesta completa

1. **Cómo funciona un modelo de lenguaje (LLM):** Un LLM genera texto prediciendo, paso a paso, qué palabra o fragmento probablemente sigue según lo que ya leyó. Imagina un mosaico que se arma en una feria: el modelo elige la siguiente ficha por su encaje con las anteriores, pero a veces pone una que luce convincente y no corresponde.

2. **Qué es una API:** Una API es una forma acordada para que dos programas se pidan cosas y reciban respuestas sin tener que conocer cómo está construido el otro. Es una trampilla de intercambio: envías un paquete con la etiqueta correcta y recibes otro de vuelta, sin que te den las llaves del taller.

3. **Qué es el fine-tuning de un modelo:** El fine-tuning consiste en seguir entrenando un modelo con ejemplos específicos para que responda mejor a una tarea o estilo determinado. Es como enseñarle a un actor un papel nuevo ensayando escenas con correcciones: no solo le das instrucciones para una función, también moldeas cómo interpreta ese tipo de papel.

4. **Qué es un rate limit:** Un rate limit fija cuántas solicitudes se pueden hacer en un periodo de tiempo. Es como recibir una cantidad limitada de fichas para una feria: cuando las gastas, toca esperar a que te entreguen el siguiente lote.

5. **Qué es el prompt engineering:** El prompt engineering es diseñar y ajustar las instrucciones que le das a un modelo para obtener una respuesta más útil. Es escribir pistas para un explorador muy literal: defines qué debe encontrar, qué reglas respetar y cómo quieres que te describa el hallazgo.
