Tengo estas tablas:
- orders (id, customer_id, total, status, created_at)
- customers (id, name, email, country, created_at)

Escribe una query SQL que muestre:
- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada
- Ordena por total_revenue DESC
- Solo clientes con al menos 3 ordenes completadas (status = 'completed')


## Respuesta completa

Asumiendo PostgreSQL, que `orders.total` es el revenue de cada pedido y que la categoría más comprada se determina por unidades:

```sql
WITH recent_orders AS (
    SELECT id, customer_id, total
    FROM orders
    WHERE status = 'completed'
      AND created_at >= CURRENT_TIMESTAMP - INTERVAL '6 months'
      AND created_at <= CURRENT_TIMESTAMP
),
customer_metrics AS (
    SELECT
        customer_id,
        COUNT(*) AS total_orders,
        SUM(total) AS total_revenue,
        AVG(total) AS avg_order_value
    FROM recent_orders
    GROUP BY customer_id
    HAVING COUNT(*) >= 3
),
category_units AS (
    SELECT
        ro.customer_id,
        p.category,
        SUM(oi.quantity) AS units_purchased
    FROM recent_orders ro
    JOIN order_items oi ON oi.order_id = ro.id
    JOIN products p ON p.id = oi.product_id
    GROUP BY ro.customer_id, p.category
),
ranked_categories AS (
    SELECT
        customer_id,
        category,
        ROW_NUMBER() OVER (
            PARTITION BY customer_id
            ORDER BY units_purchased DESC, category ASC
        ) AS category_rank
    FROM category_units
)
SELECT
    c.name AS nombre,
    c.email,
    c.country AS pais,
    cm.total_orders,
    cm.total_revenue,
    cm.avg_order_value,
    rc.category AS categoria_mas_comprada
FROM customer_metrics cm
JOIN customers c ON c.id = cm.customer_id
LEFT JOIN ranked_categories rc
    ON rc.customer_id = cm.customer_id
   AND rc.category_rank = 1
ORDER BY cm.total_revenue DESC
LIMIT 10;
```

Si quieres definir la categoría más comprada por **gasto** en lugar de unidades, cambia `SUM(oi.quantity)` por `SUM(oi.quantity * oi.unit_price)`.
