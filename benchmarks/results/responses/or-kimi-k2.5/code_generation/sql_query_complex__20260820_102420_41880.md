## Entrada exacta (lo que recibió el modelo)

**user:**

Tengo estas tablas:
- orders (id, customer_id, total, status, created_at)
- customers (id, name, email, country, created_at)
- order_items (id, order_id, product_id, quantity, unit_price)
- products (id, name, category, price)

Escribe una query SQL que muestre:
- Top 10 clientes por revenue total en los ultimos 6 meses
- Con columnas: nombre, email, pais, total_orders, total_revenue, avg_order_value, categoria_mas_comprada
- Ordena por total_revenue DESC
- Solo clientes con al menos 3 ordenes completadas (status = 'completed')


## Respuesta completa

 Aquí te presento la query SQL para obtener el top 10 de clientes por revenue:

```sql
WITH 
-- Filtrar órdenes de los últimos 6 meses completadas
recent_orders AS (
    SELECT 
        o.id,
        o.customer_id,
        o.total,
        o.created_at
    FROM orders o
    WHERE o.status = 'completed'
        AND o.created_at >= DATE_SUB(NOW(), INTERVAL 6 MONTH)
),

-- Calcular métricas por cliente
customer_metrics AS (
    SELECT 
        ro.customer_id,
        COUNT(DISTINCT ro.id) AS total_orders,
        SUM(ro.total) AS total_revenue,
        SUM(ro.total) / COUNT(DISTINCT ro.id) AS avg_order_value
    FROM recent_orders ro
    GROUP BY ro.customer_id
    HAVING COUNT(DISTINCT ro.id) >= 3
),

-- Obtener categoría más comprada por cliente
category_quantities AS (
    SELECT 
        ro.customer_id,
        p.category,
        SUM(oi.quantity) AS total_quantity,
        ROW_NUMBER() OVER (
            PARTITION BY ro.customer_id 
            ORDER BY SUM(oi.quantity) DESC
        ) AS rn
    FROM recent_orders ro
    JOIN order_items oi ON ro.id = oi.order_id
    JOIN products p ON oi.product_id = p.id
    GROUP BY ro.customer_id, p.category
)

SELECT 
    c.name,
    c.email,
    c.country,
    cm.total_orders,
    ROUND(cm.total_revenue, 2) AS total_revenue,
    ROUND(cm.avg_order_value, 2) AS avg_order_value,
    cq.category AS categoria_mas_comprada
FROM customer_metrics cm
JOIN customers c ON cm.customer_id = c.id
LEFT JOIN category_quantities cq ON cm.customer_id = cq.customer_id AND cq.rn = 1
ORDER BY cm.total_revenue DESC
LIMIT 10;
```

## Explicación de la query:

| CTE | Propósito |
|-----|-----------|
| `recent_orders` | Filtra órdenes completadas de los últimos 6 meses |
| `customer_metrics` | Calcula total de órdenes, revenue y valor promedio; filtra clientes con ≥3 órdenes |
| `category_quantities` | Determina qué categoría compró más cada cliente (por cantidad de productos) |

## Notas importantes:

1. **Categoría más comprada**: Se define por **cantidad total de productos** comprados. Si prefieres por **revenue**, cambia `SUM(oi.quantity)` por `SUM(oi.quantity * oi.unit_price)`.

2. **Fecha**: Usa `DATE_SUB(NOW(), INTERVAL 6 MONTH)` (MySQL). Para PostgreSQL: `NOW() - INTERVAL '6 months'`.

3. **Empates en categoría**: Si hay empate, `ROW_NUMBER()` elige una arbitrariamente. Para incluir todas las categorías empatadas, usar `RANK()` en su lugar.
