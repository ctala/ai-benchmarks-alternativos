## ⚡ Optimizaciones para el Timeline (Riesgos y Soluciones)

### 1. **El Cuello de Botella: Diseño → Desarrollo**
**Solución:** El diseñador entrega por **componentes**, no todo al final:
- Día 7: Sistema de diseño (colores, tipografía, botones) → Dev 1 empieza base
- Día 8: Sección Hero + Features → Dev 1 empieza maquetación
- Día 10: Resto de secciones → Dev 2 integra

### 2. **El Producto SaaS Aún No Tiene UI Real**
**Solución:** El diseñador crea **mockups realistas en Figma** (3-4 screens del dashboard de inventario) la primera semana. No esperar a capturas reales.

### 3. **Revisiones Interminables**
**Solución:** 
- **Freeze de scope** al finalizar Día 10 (no nuevas secciones)
- **Máximo 2 rondas de feedback** por fase
- Decisor único: El copywriter valida texto, el diseñador valida UI, el PO (tú) valida funcionalidad.

### 4. **Integraciones Complejas**
**Solución:** Usar **herramientas no-code/low-code** para acelerar:
- Formularios: Typeform embed o Tally (vs desarrollo custom)
- Email: Zapier + Mailchimp (vs API nativa)
- Chat: Crisp/Chatra (script simple)

| Uso | Herramienta | Por qué |
|-----|-------------|---------|
| **Diseño** | Figma + FigJam | Handoff automático a devs |
| **Desarrollo** | Next.js + Tailwind CSS o Webflow (si el equipo no tiene devs senior) | Rapidez + SEO friendly |
| **Hosting** | Vercel o Netlify | Deploy automático desde Git, CDN global gratis |
| **Forms** | Netlify Forms o Formspree | Sin backend, spam protection incluido |
| **Analytics** | Google Analytics 4 + Microsoft Clarity (heatmaps gratis) | Básico pero suficiente para lanzamiento |
| **Assets** | Unsplash (fotos), Heroicons/Phosphor Icons, Undraw (ilustraciones) | Rápido de implementar |
