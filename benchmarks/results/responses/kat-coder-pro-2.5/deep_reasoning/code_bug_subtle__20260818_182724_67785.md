## Bug identificado: MAD cero (umbral de filtrado nulo)

### Cuándo falla
Cuando **al menos la mitad de los valores son idénticos**, pero existen otros valores cercanos que no son outliers reales.

### Ejemplo concreto
```python
data = [10, 10, 10, 11]
```

### Por qué falla (traza paso a paso)

1. **Mediana** = 10
2. **Desviaciones absolutas**: `[0, 0, 0, 1]`
3. **MAD** = `find_median([0, 0, 0, 1])` = **0**  
   (la mediana de cuatro valores es el promedio de los dos centrales: `(0 + 0) / 2 = 0`)
4. **Threshold** = `3 * 0` = **0**
5. **Filtrado**: `abs(x - 10) <= 0` → solo pasan los valores exactamente iguales a 10
6. **Resultado**: `filtered = [10, 10, 10]`, promedio = **10**

El valor **11** fue eliminado incorrectamente. No es un outlier, es solo un valor cercano, pero el umbral cero lo descarta porque cualquier desviación no nula excede el threshold.

### El problema de fondo
El método de "3×MAD" asume que el MAD es positivo. Cuando hay muchos valores repetidos (o una distribución con pico agudo), el MAD colapsa a cero y el criterio de filtrado se vuelve demasiado agresivo: **elimina todo lo que no sea exactamente igual a la mediana**.

### Fix sugerido
```python
threshold = 3 * mad if mad > 0 else float('inf')
```
O usar un threshold mínimo:
```python
threshold = max(3 * mad, 1e-10)
```

Esto evita que un MAD cero descarte valores legítimos cuando la dispersión real es pequeña pero no nula.
